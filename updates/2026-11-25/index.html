📄 详细内容
  • 问题：现有具身仿真环境通常只有几十至几百个人工任务，模型容易反复训练于相似测试场景，难以形成可迁移的物理操作能力。

  • 方法：通过自动化 Real2Sim 流水线把真实操作视频重建为10,807个独立 Isaac Sim 任务，并由独立 QA Agent 检查物理保真度、复现性和验证器鲁棒性。Harbor 隔离架构隐藏仿真后端与验证器，仅开放5个交互接口，并按真机约束取消中间奖励和自行重置。

ReHarness：结果驱动的经验反向修正

用任务结果反向重写被调用的历史经验，解决智能体经验写入后无法持续纠错的问题，并在16个基准上取得最高平均增益。

用途

在需要长期运行的智能体系统中，可借鉴其结果反馈与轨迹锚定机制，持续修正经验库中的已检索内容。

启示

智能体经验的价值不应在写入时固定，而应由后续任务中的实际效用持续校正，同时保留原始轨迹作为可信依据。

📄 详细内容
  • 问题：智能体在长周期任务中需要持续积累并改进经验，但已存经验可能因缺乏后续反馈而长期保留错误或低效内容。
  • 旧法为何失效：传统系统采用单向信息流，只将执行轨迹写入经验库并在后续任务中检索，经验写入后不会依据实际使用效果更新。
  • 方法：ReHarness构建循环式架构，根据任务执行结果反向修正本次检索到的经验，同时要求重写内容以原始执行轨迹为依据。
  • 实验：在16个基准任务中，ReHarness与不同模型的组合均取得最高平均增益。

用途

在高频工具调用的智能体系统中借鉴其决策图与免回调机制，复用已验证动作以降低推理成本。

启示

智能体脚手架中的大量推理并非不可替代，将已验证决策固化为带依赖约束的可执行结构，可以同时提升执行效率与任务准确性。

📄 详细内容
  • 问题：Harness 框架频繁回调语言模型确认工具调用，带来高 Token 消耗和较慢的任务执行。
  • 旧法为何失效：传统执行流程无法复用已经解析和验证的行为、调用参数及依赖关系，导致相似决策被反复推理。
  • 方法：将高确定性的后续动作、调用参数和依赖关系存为可执行有向无环图；工具调用后检查前置条件，满足并完成认证记录后直接调度，同时依据执行反馈与成本离线自迭代优化 Harness。
  • 实验：在 DSH 基准上，准确率提升14.3%，Token 消耗减少近90%。

🤖 HarnessMM 清华大学 + 微软的研究提出了 HanressMM 方法，其核心是存储已解析的行为和依赖关系，通过复用决策来跳过慢速的推理回调，从而提高 Harness 框架的 Token 效率； ⭐️ 在基准测试中，其将 DSH 的准确率提升了14.3%的同时，将Token消耗量减少了将近90%； 其核心通过三个机制 + 一个外层自优化策略组成： 可执行的决策图：在模型推理时，将确定性很高的后续动作，调用参数和依赖关系存储为有向无环图； 决策复用：在任务过程中始终保留决策图，每次工具调用后，检查动作的前置条件是否已经满足； 替代回调：在前置条件全部满足后，完成认证记录，即可直接调度执行，无需回调 LLM 进行确认； 外层自优化：根据任务的执行反馈和成本消耗，离线自迭代优化 Harness 框架；
