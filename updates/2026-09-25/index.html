ModularRSI：冻结模型权重实现 Harness 持续自我改进

ModularRSI 通过分析执行轨迹并迭代修改、验证模块化 Harness，使冻结权重的智能体在 Terminal-Bench 2.0 上提升 4.86 个百分点，并展现跨任务、跨领域和跨模型迁移能力。

子主题：脚手架演化 IQuest Research  HarnessEvolve

 智能体脚手架演化 递归自我改进 智能体 执行验证 跨域泛化

论文：https://arxiv.org/abs/2609.14857
代码：https://github.com/IQuestLab/ModularRSI
原文：https://mp.weixin.qq.com/s/AU_oX_YrnUJ4HYfmctwL3A

ModularRSI 将智能体表示为冻结的基础模型与可演化 Harness 的组合，并把 Harness 拆分为 Agent Loop、观测管理、工具使用、上下文管理和任务完成检测五个模块。系统从多次 rollout 的成败轨迹中提炼系统性缺陷，生成代码修改，并依次通过程序检查、差异审查和执行验证，避免任务特化与运行时退化。演化后的 Harness 将 Terminal-Bench 2.0 准确率从 47.57 提升至 52.43，且能迁移到 SWE-Bench Verified 以及 GLM-5.2、MiniMax-2.5 等不同基础模型。实验还表明，模块独立演化后再整合优于全模块联合演化，而成功率居中的任务因同时提供成功与失败轨迹，最适合产生可泛化的改进。

用途与启示
  • 说明智能体能力提升不必依赖模型权重更新，外围 Harness 可以成为递归自我改进的重要载体。
  • 为智能体脚手架演化提供“轨迹分析—缺陷诊断—代码修改—验证准入”的闭环工程范式。
  • 提示演化数据应优先覆盖成功与失败并存的中等难度任务，以提高对比信号和经验提炼效率。
  • 表明模块化独立演化、功能合并与任务感知组合有助于控制模块耦合和能力冲突。
  • 跨领域、跨模型迁移结果可用于检验 Harness 改进是否形成通用执行机制，而非对特定基准过拟合。

Meta“组织第二大脑”智能体设计：可审计知识与自改进闭环

Meta 提出一种将机构知识置于模型权重之外，并通过显式推理程序、专家反馈及回归测试持续更新的可审计“组织第二大脑”智能体架构。

子主题：长期记忆 AI前线  MemoryEvolve

 智能体记忆 智能体 自我改进 人在回路 执行验证

原文：https://mp.weixin.qq.com/s/TB6qoewDLoRqQN3rYNeviw

该架构由知识系统、推理管道、评估框架和自改进闭环四层组成，旨在捕获领域专家的判断逻辑，而非仅存储和检索文档。机构知识被组织为立场文件、分类法与词汇文件、路由索引和网关文件，并通过版本控制保留在模型权重之外。推理层使用可组合的“配方”规定检查顺序、知识加载方式、决策程序和停止条件，同时区分知识缺失与推理流程缺陷。专家修正会被追溯到根因，编译为最小修改项，并通过回放与回归测试后纳入永久测试套件；Meta 称该方案将单项评估从数天缩短至数分钟，并在多个改进周期中实现零回归。

用途与启示
  • 为企业级智能体提供一种知识与模型权重解耦的长期记忆方案，使专业知识能够被审计、版本化和低成本更新。
  • 可借鉴“专家纠错—根因定位—最小修改—回放验证—回归固化”的闭环，构建不会重复犯错的组织知识系统。
  • 显式推理配方和人工检查点有助于提升合规、安全、金融等高风险场景中的可控性与责任追溯能力。
  • 该设计表明，企业智能体的持续改进未必依赖重新训练模型，也可通过知识工程、流程编排和验证体系实现。

从 AI Build AI 到真正 RSI：自进化闭环的实践路径

张江塔尖会围绕代码研发、科学发现与具身智能等场景，探讨 AI 如何打通智能体、环境、数据和模型之间的闭环，从局部优化迈向真正的递归自我改进。

子主题：递归自我改进 机器之心  Awesome-RSI

 递归自我改进 自演化 智能体 自动化科学研究 具身智能

原文：https://mp.weixin.qq.com/s/x4qitPgt_js6Pj_M1oBDDg

真正的 RSI 不只是提升既定任务表现，而是由 AI 自主发现和定义问题、提出方案、构建反馈并验证结果，形成任务、数据、环境与模型协同演进的外循环。代码任务拥有可执行环境和客观验证信号，被认为是较可能率先实现 RSI 的场景，但仍需打通模型、Harness、数据、基础设施与工具调用。科学发现可通过假设生成、实验执行、证据验证和经验沉淀构成长程闭环，同时面临反馈稀疏、干湿实验速度不匹配及科研数据不足等问题。具身智能则需要结合世界模型、仿真与真实交互、强化学习及可执行经验，让机器人从失败中持续学习并适应新环境。

用途与启示
  • 为判断系统是否具备真正的 RSI 提供标准：不仅观察任务性能，还要检验其能否自主构建并维持改进闭环。
  • 可优先在代码、科学实验等反馈明确且可验证的环境中开展长程智能体训练与自进化研究。
  • 系统设计应从单独优化模型或 Harness，转向任务、数据、环境、模型及工具链的协同演进。
  • 具身智能和 AI for Science 的关键是把稀疏、昂贵的真实反馈沉淀为可检索、可迁移和可复用的经验。

北大开源 DataFlex-RL：统一接入与公平比较 RL 数据策略

北大 DCAI 团队等开源 DataFlex-RL，通过插件化选择、重加权和领域混合组件，在统一 RLVR/GRPO 流程中动态调度训练数据并公平比较不同策略。

子主题：数据策展 新智元  EvolveLRM

 强化学习 模型训练 后训练 数据策展 策略优化

论文：https://arxiv.org/abs/2609.06107
代码：https://github.com/haolpku/DataFlex-RL
原文：https://mp.weixin.qq.com/s/iQpB2u3KJW84MwkXyAMmrg

DataFlex-RL 基于 verl 构建插件化框架，将强化学习数据策略划分为 rollout 选择、样本或 token 重加权，以及动态领域混合三类动作。框架直接复用训练过程中产生的奖励、advantage、token 概率和 prompt 分组等信号，并通过 Scorer 与 Actuator 解耦打分和执行，减少对训练器的重复修改。论文开展了 591 次实验，在统一模型、奖励函数和训练预算下比较多种策略；动态领域混合方法相对固定等比例混合取得最高 0.61 个百分点的平均提升。该项目与 DataFlex 形成互补，将数据中心化处理从训练前的数据准备延伸至 RLVR/GRPO 的在线训练调度。

用途与启示
  • 为新的 RL 数据选择、重加权或领域调度算法提供标准化接入接口，降低工程改造成本。
  • 在相同模型、奖励函数、训练预算和评测流程下比较数据策略，减少混杂因素并提升实验公平性。
  • 利用训练反馈动态调整样本难度、更新权重和领域配比，可用于研究课程学习与自适应数据调度。
  • 完整记录保留比例、权重统计和领域分布，便于诊断策略行为及复现实验结果。

Spatial-Interactor：通过物理交互学习空间推理

Spatial-Interactor利用真实与模拟交互轨迹及分层课程训练视觉语言模型，使其学习局部物理状态转移并在长程交互中持续更新空间状态。

子主题：视觉推理 Hugging Face Papers 

 视觉推理 具身智能 多模态 在策略蒸馏 长程任务

论文：https://arxiv.org/abs/2609.23038

Spatial-Interactor将空间交互学习划分为三级课程：L1被动世界状态转移、L2主动自身状态转移，以及L3长程交互轨迹。作者基于模拟和真实交互轨迹构建了LSI-108K数据集，以动作前观察、动作和动作后观察为监督信号。训练首先通过SFT学习L1和L2的局部状态转移，再使用带特权信息的在策略蒸馏，让教师分支依据片段级转移描述监督学生的在策略思维链。多个视觉语言模型和空间推理基准上的实验表明，该方法能同时改善局部转移建模与长程空间状态整合。

用途与启示
  • 为具身视觉语言模型提供从交互轨迹中学习动态空间变化的训练范式。
  • 表明分层课程可将局部状态转移学习逐步扩展到长程轨迹整合。
  • 可借鉴特权自蒸馏机制，在训练阶段利用显式状态描述增强模型的隐式空间推理能力。
  • LSI-108K可为动态空间推理、具身规划和长程状态追踪研究提供数据设计参考。
