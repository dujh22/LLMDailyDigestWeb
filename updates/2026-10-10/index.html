Novix 跑通协同进化式 RSI 规模化闭环

Novix 通过 AI 自主探索、专家持续反馈与系统能力回流，将协同进化式递归自我改进应用于模型后训练及复杂科学工程任务。

 递归自我改进 自动化科学研究 科研智能体 人在回路 自演化

原文：https://mp.weixin.qq.com/s/iLtJ8g3xwawKfnoShFBIFg

Novix 提出 Co-Evolutionary RSI，由多个 Agent 执行任务分解、数据处理、工具调用、实验和验证，专家则在方向、证据标准与关键决策节点提供反馈。系统将任务分布、评价标准、失败记录和专家判断持续回流，用于改进自身的工具选择、评估器、任务规划及模型能力。在模型后训练案例中，平台自主完成数据构造、SFT、GRPO/RFT 和检查点选择，并能在真实性能下降时停止训练、回退版本。平台还在八座水坝耦合控制和钢材循环响应预测任务中完成多轮实验与纠错，交付通过约束检查或保留测试的可执行结果。

用途与启示
  • 展示将专家判断转化为 RSI 长期反馈信号的产品化路径，使 AI 的探索方向而非单次执行能力成为优化重点。
  • 为科研智能体设计提供闭环范式：保留实验轨迹、失败路径和评价结果，并持续反哺任务规划、工具调用与评估器。
  • 说明模型训练智能体需要以真实任务探针和检查点回退机制防止训练指标改善掩盖能力退化。
  • 为复杂科学工程任务提供人在回路的协作方式，让专家聚焦方向选择、证据审查和评价标准调整。

Trace2Env：从交互轨迹构建智能体语言世界模型

Trace2Env 无需重建原始可执行系统，即可将历史交互轨迹转化为具备持久状态的语言世界模型，用于逼真模拟智能体交互环境。

★ 3 子主题：世界模型 Hugging Face Papers  EnvironmentEvolve

 世界模型 智能体 环境合成 状态持久化 长程任务

论文：https://arxiv.org/abs/2610.06100

论文提出智能体语言世界建模范式，让世界模型智能体直接充当任务智能体的交互环境，并提供忠实且有状态的模拟。Trace2Env 是一个无需训练的框架，可将历史交互轨迹重构为包含环境模式、事实证据和归纳行为知识的可复用 worldbook。运行时，世界模型智能体结合 worldbook 与持久化情景状态，预测每个动作的观测结果及其长期状态影响。在九个环境上的实验显示，该方法提升了下一观测保真度与长程交互一致性，模拟环境中产生的动作回放至真实环境时也更常保持有效。

用途与启示
  • 在原始系统不可访问或难以复现时，可利用历史轨迹快速构建智能体训练与评测环境。
  • 通过持久化情景状态保留早期动作的后续影响，提高多轮模拟的一致性。
  • 为无需重建可执行系统的环境合成提供新路径，可降低真实环境接入和复现成本。
  • worldbook 的模式、证据与行为知识结构可用于增强模拟结果的可追溯性。

AgentGarten：面向持续进化智能体的代码世界

AgentGarten通过代码化仿真后端与共享神经渲染器构建可扩展的实时交互世界，使智能体能够继承并迭代经验，在少量交互轮次中持续提升能力。

★ 3 子主题：环境合成 Hugging Face Papers  EnvironmentEvolve

 智能体 环境合成 技能演化 经验学习 视觉生成

论文：https://arxiv.org/abs/2610.12374

AgentGarten将模拟器、游戏引擎与共享神经渲染器结合，以统一接口生成具有持久状态、明确规则和真实视觉观测的交互环境。其神经渲染器由预训练视频模型适配几何条件而来，并通过 Adversarial Forcing 蒸馏和推理优化实现实时交互。智能体将每轮交互经验提炼为 playbook，供后续智能体继承和改进，从而形成经验驱动的持续进化过程。实验显示，该框架仅需 4 轮学习便可获得显著提升，而传统强化学习方案通常需要数百万轮；新世界还可通过代码持续扩展数量与难度。

用途与启示
  • 为持续学习和自进化智能体提供兼具规则一致性与视觉真实性的可扩展训练环境。
  • 通过代码定义世界状态和交互规则，降低新增任务环境及调整难度的成本。
  • 以 playbook 形式沉淀和继承交互经验，可用于探索跨代技能积累与经验复用。
  • Adversarial Forcing 为实时神经渲染器的历史条件建模和视觉质量优化提供了新思路。

DreamTrue：反事实后训练实现动作忠实的机器人世界模型

DreamTrue通过几何校准、反事实轨迹扩展与具身视频奖励模型，提升跨机器人本体视频预测的动作忠实性和物理合理性。

★ 2 子主题：世界模型 Hugging Face Papers  DataEvolve

 世界模型 具身智能 强化学习 视频生成 奖励建模

论文：https://arxiv.org/abs/2610.12468

DreamTrue是一个支持多视角、跨本体的机器人世界模型，目标是根据动作生成忠实且符合物理规律的未来视频。该方法将动作轨迹渲染为图像空间条件，并通过离线几何校准缓解机器人数据标定误差造成的动作错位。其反事实后训练会修改已记录的动作轨迹，从而覆盖更多动作与接触配置，尤其补充真实数据中稀缺的失败交互。团队还利用人工标注的机器人、物体及交互缺陷视频训练具身视频奖励模型，并以其反馈开展强化学习后训练；在AgiBot上，交互缺陷率由48.12%降至6.25%，并获AgiBot World Challenge 2026世界模型赛道第一名。

用途与启示
  • 为机器人策略训练与规划提供动作条件一致、物理可信的未来视频预测。
  • 展示如何利用反事实动作扩充失败交互与长尾接触场景，降低成功结果偏置。
  • 说明在缺少成对真实未来视频时，可通过人工缺陷标注和奖励建模提供后训练反馈。
  • 为跨机器人本体的动作表示、几何对齐和世界模型泛化提供实践路径。

Learn2Play Bench：评测智能体在陌生环境中的经验学习能力

Learn2Play Bench 通过规则新颖或反直觉的文本游戏，评测 LLM 智能体能否从重复交互中获取、保留并迁移经验。

★ 2 子主题：智能体评测 Hugging Face Papers  EvalEvolve MemoryEvolve

 智能体评估 经验学习 交互式评估 智能体脚手架 成本优化

论文：https://arxiv.org/abs/2610.08215

Learn2Play Bench 由一组新设计的文本游戏组成，其规则新颖或反直觉，旨在排除预训练知识的干扰，重点测量智能体从交互反馈中学习的能力。游戏提供可复现反馈和自动评分，并通过改变游戏实例检验经验能否迁移至新情境。实验发现，保留完整的动作与反馈记录通常比将经验总结为规则或策略更有效。表现最好的智能体仍落后于人类玩家，而在固定骨干模型时，更换智能体脚手架可同时改善成绩并降低估算推理成本。

用途与启示
  • 为经验学习、自进化智能体和智能体脚手架提供可控、可复现的评测基准。
  • 提示经验系统应谨慎压缩交互历史，完整轨迹可能比抽象规则保留更多有效信息。
  • 说明智能体性能不仅取决于骨干模型，脚手架设计也是影响学习效果与推理成本的关键变量。
  • 可用于分析探索多样性、重复动作和跨实例经验迁移等失效模式。

★1 TokenRouter：高效 Token 级 LLM 路由服务系统 Hugging Face Papers · 模型路由 · 论文 · 代码 TokenRouter 通过请求中心编程、模型中心执行和延迟批处理调度，将 Token 级 LLM 路由的解码吞吐量提升至现有系统的 2.01～64.15 倍。

★ 1 子主题：模型路由 Hugging Face Papers 

 模型路由 系统优化 成本优化 推理加速

论文：https://arxiv.org/abs/2610.12242
代码：https://github.com/thu-nics/TokenRouter

TokenRouter 面向 Token 级 LLM 路由，解决多模型推理中的执行步不同步、批请求准入延迟和开发复杂度问题。系统采用“请求中心编程、模型中心执行”范式，允许开发者从单请求视角描述路由逻辑，并由运行时为各个 LLM 启动独立子服务进行异步分发。每个子服务使用延迟批处理调度器，其关键超参数通过系统吞吐量数学模型推导。跨多种路由算法、工作负载和模型组合的实验显示，其解码吞吐量相比现有系统提高 2.01～64.15 倍。

用途与启示
  • 为细粒度 Token 级模型路由提供可落地的高吞吐服务架构。
