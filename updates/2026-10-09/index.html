R-Quest：以有效性与新颖性反馈维持推理模型自进化

R-Quest通过识别无效问题并评估数学问题的新颖性，缓解重复自训练中的数据质量与多样性坍缩，使推理模型连续十轮自进化仍能稳定提升。

★ 3 子主题：自进化 Hugging Face Papers  EvolveLRM DataEvolve

 自演化 推理 模型训练 数据质量过滤 数学人工智能

论文：https://arxiv.org/abs/2610.04299

研究发现，自生成问题中的无效问题会随训练轮次增加，而答案一致性过滤反而可能提高这类问题在训练数据中的占比。基于词法相似度的多样性控制无法识别表达不同但数学上等价的问题，导致后期问题多样性坍缩。R-Quest先训练求解器识别并拒绝无效问题，再用其判断指导出题器奖励和求解器数据过滤，同时借助冻结的基础模型提供问题新颖性反馈。该方法在两个模型家族及数学推理、通用推理和代码生成等12个基准上取得最高平均表现，连续十轮保持稳定增益，最终比R-Zero高17.32分。

用途与启示
  • 揭示迭代式自训练失效不仅源于答案噪声，也与问题有效性下降和语义重复积累有关。
  • 可将有效性判别器与新颖性反馈纳入自生成数据流水线，改善训练数据筛选和奖励设计。
  • 提示多轮自进化系统应使用语义或数学等价性判断，而不能只依赖表层文本相似度控制多样性。
  • 为构建可长期运行的推理模型闭环自进化机制提供了实证方案。

SCAPO：半事实信用增强策略优化

SCAPO利用半事实提示干预衡量词元稳定性，改进GRPO的词元级信用分配，从而提升数学推理准确率与分布外泛化能力。

★ 3 子主题：信用分配 Hugging Face Papers  EvolveLRM LogicEvolve

 强化学习 信用分配 策略优化 推理 跨域泛化

论文：https://arxiv.org/abs/2609.40360
代码：https://github.com/DtYXs/SCAPO

论文发现，采用可验证奖励的强化学习模型仍容易受到与任务无关的提示特征影响，且不同候选词元的敏感性存在显著差异。传统GRPO为回复中的所有词元分配相同的结果优势，可能同时强化有效推理路径和伪相关依赖。SCAPO通过保持问题及答案不变的半事实提示干预，测量固定回复的词元概率漂移，并在训练早期降低不稳定词元的优势权重。基于Qwen3-4B-Base和Qwen3-1.7B-Base的实验中，SCAPO相较GRPO在AIME 2024—2026上分别提升5.63和4.17个百分点，并在多数数学基准及全部分布外基准上取得最佳结果。

用途与启示
  • 为RLVR提供比序列级结果奖励更细粒度的词元信用分配机制。
  • 可借助半事实稳定性抑制模型对提示表面特征和伪相关模式的依赖。
  • 表明无需单独奖励“稳定性”，仅削弱高漂移词元的优势即可改善推理与泛化。
  • 可用于设计更具因果稳健性的GRPO变体及分布外推理训练方案。

★0 STEPQuant：面向 Delta 规则循环状态的时空量化 Hugging Face Papers · 模型轻量化 · 论文 · 代码 STEPQuant依据量化误差的持续时间与空间影响分配循环状态精度，在名义 6-bit 预算下接近 FP32 准确率，并将服务总显存最多降低 68.7%。

★ 0 子主题：模型轻量化 Hugging Face Papers 

 系统优化 成本优化 长上下文 状态表征 模型开发

论文：https://arxiv.org/abs/2609.38169
代码：https://github.com/Dreamer-Toby/STEPQuant

线性注意力以固定大小的循环状态替代持续增长的 KV Cache，但并发服务时循环状态仍会形成显著的显存瓶颈，直接低比特量化还会因误差在连续状态更新中传播而损害准确率。研究发现，量化误差在时间上受记忆存续周期影响，在空间上则因不同 key 行对输出的影响不同而呈现显著差异，同时状态幅值在行列方向均不均匀。STEPQuant据此按误差大小和记忆寿命分配精度，并结合 key 行影响与状态分布联合拟合 key-row 和 value-column 缩放因子。在 Qwen3.8-27B 与 Kimi-Linear-48B-A3B-Instruct 上，其 6-bit 配置接近 FP32 状态准确率，4-bit 配置优于统一 INT8；集成 SGLang 优化内核后实现超过 5 倍的循环状态压缩，服务总显存最多下降 68.7%。

用途与启示
  • 为线性注意力模型的并发推理提供比统一量化更精细的循环状态压缩方案。
  • 表明持久状态量化不能只依据数值幅度，还应同时考虑误差的生命周期及其对模型输出的敏感度。
  • 可将时空敏感的混合精度分配思想推广到长期记忆、状态空间模型及其他递归推理架构。
  • 与 SGLang 和定制 GPU 内核结合后，可直接用于降低大模型长短文本生成服务的显存成本。
