SEED：自进化在策略蒸馏

用持续进化的事后技能提供稠密监督，弥补智能体强化学习仅靠稀疏结果奖励的缺陷。

★ 3 子主题：在策略蒸馏 arXiv  AgentTrainEvolve

 在策略蒸馏 强化学习 智能体 技能演化 长程任务

论文：https://arxiv.org/abs/2607.14777
代码：https://github.com/jinyangwu/SEED
用途

在长程工具调用或多轮交互智能体训练中，可直接使用其代码，或借鉴技能增强重打分机制补充稀疏结果奖励。

启示

从当前策略轨迹中提炼并同步更新的事后技能，可以把整局成败转化为与策略分布对齐的细粒度监督。

📄 详细内容
  • 问题：结果奖励只在完整轨迹层面提供稀疏信号，难以指导长程智能体的中间决策和词元级策略学习。
  • 旧法为何失效：单靠任务成败优化无法精细分配各步骤贡献，固定的技能分析器又可能随着策略更新而逐渐滞后。
  • 方法：SEED先用离线完整轨迹训练策略提取可复用的事后技能；强化学习阶段由当前策略同步采集轨迹和分析技能，并比较普通上下文与技能增强上下文下的动作概率，将变化转化为稠密的在策略蒸馏信号，与结果奖励联合优化。
  • 实验：在文本和视觉智能体任务上，SEED持续提升任务表现与样本效率，并能泛化到未见场景。

MBT：并行分支与共享缓存

用并行Transformer分支与共享KV缓存，同时提升语言建模质量和长上下文解码效率。

★ 3 子主题：模型架构创新 Hugging Face Papers  NewModel SystemEvolve CacheEvolve

 模型开发 系统优化 缓存优化 长上下文 推理加速

论文：https://arxiv.org/abs/2611.19800
用途

在语言模型预训练和长上下文推理系统中借鉴Balanced分支结构与Joint-KV机制，以提升质量并降低缓存和解码成本。

启示

并行分支带来的收益并非简单改变宽度或深度，而是一种可独立扩展的计算维度，并天然创造了跨分支共享推理状态的机会。

📄 详细内容
  • 问题：传统Transformer主要靠加宽或加深扩展，难以同时改善建模质量、训练效率和长上下文推理成本。
  • 旧法为何失效：单路顺序堆叠限制了计算组织方式，而独立分支若各自保存KV缓存，又会增加推理存储开销。
  • 方法：Multi-Branch Transformer先经过共享前层，再并行执行多个独立参数化分支并融合输出；Balanced配置平衡宽度与深度，Joint-KV则在各深度汇合分支表征，构建共享KV缓存。
  • 实验：在总参数量0.8B至2.1B的四种MoE规模下，分支模型在匹配参数与训练计算量时优于顺序Transformer；最终方案使基线需多至1.26倍训练主体计算量才能追平，并将完整模型KV缓存减少最多34%、单张H200解码吞吐提高最多51.4%。

ForceHarness：冻结模型力觉闭环

用自主闭环的力控动作与物理量翻译，让无法微调的多模态模型零样本完成接触操作，真机成功率从3.3%升至90.0%。

★ 2 子主题：具身规划 Hugging Face Papers  PhysicalEvolve HarnessEvolve

 具身智能 工具调用 执行反馈 不确定性估计 人工智能框架

论文：https://arxiv.org/abs/2611.21099
用途

在API调用的冻结多模态模型控制机器人时，可借鉴其自终止力控原语和物理量翻译层，为接触操作增加无需微调的低层力觉闭环。

启示

冻结模型不必直接处理高频原始传感器流；将快速反馈下沉为自治动作，再把轨迹提升为带不确定性的物理语义，能显著增强其物理决策能力。

📄 详细内容
  • 问题：仅靠图像的前沿多模态模型看不到接触力，而机器人操作中的接触变化又快于API模型的决策速度，导致零样本力控任务难以完成。
  • 旧法为何失效：远程模型无法及时闭合高频力反馈回路，也难以直接理解原始力传感器流；依赖示范训练的力觉策略还要求额外数据与微调。
  • 方法：ForceHarness先从腕部传感器或关节力矩校准手部受力，再用可在接触事件处自主终止的力控原语执行局部闭环；物理翻译层把力轨迹转成带不确定性的物理量，作为工具结果交给冻结模型推理。
  • 实验：团队构建含7项任务和隐藏物理变量的MuJoCo基准HiddenPhys。真机无腕部力传感器时，GPT-6 Astra零样本成功率由3.3%升至90.0%；在ForceBench和HiddenPhys上分别提升17.5和34.3个百分点，超过示范训练的力觉策略，并在HiddenPhys上追平手写专家控制器。

VideoNexus：独立感知的证据压缩

用独立感知子智能体回传紧凑时序证据，避免长视频细节挤占规划上下文并降低成本。

★ 2 子主题：上下文压缩 Hugging Face Papers  HarnessEvolve CacheEvolve

 智能体 视频理解 上下文压缩 多模态 成本优化

论文：https://arxiv.org/abs/2611.21392
用途

在长视频问答或视频检索智能体中借鉴其独立感知上下文与紧凑证据接口，减少规划器输入和调用成本。

启示

长视频推理的关键瓶颈不只是采样长度，而是感知结果以何种粒度进入规划上下文；证据接口越紧凑且时间定位越明确，越能兼顾细节与效率。

📄 详细内容
  • 问题：长视频问答需要定位证据、辨认视觉细节并整合观察结果，密集视觉内容会同时加重感知与推理上下文负担。
  • 旧法为何失效：直接向规划器返回视频帧会持续扩张上下文；稀疏采样可能遗漏决定性细节，逐帧描述也无法阻止上下文增长。
  • 方法：VideoNexus 将细粒度视频感知与证据驱动的规划推理解耦；规划器决定检查位置、解析目标和采样密度，感知子智能体在独立上下文中处理原生音视频，仅回传紧凑且带时间定位的证据。
  • 实验：以 Gemini 3.8 Flash 同时负责规划和感知时，在完整 LVBench 上达到 88.6%，较同骨干静态输入和内置智能体处理分别高 3.6、1.1 个百分点，API 成本仅为后者的 44%；使用 Kimi K3 时，较官方 Video-GAIA ReAct 脚手架高 8.5 个百分点。

认知共生体：关系可迁移的终身增强

用可穿戴、多设备协同且关系可迁移的终身智能体，解决云端助手不在场、换模型即失忆的问题。

★ 2 子主题：智能体框架 新智元  PersonalEvolve MemoryEvolve AutonomousAgentEvolve

 智能体 智能体记忆 具身智能 人工智能应用 人工智能安全治理

论文：https://arxiv.org/abs/2611.05376
原文：https://mp.weixin.qq.com/s/tabOubDz4J48ShhSXX3u4g
用途

在可穿戴个人智能体或具身机器人系统中，借鉴其模型外持久化关系层、快慢双回路及可审计治理架构。

启示

个人AI的长期价值不应绑定某代模型，而应沉淀在可迁移、可审计且由用户掌控的关系层中。

📄 详细内容
  • 问题：现有个人智能体主要驻留云端，难以持续感知用户所处环境、身心状态与即时需求，也无法在关键时刻低摩擦地增强人的记忆、判断和行动。
  • 旧法为何失效：聊天助手和云端智能体以完成任务为目标，缺少第一人称情境与终身关系；更换模型、应用或设备后，用户记录、介入策略和相互理解往往需要从头建立。
  • 方法：提出“认知共生体”，通过眼镜、耳机、吊坠、指环等设备持续连接用户，并以“认知全双工”让后台慢回路检索核对、前台快回路实时提示。用户记录、系统对用户的理解、介入策略及工具框架被置于底座模型之外，从而支持跨模型迁移、审计与回滚。
  • 局限与后续：长期贴身运行会带来操纵与谄媚、技能退化、虚假记忆、思想数据泄露、厂商锁定及隐蔽作弊等风险，需要协助等级申报、防篡改日志、硬件证明和隐私保护证明共同约束。

TCP4D：统一TCP跟踪与轨迹生成

用共享四维场景表征从单目视频恢复机器人动作并生成未来轨迹，还可跨机器人合成示范数据。

★ 2 子主题：三维跟踪 Hugging Face Papers  RobotEvolve PhysicalEvolve DataEvolve

 具身智能 状态追踪 任务规划 数据合成 能力迁移

论文：https://arxiv.org/abs/2611.23143
用途

在机器人模仿学习与跨本体迁移系统中，借鉴共享四维表征从单目视频提取TCP动作标签，并合成目标机器人示范用于策略训练。

启示

以本体无关的工具中心点作为统一动作接口，可让运动恢复、未来规划和跨机器人数据迁移共享同一空间表征。

📄 详细内容
  • 问题：机器人操作视频缺少动作与夹爪状态标注，难以仅从RGB画面恢复可用于不同机器人本体的操作轨迹。
  • 旧法为何失效：已有方法通常依赖源机器人的已记录状态或本体专用动作空间，难以利用普通视频并迁移到新机器人。
  • 方法：TCP4D以与本体无关的工具中心点位姿为动作空间，用共享四维场景表征同时恢复SE(3)度量位姿、夹爪状态、场景几何和相机参数，并结合观测与语言指令生成未来TCP轨迹；其跨本体增强管线还能重定向动作并合成新本体观测。
  • 实验：跟踪器在DROID和RoboLab上的绝对轨迹误差分别为7.60毫米和16.07毫米，仅用10条示范即可适配新本体；生成器在RoboTwin上平均成功率达69.19%，源数据与增强数据联合训练比仅使用增强数据将目标机器人成功率提高41.5%。

Heave-Ho：无网络通信多机协作

用局部观测控制与语音领从同步解决多个人形机器人长时程全身协作，并从2台扩展至10台。

★ 2 子主题：多智能体协作框架 Hugging Face Papers  SwarmEvolve RobotEvolve PhysicalEvolve

 多智能体协作 具身智能 长程任务 任务规划 多智能体系统

论文：https://arxiv.org/abs/2611.22275
用途

在多个人形机器人搬运和协同操作系统中借鉴其局部观测控制与语音领从同步机制，构建无需集中式网络的长时程执行框架。

启示

将物理耦合下的局部控制与人类可感知的语音同步结合，可使只在小规模同构团队上训练的策略自然扩展到更大规模异构团队。

📄 详细内容
  • 问题：多个人形机器人协作需要同时处理全身物理交互、长时程规划和精确同步，且要在去中心化条件下稳定执行。
  • 旧法为何失效：基线方法难以兼顾物理耦合控制与长时程协调，在缺少集中式网络通信时尤其难以同步多个机器人。
  • 方法：Heave-Ho在低层用多智能体后训练，将人形基础跟踪模型适配到机器人间的物理耦合交互，仅凭局部观测实现去中心化控制；高层训练视觉语言规划器，并以语音领从机制同步执行，无需网络通信。
  • 实验：HH-Bench包含12项任务，覆盖2至10台人形机器人及异构团队；系统仅用两台同构机器人训练，即可扩展至10台并零重训练泛化到异构团队，整体优于基线，真实机器人实验也验证了鲁棒性。

📄 详细内容
  • 问题：当大模型不经梯度训练、直接编写目标权重时，传统Transformer是否仍是合适的模型结构。
