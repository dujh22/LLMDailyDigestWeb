RSI Arena：人类反馈校准递归改进

用开放人类盲测指导智能体自主后训练，并揭示受欢迎度提升不等于能力或安全性进步。

★ 3 子主题：递归自我改进 机器之心  EvolveLRM Awesome-RSI

 递归自我改进 模型训练 人在回路 模型评估 人工智能可靠性

论文：https://arxiv.org/abs/2610.33624
原文：https://mp.weixin.qq.com/s/XDcZOAwvD63JGYY2aPFXLg
用途

在自动化后训练系统中借鉴 RSI Arena 的等预算沙箱、开放盲测和能力—偏好—安全分离评估机制，审计智能体是否产生真实改进。

启示

递归自我改进的核心瓶颈不是能否自动提高评分，而是能否区分真实能力增长、风格迎合与安全退化，并由人类持续定义值得优化的方向。

📄 详细内容
  • 问题：AI 已能自主完成模型后训练，但评测分数上涨可能来自真实能力进步，也可能只是迎合评分规则，因而难以判断什么才算可靠的自我改进。
  • 旧法为何失效：围绕固定 benchmark 优化容易造成基准过拟合和奖励作弊；开放人类投票虽更难被直接钻空子，却仍会受到回答长度等风格偏好的影响。
  • 方法：RSI Arena 让 10 个前沿模型在同一起点、独立沙箱和等额预算下自主完成数据选择、训练、评估与提交，再用独立基准和真实用户盲测反馈迭代；论文进一步提出结合人类反馈的 RSIHF 框架，并要求能力、偏好与安全性分开评估。
  • 实验：第一阶段每个智能体获得1000 GPU小时和300美元 API 额度，最佳模型补齐与 NVIDIA Instruct 能力差距的中位比例达76%；第二阶段8/10模型的人类相对评分提升，中位增幅28分，但综合基准仅提升2个百分点，二者相关系数为−0.19。较长回答赢得72%的长度有差异投票，且部分模型在 StrongREJECT 上安全性下降。
  • 局限与后续：实验仅使用一个基础模型，每个训练智能体只运行一次，且第二阶段变化无法完全归因于人类反馈；后续需持续独立评估能力与安全性，并研究何时求人介入及如何跨轮校准反馈。

RSI综述：四组件七步自进化框架

用四类可进化组件与七步更新闭环，解释智能体如何把交互经验转化为可验证、可复用的长期改进。

 递归自我改进 智能体 自演化 经验学习 智能体脚手架演化

原文：https://mp.weixin.qq.com/s/qSGDg7qCREq-dNgXYx2Y9g
用途

在设计长期运行的编程或工具调用智能体时，可借鉴四组件与七步生命周期搭建经验收集、更新验证、回归测试和回滚闭环。

启示

智能体自进化的关键不只是保存成功经验，而是让经验经过归因与独立验证后成为可维护结构，并继续提升下一轮改进本身的质量。

📄 详细内容
  • 问题：智能体如何在模型权重不变时，将工具调用、失败修复和用户反馈沉淀为能力，并让既有经验继续帮助后续自我改进。
  • 旧法为何失效：既有工作分散在提示、记忆、技能与运行框架等方向，常侧重生成候选更新，缺少跨组件归因、独立验证和长期维护的统一分析框架。
  • 方法：综述40项代表性研究，并对20个更新闭环进行对照；以 When、Where、How 三个问题统一 Prompt、Memory、Skill、Harness 四条进化主线，再将经验转化拆为收集、评估、诊断、提炼、更新、验证和整合保留七步。
  • 实验：通过20项研究的机制对照，分析不同方法在诊断、候选验证、保留决策以及经验参与后续改进方面的差异；本文属于综述，未报告统一基准上的性能提升。
  • 局限与后续：持续进化仍需解决跨组件信用分配、规则与技能的合并退役及回滚，并在相同起点、反馈和计算预算下独立检验继承经验是否真正改善后续更新。

OptiMer：分布向量最优合并

用可复用的训练差分向量替代反复混合数据训练，将配比优化加速15～35倍并提升平均得分。

★ 2 子主题：数据混合 机器之心  EvolveLRM DataEvolve

 模型训练 数据工程 成本优化 贝叶斯方法 模型开发

原文：https://mp.weixin.qq.com/s/fyS_AzoKoDuiwIIk0HbaWQ
用途

在语言或领域特化模型开发中，分别训练并保存各数据分布向量，再用OptiMer低成本搜索目标任务的合并权重，以替代反复调整数据配比并重训。

启示

持续预训练的参数变化轨迹近似线性，使向量权重可充当有效训练量的代理，从而将数据配比选择与昂贵的模型训练解耦。

📄 详细内容
  • 问题：持续预训练前必须确定各数据集配比，但配比效果只能在训练完成后验证，调整一次通常就要重新训练。
  • 旧法为何失效：传统数据混合将配比选择与完整训练绑定，单个配比需129.3小时，难以低成本试错或快速适配新任务。
  • 方法：OptiMer分别在各类数据上持续预训练，以训练后参数减去基座参数得到分布向量，再结合指令遵循向量，通过贝叶斯优化搜索最优合并权重；每次尝试仅需模型合并与评估。
  • 实验：在C-Eval、Japanese Leaderboard、MMLU、GSM8K和HumanEval等基准上平均得分70.37，超过数据混合训练的63.71；100次配比搜索仅需8.5小时，实现15～35倍加速。用于Gemma-SEA-LION-v4-27B时，日语得分由66.34升至74.40，并保持东南亚语言能力。
  • 局限与后续：实验仅覆盖持续预训练；负权重是否对应选择性遗忘尚未验证，未来计划扩展至后训练数据配比优化。
