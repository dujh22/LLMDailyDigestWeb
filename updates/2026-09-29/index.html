PhysicalRSI 1.0：具身智能递归自我改进基线登顶RoboDojo

港大MMLAB提出PhysicalRSI 1.0，通过协同演化规划、执行与Harness，在RoboDojo上以较低Token成本取得榜首成绩。

子主题：递归自我改进 具身智能之心  Awesome-RSI HarnessEvolve

 递归自我改进 具身智能 智能体脚手架演化 模型评估 长程任务

原文：https://mp.weixin.qq.com/s/niXIBI3OIQc2UvuDZ0J8-Q

PhysicalRSI 1.0采用System 1–2协同自进化机制，由System 2分析任务与失败原因并改进System 1的动作程序、工具、记忆和技能。其Embodied Self-Harness允许父代依据录像、动作记录和评估反馈生成多个子代，再由物理环境按任务奖励或成功率选择可继承版本。报道称，该系统在RoboDojo的42项任务上取得36.27分和31.38%平均成功率，超过GPT-6 Astra的28.97分和22.48%。文章还称其完整评测Token成本约为GPT-6 Astra的百分之一，并在插钥匙、插管等精密操作任务上取得明显提升。

用途与启示
  • 为具身智能中的递归自我改进提供可复现的基础框架，将规划、执行技能、记忆和Harness统一纳入演化范围。
  • 展示如何把单次失败分析固化为可继承的代码与配置，而非仅依赖上下文中的临时反思。
  • 为具身自进化评测提供版本、交互轨迹、环境选择和能力增益之间的可追溯范式。
  • 说明通用模型与专用动作工具的系统级编排，可能比单独扩大模型调用规模更具成本效益。

AgentWorld：评测多智能体长程协作能力

AgentWorld 通过 MMORPG 沙盒中的长程团队任务及因果协作指标，评测多智能体在非对称角色分工、资源交接、持续沟通和共享计划维护方面的能力。

子主题：智能体评测 Datawhale  SwarmEvolve

 多智能体系统 智能体评估 多智能体协作 长程任务 过程评估 任务规划

论文：https://arxiv.org/abs/2609.31590
代码：https://github.com/openagents-org/agentworld
数据集：https://github.com/openagents-org/agentworld
原文：https://mp.weixin.qq.com/s/hOzjqSrWmNa0-MDE9RbTAA

AgentWorld 提供 100 个人工设计任务和 100 个增强变体，每项任务通常跨越 50 轮以上交互，需要 3 至 20 个具有非对称角色与能力的智能体协作完成采集、制作、资源分配或战斗目标。基准采用黑箱设置，各智能体独立行动且无法访问其他成员的内部状态，并通过高层工具执行基础操作、依靠程序化规则验证结果，重点考察任务依赖、联合规划、信息传递和长程协调。Gemini 3 Flash、Claude Haiku 4.5、GPT-5 Mini 和 DeepSeek R1-70B 在主任务上的成功率分别为 52.0%、45.0%、36.0% 和 20.0%，说明较强的个体能力不会自然转化为可靠的团队协作。主要失败模式包括通信中断、角色混淆以及跨轮次共享计划失效。论文还提出基于因果依赖追溯的 Causal Collaboration Effectiveness（CCE），衡量真正促成任务完成的动作与消息比例，但其因果贡献判断仍主要依赖 LLM 辅助分析。

用途与启示
  • 为长程、多角色、非对称能力条件下的多智能体系统提供可执行、可观察且可比较的协作评测环境。
  • 提醒开发者同时评估个体模型能力与团队组织能力，不能仅凭通信量或个体基准成绩推断协作效果。
  • 可用于比较不同基础模型、协作脚手架，以及并行分工、集中协调和持续相互适应等编排方式。
  • CCE 可补充任务成功率，帮助识别有效交接、无效行动、重复劳动、协作瓶颈及成员的实际贡献，但应与时间和成本等指标联合使用。
  • 失败模式表明多智能体框架需要加强共享状态维护、角色约束、通信协议和跨轮计划恢复能力，并可将团队结果与过程反馈用于训练和系统迭代。

多智能体提出C-HD最短路径算法并完成Lean验证

Vals AI称10个Claude Opus 5.5智能体在15小时协作中提出渐近复杂度优于特定稀疏图区间Dijkstra算法的C-HD方案并通过Lean验证，但工程实测仍显著更慢。

子主题：形式化证明 新智元  LogicEvolve

 自动化科学研究 多智能体系统 形式化验证 算法创新 科学发现

原文：https://mp.weixin.qq.com/s/XD7K50diurlB9z1rcHythw

Vals AI让10个Claude Opus 5.5智能体在共享留言板中自治分工、相互质疑并记录失败路线，15小时内进行了733次讨论。智能体提出了基于局部有界搜索、枢轴和递归分解的C-HD最短路径算法，宣称其在特定稀疏图密度范围内实现了对Dijkstra算法的渐近复杂度改进。团队生成了289个Lean文件，对算法正确性和复杂度上界进行形式化证明，并称证明通过Lean Kernel验证。后续C语言实现显示，受预处理、标签处理和内存调度等巨大常数开销影响，C-HD实际运行比Dijkstra慢约1.4至2.8倍，也比DMMSY算法慢约1.8至2.9倍。

用途与启示
  • 展示多智能体协作、独立同行评审与形式化验证结合后，可用于高难度算法发现和理论研究。
  • 说明渐近复杂度突破不等于工程性能提升，算法评估还需覆盖常数项、内存开销和真实规模基准。
  • 可作为LogicEvolve研究中“提出猜想—协作推导—Lean证明—工程复现”的闭环案例。
  • 提醒对重大AI科研突破同时开展证明审计、代码复现和实证性能验证。

FuseReg：正则化层融合缩小表征自编码器的重建—生成差距

FuseReg通过随机采样视觉编码器层子集进行训练，降低下游模型对跨层特征差异的敏感性，同时改善表征自编码器的图像重建与生成质量。

子主题：图像生成 Hugging Face Papers 

 视觉生成 视觉表征学习 扩散模型 模型训练

论文：https://arxiv.org/abs/2609.31620

FuseReg针对表征自编码器中浅层特征利于像素重建、深层特征利于生成质量的矛盾，以随机编码器层子集训练替代固定启发式层融合。理论分析表明，子集采样会显式惩罚模型对跨层特征分歧的敏感性，从而提升层融合鲁棒性。在ImageNet-256和DINOv3-L上，同一个解码器无需重训即可处理完整、稀疏及单层融合，并取得高于固定融合专用解码器的PSNR。仅替换RAEv2 DiT-XL的解码器即可将无引导gFID降低27%，同时正则化解码与扩散训练阶段则使DiT-Base的无引导gFID降低29%。

用途与启示
  • 为表征自编码器提供无需修改预训练视觉编码器的层融合训练方案。
  • 说明随机子集训练可作为跨层特征鲁棒性的正则化机制，减少固定层选择带来的阶段耦合。
  • 支持单一解码器适配多种层融合配置，有助于降低模型适配与重复训练成本。
  • 为统一优化图像重建质量和扩散生成质量提供可迁移的方法思路。

解耦量化：分别优化 LLM 预填充与解码

解耦量化（DQ）针对预填充与解码阶段分别配置计算格式、权重和存储位置，在保持低比特模型精度的同时提升首词生成速度。

子主题：模型轻量化 Hugging Face Papers 

 系统优化 成本优化 模型开发 长上下文 推理加速

论文：https://arxiv.org/abs/2609.26333

论文指出，LLM 预填充更受益于低精度算术，而解码更依赖紧凑权重以减少内存传输，因此提出分阶段专门优化的解耦量化方案。实验表明，仅在解码阶段移除激活量化，可在不增加推理成本的情况下改善解码密集型任务精度；独立训练计算原生的预填充权重，则可兼顾提示处理速度与低比特解码精度。针对 Qwen3.8-27B 的 1-bit 解码器，NVFP4 预填充器令 MMLU-Pro 和 MMMU-Pro 准确率分别提升 32.5 与 35.3 个百分点，且无需修改解码检查点。为在单设备容纳额外检查点，作者提出从 SSD 流式加载权重的 ODP，在 8K 提示长度下通过 llama.cpp 获得 1.78 倍首词延迟加速，并在 vLLM 及最高 2.8T 参数模型上验证方案。

用途与启示
  • 为预填充和解码采用不同量化策略，避免统一量化格式造成速度与精度之间的不必要折中。
  • 可通过替换或新增预填充检查点增强既有超低比特解码器，而不必重新训练或修改解码权重。
  • SSD 权重流式加载为单卡部署双检查点提供了可行路径，尤其适合长提示和首词延迟敏感场景。
  • 为 vLLM、llama.cpp 等推理系统设计阶段感知的量化与权重调度机制提供参考。

PISA：对数线性复杂度的块稀疏注意力

PISA通过金字塔式Top-K分层路由将块稀疏注意力的选择复杂度降至O(N log N)，并以硬件感知Triton内核兼顾训练与推理效率。

子主题：系统优化 Hugging Face Papers 

 长上下文 系统优化 稀疏注意力 推理加速 模型开发

论文：https://arxiv.org/abs/2609.31093

PISA针对传统块稀疏注意力仍需为全部查询—块组合打分、选择阶段保持二次复杂度的问题，提出由粗到细的金字塔Top-K策略。方法通过池化构建O(log N)层键表示，从最粗层开始，在每层使用LogSumExp对有界候选集合评分并逐步细化。其总体注意力选择复杂度为O(N log N)，且无需显式物化完整的查询—键分数矩阵。作者还实现了面向硬件的Triton训练与推理内核，将分层路由和LogSumExp评分融合；实验显示，该方法在常识推理上保持与基线相当的表现，并在检索任务上取得更好结果。

用途与启示
  • 为长上下文语言模型提供比二次自注意力更具扩展性的块稀疏注意力方案。
  • 表明稀疏注意力的关键瓶颈不仅是注意力计算，还包括稀疏块的选择与路由成本。
  • 金字塔式粗到细候选筛选可用于其他大规模检索、路由和近似Top-K计算场景。
  • 融合式Triton内核说明算法复杂度优化需要与硬件执行和内存访问设计协同推进。

RSIAgent 是一个免训练的多智能体递归自我改进框架，由 curriculum、actor 和 verifier 三类智能体协同完成自主探索、任务执行、结果验证与记忆巩固。框架采用 broad-then-deep 策略：BRS 并行覆盖多方向经验，DRS 顺序探索困难案例、隐藏约束与因果依赖。其持久记忆不只是保存成功轨迹，而是通过经验蒸馏与冲突调和，形成包含适用条件、动作后果和不确定性的可复用因果知识。探索结束后记忆被冻结，在模型参数不更新且无人工监督、gold label 或额外训练数据的条件下用于下游任务，并在 OSWorld 2.0、Agents’ Last Exam 和 GameCraft-Bench 上表现出竞争力与迁移性。

用途与启示

  • broad-then-deep 探索可作为新环境冷启动方案，先建立广泛认知，再针对失败模式、边界条件和隐藏约束深入测试。
  • 独立 verifier 与环境反馈 grounding 能减少执行者自我确认，并避免未经验证的经验污染长期记忆。

RayOrch：血缘可控的多粒度基础模型数据流引擎

RayOrch通过显式维护父子血缘、顺序与终止状态，实现异构文档和视频数据准备流水线的跨父项动态批处理与高效分布式执行。

子主题：系统优化 Hugging Face Papers 

 数据工程 系统优化 模型训练 多模态 状态追踪

论文：https://arxiv.org/abs/2609.18703
代码：https://github.com/OpenDCAI/RayOrch
  • RayOrch面向基础模型数据准备，将异构文档和视频转换为结构化记录，并支持有序、输入相关且子项数量可变的数据展开与聚合。
  • 编译器负责校验展开与聚合操作的匹配关系，运行时持续记录子项归属、直接父项、不可变序号及终止状态，从而避免应用自行维护血缘和重组逻辑。
  • Per-Call FIFO Ready Queue可跨父项批量调度就绪子项；聚合阶段依据声明的成员关系和序号恢复结果，不依赖批次边界或任务完成顺序。
  • 在NVIDIA H20 GPU上，MinerU从4卡扩展至64卡获得15.14倍加速，视频流水线从8卡扩展至64卡获得7.82倍加速，并在多项任务中优于Ray Data和Daft。
用途与启示
  • 为大规模基础模型预训练及多模态数据清洗提供保留数据血缘的分布式执行方案。
  • 适合处理单个父样本产生长尾数量子任务的文档解析、视频切分和特征提取流水线。
  • 父项级类型化故障可抑制同一父项尚未派发的兄弟任务，同时允许无关父项继续运行，有助于提升容错隔离能力。
  • 显式的顺序、完成状态和结果路由机制可降低数据工程代码复杂度，并增强流水线的可追踪性与可复现性。
