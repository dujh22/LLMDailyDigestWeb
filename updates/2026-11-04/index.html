CUA-Master：开放世界双循环递归改进计算机使用智能体

CUA-Master通过开放世界数据与模型弱点驱动的嵌套双循环框架，持续合成可验证任务并递归提升计算机使用智能体的能力。

 递归自我改进 图形用户界面智能体 智能体 数据合成 长程任务

论文：https://arxiv.org/abs/2611.03126

CUA-Master提出嵌套式双循环递归改进框架，外循环构建“世界—数据—模型”飞轮，根据持续暴露的模型弱点指导后续数据构造与优化。内循环从教学视频中挖掘真实工作流，并通过视觉—语义双路径重建交互轨迹，再将种子任务转化为可复用原语，以可控方式合成多样、复杂且可验证的任务。框架还引入反馈引导的快照—回滚—重试机制，以提高真实环境中轨迹采集的效率与可靠性。CUA-Master-27B在OSWorld Verified、OSWorld 2.0、WeaveBench和Agents’ Last Exam上分别取得80.2、36.9、43.9和25.0分，并在多轮递归迭代中持续提升。

用途与启示
  • 为计算机使用智能体建立由开放世界数据驱动的持续能力扩展路径，缓解仅依赖自生成经验导致的收益递减。
  • 可借鉴“模型弱点发现—数据构造—训练优化—重新评测”的外循环，搭建闭环自进化系统。
  • 利用真实工作流种子、任务原语和可验证合成机制，提高GUI与CLI混合任务数据的多样性和可控性。
  • 快照回滚与反馈重试机制可用于降低真实环境轨迹采集失败的成本，并增强长程任务执行可靠性。

美团发布原生多模态模型 LongCat-2.5

美团发布总参数 1.6 万亿、激活参数 480 亿的 LongCat-2.5，面向长程智能体任务，以原生多模态训练、真实代码环境强化学习和国产 AI 加速卡全栈优化为主要特点。

★ 3 子主题：模型发布 AGI Bar  NewModel

 模型开发 多模态 长程任务 强化学习 系统优化

原文：https://mp.weixin.qq.com/s/cyKRPZLWKADHcA-xlqH5fQ

LongCat-2.5 总参数为 1.6 万亿、激活参数为 480 亿，支持 1M token 上下文和单次最多 128K token 输出，重点提升长程智能体任务能力。模型从训练初期便将图片离散化为多层视觉 token，与文本 token 放入统一序列进行原生多模态学习，可用于看图编程、视觉验证、3D 交互内容生成和办公分析。其强化学习任务来自公开仓库及美团内部的真实 PR、issue 和智能体失败轨迹，并通过 Trajectory2Task 将失败记录还原为可复现、可判分的训练任务。训练和推理全程运行于国产 AI 加速卡，超节点并行使长上下文微调的单卡吞吐较 DDP 基线提升 86%，W4A4 推理则令 prefill 与 decode 吞吐分别提升 43.3% 和 42.77%。

用途与启示
  • 为长程代码开发、终端操作和跨软件办公自动化提供新的基础模型选择。
  • 展示了将真实仓库任务及失败轨迹转化为可验证强化学习环境的训练路径，可用于构建更贴近实际工作的智能体数据闭环。
  • 原生统一视觉 token 与文本 token 的设计有助于实现“生成代码—查看效果—继续修正”的多模态执行闭环。
  • 国产加速卡上的超节点并行与 W4A4 量化实践，为万亿参数、百万上下文模型的自主可控训练和低成本推理提供工程参考。

Group-Evolving Agents：经验共享驱动的开放式群体自进化

GEA 将进化单位从单个智能体扩展为智能体群组，通过共享执行轨迹、工具与框架改进经验，显著提升编码智能体的持续演化能力。

 自演化 多智能体系统 经验复用 智能体 人工智能辅助编程

论文：https://arxiv.org/abs/2602.04837

GEA 以智能体群组代替孤立个体作为基本进化单位，利用档案库和兼顾任务成功率与新颖度的选择机制组建父代。父代智能体汇总代码修改、预测补丁、工具调用日志及评估结果，形成共享经验池，再通过反思与进化模块生成框架级补丁。该方法在 SWE-bench Verified 和 Polyglot 上分别达到 71.0% 和 88.3%，显著超过同规模 DGM 基线的 56.7% 和 68.3%。实验还表明，群体共享能够保留不同分支发现的工具创新，提升跨模型迁移能力和框架缺陷修复效率，但带来较高计算成本及可解释性、对齐风险。

用途与启示
  • 为开放式智能体演化提供群体级经验复用机制，缓解树状进化中的分支隔离和创新丢失问题。
  • 表明性能与新颖度联合选择可以将探索多样性转化为可累积的工具和工作流资产。
  • 可用于自动演化编码智能体的工具链、提示策略和执行框架，并增强跨基础模型迁移能力。
  • 提醒实际部署需控制高额评测成本，并加强对自动生成补丁的审计、解释和安全验证。

清华大学与加州大学伯克利分校推出模块化、跨环境统一且支持后续训练的 uni-robot-agent，使开放权重模型无需特权输入即可低成本操作仿真及真实机器人，并为具身智能体评测、训练与持续学习建立工程底座。

uni-robot-agent 统一了仿真与真机环境中的感知、运动、技能和 episode 控制工具，通过环境适配器兼容不同机器人平台，并支持替换智能体运行时、上下文策略、感知后端与动作模型。开箱即用的 Qwen3.8-Flash-Next 在 RoboDojo 上取得 31.39 分，超过已公布的 Astra-RoboProbe 结果 28.97 分及多种 VLA/WAM 基线，调用成本约为 Astra 的 6.6%。在包含 19 项任务的 RealEval 真机评测中，零样本 Qwen 展现出有竞争力的操作能力，并超过经过环境微调的 π0.5。跨模型分析、消融与轨迹研究表明，相机标定、跨视角定位、空间几何计算和具身推理是有效机器人操作的关键通用能力，且系统整体并不过度依赖预置技能库。

RSI 系统优化 Agent 的 Reward Hacking 与验证边界

文章指出系统优化 Agent 会在迭代搜索和选择压力下持续放大评估指标与真实目标的偏差，因此验证强度必须随搜索预算同步增长。

  • 系统优化中的 Reward Hacking 主要表现为语义 hacking、测量 hacking 和评估 hacking，分别利用测试覆盖不足、异步计时缺口以及判分逻辑或评测上下文漏洞。
  • Agent 优化循环把分数作为唯一反馈，并持续保留高分候选，使评分器的微小偏差在选择压力下复利放大；扩大搜索预算也会提高发现评测捷径的概率。

  • 为系统优化 Agent 和 RSI 闭环设计防 Reward Hacking 的评测与验收机制。
  • 将验证预算与搜索深度绑定，避免新增计算预算系统性流向评测捷径。
  • 通过评估器隔离、隐藏测试、缓存状态控制和端到端复测提升性能结论的可信度。
  • 提醒强化学习与自进化系统避免把早期 rollout 中的违规捷径固化进模型参数。

AutoSFT：多智能体自动配置 SFT 训练数据

AutoSFT 通过多智能体研究闭环自动分析、修复、合成和编排 SFT 数据，在指令遵循基准上优于单智能体的数据配比搜索。

★ 3 子主题：数据策展 微信公众号  DataEvolve SwarmEvolve AgentEvolve

 数据工程 多智能体系统 模型训练 数据合成 长程任务

论文：https://arxiv.org/abs/2610.22194v1
代码：https://github.com/Thinking-Space/AutoSFT
原文：https://mp.weixin.qq.com/s/R4aSMuw8wi7GAaWzF-dLUw?scene=1
