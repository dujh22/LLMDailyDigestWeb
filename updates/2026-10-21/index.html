Self-HPO：框架与策略协同优化的自进化编码智能体

Self-HPO通过交替优化智能体交互框架与策略模型，针对持续变化的失败模式递归提升编码能力与可靠性。

★ 3 子主题：脚手架优化 Hugging Face Papers  HarnessEvolve AgentTrainEvolve CodeEvolve SystemEvolve

 智能体脚手架演化 策略优化 强化学习 递归自我改进 人工智能辅助编程

论文：https://arxiv.org/abs/2610.22791

Self-HPO将编码智能体的交互框架与策略视为相互影响的组件，避免仅优化其中一方导致能力错配。每轮中，当前策略先分析自身失败并提出候选框架，再在选定框架下通过强化学习更新策略，训练中发现的困难任务则进入下一轮框架搜索集。在三个编码基准上，该方法将Qwen3.5-35B-A3B的平均问题解决率从57.8%提高至64.8%，并能泛化到分布外场景。框架和策略单独替换时均保留收益，而联合优化的增益超过二者独立增益之和，同时改善Pass@1可靠性与Pass@k能力上限。

用途与启示
  • 为编码智能体提供框架—策略闭环协同演化方案，使交互机制持续适配策略模型的新失败模式。
  • 表明困难任务可作为连接策略训练与下一轮框架搜索的反馈信号，形成递归自我改进循环。
  • 联合优化产生超加性收益，说明智能体能力提升不应只依赖底层策略训练，还需同步演化执行脚手架。
  • 可引入更强外部模型作为框架提议器，在保留整体流程的同时进一步提高性能。

EdgeRock-4B：固定内存长推理，KV Cache削减99.1%

EdgeRock-4B通过记忆岩锚机制将长上下文历史状态保持在固定容量，在256K上下文下削减99.1%的KV Cache，并实现单卡最高6.42倍吞吐提升。

★ 3 子主题：缓存优化 量子位  CacheEvolve NewModel

 缓存优化 长上下文 推理加速 系统优化 多模态

代码：https://github.com/rockmatrix-ai/EdgeRock
原文：https://mp.weixin.qq.com/s/XlGTNPhtP88uAL5srNtoxQ

EdgeRock-4B基于Qwen3.5-4B转换而来，以滑动窗口注意力和记忆岩锚（RMA）替换全注意力，无需从头预训练。RMA将历史划分为循环状态、最近1024个词元的局部窗口和固定容量锚点库，只保留远程历史中评分最高的关键信息，使注意力KV固定为72 MiB。模型在256K上下文下较源模型减少99.1%的KV Cache，并在单张80GB Hopper GPU上实现512路并发和12124 tokens/s输出吞吐。其AIME 2024—2026平均一次通过率为82.9%，同时支持文本与图像推理，消融实验也显示RMA是远距离信息回忆的关键。

用途与启示
  • 为长推理和长程智能体提供可预测的固定内存预算，避免上下文增长导致显存持续膨胀。
  • 提升单卡并发量与解码吞吐，降低长上下文推理的单位词元成本。
  • 为端侧设备、机器人和专用芯片上的持续推理提供固定状态存储方案。
  • 展示了从现有Transformer模型转换为有界状态架构、同时保留推理与多模态能力的可行路径。

OpenVLHarness：以多模态记忆增强真实世界视觉智能体工具使用

OpenVLHarness通过统一工具能力层、证据渲染与持久化多模态记忆，使视觉智能体能够迭代获取、保存并组合真实世界证据，同时提升任务表现并降低推理成本。

 工具调用 多模态 智能体记忆 智能体 视觉推理

论文：https://arxiv.org/abs/2610.26860

OpenVLHarness面向仅靠内部推理难以解决的视觉任务，引入由能力层和持久化多模态记忆组成的推理脚手架。能力层统一封装异构工具，并将工具结果渲染为智能体可解释的观察信息；记忆模块则将图像、结构化数据和网页引用保存为可寻址对象。系统还提供代码接口，可针对已存储数据执行程序，从而组合多个工具产生的证据。在22个基准和8种开放或闭源骨干上的实验显示，该框架较无工具基线平均提升9.7至12.6分，并在部分设置下以不超过对照方案37%的模型词元成本获得更高成绩。

用途与启示
  • 说明单纯增加推理预算对依赖外部证据的视觉任务收益有限，工具增强与证据持久化更为关键。
  • 为视觉智能体设计提供“统一工具接口—证据渲染—多模态记忆—程序化组合”的模块化架构参考。
  • 表明可寻址的多模态记忆能够支持跨步骤证据复用，减少重复调用工具及上下文信息丢失。
  • 展示智能体脚手架可同时改善任务准确率与词元成本效率，适用于真实世界视觉分析工作流。

OR-License：现实世界运筹学智能体评测基准

OR-License 通过真实商业项目材料、客户模拟器和隐藏验证机制，端到端评估 LLM 智能体完成专业运筹学任务的可行性、解质量与信息获取能力。

★ 2 子主题：智能体评测 Hugging Face Papers  EvalEvolve HarnessEvolve NewApply

 智能体评估 真实世界基准测试 长程任务 执行验证 智能体

论文：https://arxiv.org/abs/2610.24087

OR-License 收录31个来自10类工业场景的实例，源自总价值368万美元的付费运筹学项目，并在去标识化后保留原始需求、数据、交付格式和信息边界。配套的 ORSim 客户模拟器仅按交互披露业务事实，不直接提供运筹学知识，用于考察智能体持续发现并弥合信息缺口的能力。隐藏评估既检查交付方案的可行性，也将目标质量与客户实际接受的专家方案比较；DAQ 指标会将不可行交付计为零。在11个前沿模型的代码智能体配置中，部分模型在条件目标质量上超过专家参考，但没有模型达到专家级 DAQ；最强 Claude Code 配置的严格可行率为88.39%，DAQ 为0.87，任务均衡后的研究链完成率仅为24%至45%。

用途与启示
  • 为评估智能体能否从原始客户材料直接完成需求澄清、数学建模、实现和验证提供现实世界基准。
