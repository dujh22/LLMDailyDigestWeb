RSR：递归自我重写扩展复杂任务执行轨迹

RSR 将多种专用脚手架发现的成功经验递归重写为通用脚手架下可复用的训练轨迹，显著提升模型在复杂终端与长程任务上的表现。

子主题：递归自我改进 Hugging Face Papers  HarnessEvolve EvolveLLM

 递归自我改进 模型训练 智能体脚手架 长程任务 执行轨迹

论文：https://arxiv.org/abs/2610.02826

论文提出 Recursive Self-Rewrite（RSR），使用同一个 Qwen-3.8-27B 模型在多种脚手架下发现解法，再将其重构为通用脚手架可执行的训练轨迹。系统由规划器、批评器和执行器组成：规划器将过程提炼为 runbook，批评器检查验证器或答案泄漏并驱动递归修订，执行器则在全新沙箱中验证合格方案。三个脚手架在约 3,000 个自策展终端任务中共同解决 759 个任务，比记录池中最强的单一脚手架多 34.3%，并将 2,001 条成功源轨迹扩展为 11,094 条重写轨迹。使用这些轨迹进行监督微调后，模型在 Terminal-Bench 2、Terminal-Bench 4、Terminal-Bench Hard 和 Software Terminal-Bench 上均优于基础模型及直接轨迹 SFT，长程任务的过程奖励也由 0.21 提升至 0.29。

用途与启示
  • 将部署时不可用的专用脚手架能力转化为基础模型在通用脚手架下可直接复用的能力。
  • 为复杂任务提供一种兼顾轨迹扩增、泄漏审查和沙箱复验的数据合成流程。
  • 表明多脚手架产生的异质经验经过递归重写后，比直接使用原始成功轨迹进行监督微调更有效。
  • 可用于构建终端智能体、软件工程智能体及其他长程任务智能体的高质量训练数据。

SAGE以结构信号纠正长程推理偏差

SAGE通过代数稀疏化与双曲结构引导缓解长程推理中的探索和累积偏差，使Qwen3在Andrews–Curtis任务上的Lean验证通过率提升至基础模型近8倍。

SAGE首先利用符号闭包分析（SCA）解释长程推理中的两类失效：可行分支占比随深度快速缩小造成探索偏差，稀疏终点奖励与KL约束则使早期错误持续累积。方法通过代数稀疏化衡量候选操作对未解决残差的解释能力，并以双曲空间中的状态—目标距离为推理前缀提供逐步结构反馈。训练时，两类势函数用于软重排候选步骤和计算组相对优势；训练完成后无需额外结构评分或在线搜索。实验覆盖12个基准和7个模型家族，SAGE总体优于多种后训练基线，并在AC长程任务上显著提高路径求解率及Lean形式化验证通过率。

  • 可将形式化验证通过率与局部操作有效率结合，用于区分“步骤合法”和“全局成功”。
  • 启示后续研究为自然语言和开放任务设计可靠的残差表示、目标锚点及结构势函数。

自生成反馈破坏测试时训练的长期稳定性

研究通过长达 128K token 的实验与因果分解发现，模型基于自身生成文本持续更新会形成闭环退化，而在提交更新前用独立真实文本验证可基本消除损害。

子主题：测试时训练 Hugging Face Papers 

 模型训练 持续学习 人工智能可靠性 执行验证 长上下文

论文：https://arxiv.org/abs/2610.05076

论文研究模型在推理期间将信息写入权重的测试时训练，并发现保留自生成文本带来的更新会降低模型对独立人类文本的预测能力，该现象横跨 125M、760M、3B 配置及 Qwen3-4B。固定生成模型后，125M 和 760M 配置中超过 98% 的损害被消除，表明关键问题是生成器与学习器相互影响形成的闭环反馈，而非写入权重本身。Recorded Replay 与单步配对实验进一步显示，模型在更好拟合当前生成样本的同时，会恶化对新真实文本的预测，且少数异常轨迹贡献了大部分严重失效。Settlement 方法在提交候选状态前使用独立真实文本评估，将两个模型的平均终点差距压至 0.07 和 -0.02 nats，同时保留了真实文本适应收益。

用途与启示
  • 为长时程测试时训练揭示“自生成数据—参数更新—后续生成退化”的因果反馈链。
  • 说明评估在线适应算法时，应同时测量源样本拟合效果与独立真实数据上的泛化变化。
  • 可将独立证据验证与有条件提交机制加入持续学习系统，阻止有害更新被永久写入模型。
  • 提醒实际部署关注少数高损害轨迹，并设置更新拒绝、回滚或状态隔离机制。

AutoSciBench：自主生成并迭代适配科学智能体评测基准

AutoSciBench通过分析智能体求解轨迹与评判反馈，自动生成并持续改进科学任务，使评测难度能够随智能体能力演进。

 智能体评估 动态基准测试 科学研究基准 任务生成 自动化科学研究

论文：https://arxiv.org/abs/2610.05140

AutoSciBench将每项任务分解为描述科学领域、数据模态和推理方式的高层概念，以及规定问题、环境和标准答案构造与验证方法的底层配方。框架利用求解智能体的执行轨迹和评判反馈修改任务概念或配方，封堵解题捷径，并强化原始数据复查、中间结果解释和证据整合要求。它还会从既往任务的完整改进轨迹中蒸馏经验，用于指导新概念和后续基准任务的生成。实验覆盖计算生物学、材料科学和临床影像，生成基准相较人工基准分别将前两个领域的平均求解准确率降低22.4和25.5个百分点，同时在三个领域获得更高的平均质量评分。

用途与启示
  • 为快速饱和的科学智能体基准提供自动更新机制，使评测持续暴露模型的剩余失效模式。

  • 高层概念与底层配方的分层表示有助于复用任务构造经验，并扩展至新的科学领域和数据模态。
  • 可作为动态基准测试和评测智能体研究的基础框架，降低人工策题、验证与维护成本。

EVISKILL：以可回放证据驱动智能体技能演化

EVISKILL通过可回放证据卡、显式证据关联与定向重执行验证，使LLM智能体能够在不更新模型参数的情况下持续积累和修正可复用技能。

 技能演化 智能体 经验学习 持续学习 执行回放

EVISKILL面向LLM智能体的持续技能演化，将交互执行中的观察组织为可回放证据卡，并让每项技能编辑显式关联其支持情境。框架通过定向回放重新执行相关任务，验证编辑是否有效并为后续修正提供反馈。它跨轮次保留证据和已获局部支持的临时编辑，避免因全局验证失败而丢弃有价值的局部改进，同时由全局验证决定编辑是否最终固化到技能中。作者在三个交互式基准和六种LLM骨干模型上验证了该方法的有效性。

用途与启示
  • 为智能体技能库建立“修改—证据—验证结果”的可审计链路，提高技能演化的可信度。
  • 通过定向执行回放替代仅依赖全局得分的粗粒度判断，保留得到局部证据支持的有效修正。
  • 适用于无需更新模型参数的持续学习场景，可将长期交互经验沉淀为可复用的程序性知识。
  • 启示智能体演化系统将证据持久化、局部验证与最终技能固化解耦，以降低错误经验被永久写入的风险。

NAT-ARC：自然图像预训练迁移至ARC视觉推理

何恺明团队提出纯视觉ARC求解方案NAT-ARC，将ImageNet上的MAE预训练视觉先验迁移至抽象格子推理，集成模型在ARC-1上取得70.2%的pass@2。

子主题：视觉推理 量子位  LogicEvolve

 视觉推理 推理 模型训练 跨域泛化 测试时计算

原文：https://mp.weixin.qq.com/s/IQH3easn93wPN_cXtbUzMw

NAT-ARC在VARC视觉编解码流程前引入ImageNet MAE预训练，并在ARC离线训练后针对每道测试题使用少量示例进行LoRA微调。自然图像预训练赋予模型前景分离、对象匹配和连通区域识别等视觉先验，使其能够迁移到match-and-copy与connected-component reasoning等抽象任务。最佳0.6B单模型在ARC-1上达到63.4%的pass@2，融合不同预训练策略后达到70.2%，接近8B专用语言模型系统的71.6%。实验还表明，预训练缓解了小数据条件下大模型的过拟合，使模型从base到huge规模呈现稳定的性能增长。

用途与启示

Pivot-SD：掩码扩散语言模型的高效自蒸馏 Hugging Face Papers · 自蒸馏 · 论文 Pivot-SD以信息增益识别掩码扩散语言模型去噪过程中的高影响力关键提交，并通过成功轨迹正向监督与失败轨迹定向抑制实现高效离线自蒸馏。

子主题：自蒸馏 Hugging Face Papers 

 模型蒸馏 模型训练 信用分配 推理 数据合成

论文：https://arxiv.org/abs/2610.03665

Pivot-SD针对掩码扩散语言模型的信用分配难题，不再监督完整输出或对整个去噪步骤统一分配奖励，而是聚焦显著影响后续生成的关键词元提交（pivot）。该方法以剩余掩码位置的不确定性下降衡量信息增益，据此自动选择高影响力 pivot。对于成功轨迹，框架使用交叉熵强化这些提交；对于失败轨迹，则采用定向 unlikelihood 抑制错误 pivot，同时不改动失败轨迹的其余部分。实验仅使用200个问题、每题4次 rollout，便使 LLaDA-8B-Instruct 在数学与代码基准上优于全序列 SFT 和同预算的扩散强化学习基线。

用途与启示
  • 为掩码扩散语言模型提供细粒度信用分配方案，将训练资源集中于真正改变生成走向的词元决策。
  • 展示信息增益可作为筛选高价值训练信号的依据，减少对完整轨迹监督和大规模采样的依赖。
  • 成功与失败轨迹采用非对称学习目标，可在保留有效行为的同时精准抑制关键错误。
  • 适合用于低数据、低 rollout 预算下的数学推理与代码能力后训练。
