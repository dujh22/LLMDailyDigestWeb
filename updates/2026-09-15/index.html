同模型 Token 相差 70 倍：AI 编程智能体框架成本实测

三项基准测试显示，即使使用相同模型，智能体框架的启动开销、交互轮数及服务路径缓存命中率仍可造成数十倍的 Token 与成本差异。

子主题：智能体评测 InfoQ  Groom

 智能体评估 成本优化 智能体脚手架 人工智能辅助编程 缓存优化

原文：https://mp.weixin.qq.com/s/SS1oXvOdVaT3QPORdLtSAg

三项测试分别比较了多种 AI 编程智能体框架在 Python 任务、企业工作流和编码基准上的成本、Token 用量与成功率。6 月测试中，每项已解决任务约消耗 3500 至 29.2 万个 Token，框架启动税乘以运行轮数对总 Token 用量的解释度达到 R²=0.99。缓存命中率会显著改写成本排名，例如不同端点协议和网关路由可使缓存输入占比从约 1.5% 变化到 70% 以上。文章建议以“每个经验证成功结果的成本”为核心指标，同时检测真实服务路径的缓存比例、提示词传输保真度及静默截断问题。

用途与启示
  • 评估 AI 编程工具时，应同时控制模型与智能体框架变量，避免把框架开销误判为模型成本。
  • 优先测量系统提示词与工具说明产生的启动税、平均交互轮数及缓存命中率，这些指标可能比迁移模型更具优化价值。
  • 采购和平台选型应比较每个经验证成功任务的成本，而非孤立比较 Token 总量、标价或通过率。
  • 对长上下文场景进行实际字节传输和截断测试，防止框架静默丢弃输入却仍报告执行成功。

ActionSplice：交互式世界模型中的在线动作编辑

ActionSplice通过反事实状态传输在不回滚采样、不修改世界模型的情况下响应中途变更的动作，实现更连贯且高效的交互式视频生成。

子主题：世界模型 Hugging Face Papers 

 世界模型 视频生成 动态操控 推理加速

论文：https://arxiv.org/abs/2609.08230

ActionSplice面向分块自回归视频世界模型中动作只能在下一生成块生效的问题，将在线动作修改建模为反事实状态传输（CST）。其轻量级校正器把采样中断时的模型原生表示迁移至新动作在相同求解步骤下对应的状态，世界模型和采样器均保持冻结，且无需重放已完成的计算。CST-R会重定向整个活动视频块，CST-T则保留时间前缀、仅修改后缀，以兼顾历史连续性和动作响应。实验显示，该方法显著降低相对回滚结果的LPIPS，并相较等待下一视频块获得最高2.73倍的像素就绪速度提升。

用途与启示
  • 为低延迟、可实时操控的交互式视频世界模型提供无需重训的推理期动作编辑方案。
  • 反事实状态传输可作为通用中间状态修正机制，减少动作变更引发的回滚与重复计算。
  • 时间拼接策略适合需要保留既有生成前缀、仅重定向未来轨迹的游戏和仿真应用。
  • 该工作表明轻量校正器能够在冻结大型生成模型的前提下改善交互响应速度与视觉连续性。

文章将 RSI 定义为智能体利用任务轨迹与反馈更新自身状态，并让更新后的状态参与后续任务以提升未来表现，其更新既可由智能体自身执行，也可由 Teacher、Meta-Agent 或外部训练程序完成。现代智能体被抽象为 Agent = Model + Harness，进化对象可分为模型参数、上下文、长期记忆、Skill，以及工具和 Harness 代码。文章结合 SEAL、Prime Agent、ReasoningBank、TRACE、SkillSmith 等工作，比较知识内化、经验检索、技能维护与执行流程修改等不同路径的收益和代价。版本继承结构还可划分为链式、树形和图式进化：链式简单但容易累积错误，树形与图式能够扩大探索和复用多源经验，但会增加版本选择及评测成本。

  • 链、树、图三类谱系结构可用于分析系统的探索能力、错误恢复能力和评测开销。
  • 为设计自进化智能体提供启示：更新机制必须与验证、回滚和组件协同测试结合，避免错误经验或局部修改持续污染后续任务。

MetaRSI-v1：协同优化数据、模型与 Harness 的递归自我改进系统

MetaRSI-v1 通过 Data-RSI、Harness-RSI 和 Model-RSI 三类算子及分层动态调度机制，协同改进数据、执行脚手架与模型参数，在多项编程和推理基准上实现持续自我提升。

子主题：递归自我改进 智猩猩AI  Awesome-RSI DataEvolve EvolveLLM HarnessEvolve

 递归自我改进 智能体脚手架演化 数据合成 模型训练 策略优化

原文：https://mp.weixin.qq.com/s/HYFx2Vo0n1Uqkpd2eFE2VQ

MetaRSI-v1 将 AI 系统表示为数据、模型参数和 Harness 三类可修改状态，并以统一的 Observe、Diagnose、Propose、Validate、Execute、Select、Export 内核约束改进过程。Data-RSI 从执行轨迹中提取并验证训练数据，Harness-RSI 编辑提示词、记忆、工具、技能库和 MCP 资源，Model-RSI 则搜索受约束的 LoRA 训练配置，将能力内化到权重。RSI² Agent 动态选择算子及调用顺序，MetaRSI² Agent 再复盘并优化调度策略，同时通过封闭评估器、权限边界和学习信号失效规则防止奖励作弊与过期数据训练。基于 Qwen3.5-35B-A3B 的实验显示，系统在四项基准上平均提升 10.9 个百分点，较最强固定组合策略多提升 3.6 个百分点；仅使用 Data-RSI 与 Harness-RSI 的 API 路线也能让多个前沿模型实现自我提升。

用途与启示
  • 为递归自我改进提供统一的 Data—Model—Harness 系统视角，避免只优化单一层面造成局部最优。
  • 展示动态调度优于固定算子组合，说明不同失败模式需要匹配不同的改进路径。
  • 通过确定性验证、封闭评估器和权限隔离，为自修改系统建立可审计的安全边界。
  • 证明即使无法访问模型权重，也可借助数据合成与 Harness 演化在 API 模式下实现 RSI。
  • 揭示 Harness 上下文成本与模型训练成本之间的权衡，可用于决定能力应保留在运行时还是内化到权重。
