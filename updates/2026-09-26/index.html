WROP：在世界模型中训练物体恒存性

研究团队提出含150种认知任务的WROP数据基础设施，并训练16B参数世界模型PWM-WROP，以增强视频模型对物体恒存性与实体性的理解。

子主题：世界模型 Hugging Face Papers 

 世界模型 视频生成 模型训练 模型评估 人工智能

论文：https://arxiv.org/abs/2609.28654

研究提出WROP（World Reasoning with Object Permanence），围绕物体恒存性和实体性设计150种认知科学启发的任务，分为六类认知范畴。团队通过Blender生成器随机改变速度、光照、相机角度等干扰参数，同时保持任务的认知结构不变，每项任务生成超过1万条样本，最终形成150万样本的训练语料和包含300道题的考试集。研究评估了14个视频模型，覆盖参考图生成视频、视频编辑和视频续写三种类型，并训练了16B参数世界模型PWM-WROP。在盲测两两比较的Elo排名中，PWM-WROP位列视频续写模型第一、综合第三；团队还开放了数据、考试、模型答案、评分、权重及面向AWS Trainium2的原生PyTorch训练栈PWM。

用途与启示
  • 为物理常识和核心认知能力提供可控、规模化的世界模型训练数据生成方案。
  • 展示认知科学启发的数据设计能够显著增强视频模型的物体恒存性推理能力。
  • WROP考试可用于系统评估世界模型在遮挡、消失与重现等场景中的物理一致性。
  • Blender程序化生成与干扰因素随机化方法可借鉴到其他物理推理能力的数据合成中。

AEWM：面向 LLM 智能体的可编辑世界模型

AEWM 不再模拟高熵工具响应，而是通过动作判别与状态修订直接清理受污染的任务状态，从而提升 LLM 智能体的长程决策能力。

子主题：世界模型 Hugging Face Papers 

 智能体 世界模型 状态追踪 长程任务 执行反馈

论文：https://arxiv.org/abs/2609.28416

论文指出，传统语言世界模型侧重预测环境观察，但在能够获得真实执行反馈时，重建高熵且依赖执行的工具响应价值有限。作者提出 Agent-Editing World Model（AEWM），利用 Action Judge 将决策分为关键、探索和噪声三类，并通过 State Revision 编辑由噪声推理与动作造成的任务状态污染。基于 AEWM 的 EditAct 与真实环境执行结合，直接修改后续决策所依赖的状态，而非仅提供文字批评。AEWM 在动作判别基准上取得 70.5% macro-F1，并在六个基准、三个智能体骨干上带来平均 3.2～6.7 分的提升；基于验证轨迹的 AEWM-RFT 也较 Self-RFT 提升 2.2～2.6 分。

用途与启示
  • 为智能体世界建模提供新方向：重点建模推理和动作如何改变任务进展，而非复现可由环境直接返回的工具响应。
  • 可用于缓解长程任务中的错误假设、过期计划和噪声动作持续污染上下文的问题。
  • Action Judge 与 State Revision 可作为智能体运行时的状态维护模块，也可生成经过验证的轨迹用于离线微调。
  • 说明将真实执行反馈与可编辑任务状态结合，可能比单纯自我批评或观察预测更有效。

SAE 潜在空间中涌现的词性类别

研究发现，稀疏自编码器能以分布式、类别依赖的潜在特征组编码语言模型中的词性信息，而非形成词性与单一潜变量的一一对应。

子主题：稀疏自编码器 Hugging Face Papers 

 人工智能可解释性 表征探测 人工智能

论文：https://arxiv.org/abs/2609.29362

研究以词性类别为受控案例，考察稀疏自编码器（SAE）的潜在表示是否显露语言模型中的形态句法结构。实验显示，词性可以从 SAE 激活中被高度准确地恢复，但单个潜变量并不与单个词性类别形成一一对应。词性信息主要由紧凑的稀疏潜变量组共同承载，且开放词类与封闭词类、不同标签之间存在显著差异。相关特征组在留出数据上保持稳定，同时语义或语法相近的类别之间会共享部分潜变量，说明语法信息具有分布式和类别依赖的表征形式。

用途与启示
  • 为使用 SAE 解释语言模型内部语言学表征提供实证依据。
  • 提醒研究者避免将单一潜变量直接解释为原子化的语法概念，应分析潜变量群组及其重叠结构。
  • 可用于设计更可靠的形态句法表征探测方法，并区分结构编码与词汇记忆效应。
  • 为比较不同模型层、SAE 配置及语言之间的语法表征结构提供分析范式。

Qwen-Planner-Agent：真实世界移动规划智能体的闭环 AI-for-AI 框架

Qwen-Planner-Agent 以统一的动作—反馈—验证契约闭环连接数据生产、模型训练与部署，实现移动规划模型和智能体执行框架的协同迭代。

子主题：闭环自进化 Hugging Face Papers  DataEvolve EvolveLLM HarnessEvolve

 智能体 长程任务 模型训练 强化学习 模型与框架协同优化

论文：https://arxiv.org/abs/2609.29892

Qwen-Planner-Agent 面向真实设备上的复杂长程移动任务，提出可规模化开发和持续迭代的闭环 AI-for-AI 框架。数据环节通过人工把关的智能体数据飞轮，自动构造任务、采集交互轨迹、策展和平衡训练数据，并依据训练反馈调整后续数据生成。训练环节结合监督式规划冷启动与混合环境在线智能体强化学习，并提出 CARE 奖励和优势工程，在维持任务表现的同时降低推理及工具使用成本。部署环节以执行证据驱动记忆、技能、工具和子智能体编排，将结构化动作反馈及失败轨迹回流至模型与执行框架；该系统在 MobilePA-Bench 上取得最佳综合表现，并可迁移改善其他智能体基准。

用途与启示
  • 为真实世界长程移动智能体提供覆盖数据、训练和部署的闭环开发范式。
  • 说明统一的动作—反馈—验证契约可作为模型与执行框架协同演化的接口基础。
  • CARE 可用于优化在线强化学习中的能力匹配、奖励设计与优势估计，降低推理和工具调用开销。
  • 保留并回流失败轨迹有助于定位执行瓶颈，持续改进记忆、技能、工具及子智能体协调能力。

IterSynth：角色解耦的迭代式深度搜索智能体

IterSynth通过分离规划与证据综合角色、维护动态摘要状态并采用角色解耦策略优化，显著提升长程深度搜索智能体的性能。

子主题：深度研究智能体 Hugging Face Papers 

 智能体 深度研究 任务规划 强化学习 长程任务

论文：https://arxiv.org/abs/2609.29444

IterSynth将深度搜索拆分为Planner与Synthesizer两个角色，前者识别信息需求，后者把检索证据整合进持续演化的摘要状态。该范式以摘要而非完整搜索历史作为持久状态，从而缓解ReAct式智能体中的能力耦合与上下文噪声问题。训练方面，Role-Decoupled Policy Optimization（RDPO）结合终局结果奖励和逐轮量规评估，并为不同角色计算专属优势以改进信用分配。IterSynth-8B在BrowseComp、Xbench-DS等五个长程深度搜索基准上取得50.7的平均分，较此前最强的同规模智能体提升4.2个百分点，并能作为模型无关的提示范式为前沿闭源模型带来零样本增益。

用途与启示
  • 为深度搜索系统提供“规划—综合”职责分离的智能体架构，降低单一策略同时承担多项能力的训练难度。
  • 可用动态摘要替代不断累积的完整搜索轨迹，控制长程任务中的上下文长度与信息噪声。
  • RDPO展示了按角色进行优势估计和信用分配的训练思路，可推广至其他多阶段智能体工作流。
  • 该方法兼具训练框架与提示范式属性，适合用于改造现有ReAct式研究、检索和证据综合智能体。

 多模态 视觉表征学习 模型评估 数据策展

代码：https://github.com/ShaohuaDong2021/RGBD20K/

神经谱容量：无需训练的架构测量与设计

研究提出基于权重矩阵奇异值谱的神经谱容量（NSC），可仅凭网络规格评估容量，并在资源约束下快速搜索最优架构。

子主题：模型架构创新 Hugging Face Papers 

 模型开发 系统优化 成本优化 模型评估

论文：https://arxiv.org/abs/2609.23087

论文指出，参数量和 FLOPs 无法区分深宽比、注意力头及 FFN 分配不同但预算相同的网络架构。作者提出神经谱容量（NSC），利用随机初始化下的 Marchenko–Pastur 定律，从架构规格直接计算基于奇异值谱的容量标量，无需实例化模型、数据或梯度。NSC 的逐层可加结构支持动态规划求解器 NSC-DP，可在数秒内于 CPU 上找到资源约束下全局最大化 NSC 的架构。实验中，NSC 在七个 Transformer 与 CNN 家族的排序任务上优于参数量、FLOPs 及多种免训练代理指标，并能快速优化 Transformer-XL 架构及将 LLaMA-7B 剪枝至表现更优的 5.7B 配置。

用途与启示
