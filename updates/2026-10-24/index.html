OpenForge RL：Harness 原生智能体端到端训练框架

OpenForge RL 通过轻量代理与 Kubernetes 编排器解耦训练和推理，使不同 Harness 与环境中的智能体能够直接开展端到端强化学习训练。

原文：https://mp.weixin.qq.com/s/Vg2MV5ZBww7BXa3zVXEMBA

OpenForge RL 使用轻量代理拦截 Harness 的模型调用，将交互自动重建为轨迹，并转换为 veRL 等格式的强化学习样本。Kubernetes 编排器在隔离的云端容器中执行 Rollout，支持弹性扩缩容、资源解耦与超时控制；配套数据合成管线通过任务提议、质量剪枝、环境及验证脚本构建和测试修补循环生成可执行任务。实验覆盖 Claw 文本工具调用和浏览器、桌面 GUI 操作，表明单一 Harness 上的训练可向未见 Harness 泛化，并主要改善自我验证、工具覆盖与多步任务完成能力。OpenForge-Claw 与 OpenForge-GUI 在 ClawEval、OSWorld-Verified、Online-Mind2Web 等基准上优于同规模开放模型，但错误恢复仍是明显短板。

用途与启示
  • 无需为强化学习训练重写简化版 Harness，可降低训练系统与实际部署系统之间的行为偏差。
  • 轻量调用代理可将现有智能体运行轨迹直接转化为标准训练样本，便于接入不同强化学习后端。
  • 基于 Kubernetes 的隔离 Rollout 架构适合大规模并行训练，可缓解推理任务与训练节点之间的资源争用。
  • 数据合成与自动验证流程说明，数百至数千个高质量可执行任务也可能获得较强训练收益。
  • 后续可重点加强故障诊断、状态恢复和失败轨迹训练，以弥补智能体错误恢复能力不足。

HarnessPro：无标签多智能体进化将 Agent 成本降低 53%

清华大学与智谱 AI 团队开源 HarnessPro，通过无标签多智能体协同进化、合成测试与帕累托优化，在提升 Agent 任务通过率的同时将单任务成本最高降低 53%。

HarnessPro 由轨迹诊断、进化规划、代码编辑和测试合成四类 Agent 构成闭环，可依据执行轨迹自动修改并验证 Agent Harness，无需接触官方测试用例或标准答案。测试合成器根据任务描述生成可执行单元测试，使失败案例召回率从 41.7% 提升至 83.3%，缓解 LLM 裁判的乐观偏差。框架将任务性能与执行成本纳入帕累托优化，生成 Lite、Medium 和 Heavy 三档方案；在 SWE-Bench Pro 上，Medium 方案以 79.0% 通过率将单任务成本从 2.68 美元降至 1.26 美元，降幅达 53%。进化后的 Harness 自动形成动态推理路由、工具预算运行时钩子、前缀缓存保护和日志压缩等机制，并在 Terminal-Bench 2、SWE-Bench Pro 与 ProgramBench 上展现性能和成本优势。

用途与启示
  • 为无需官方标签的 Agent Harness 递归自我改进提供自动化方案。
  • 展示任务性能、Token 成本与运行延迟可通过多目标帕累托优化共同改进，而非以持续增加推理开销换取性能。
  • 以合成可执行测试替代单纯的 LLM 主观评判，为无标签环境中的候选验证提供更可靠的反馈信号。
  • 动态路由、工具预算钩子、缓存保护和日志压缩可作为生产级 Agent 控制推理成本与无效探索的通用设计。
  • Lite、Medium、Heavy 三档帕累托方案便于按部署预算和性能需求选择运行配置。
