Astar：从演化历史学习并指导 AI 系统闭环进化

阿里与浙江大学提出 Astar，通过学习代码提交、实验结果与业务反馈生成系统优化方案，并结合奖励模型、代码代理和结果回流构建 AI 系统持续进化闭环。

子主题：闭环自进化 机器之心  EvolveLRM

 自演化 模型训练 强化学习 数据工程 人工智能辅助编程 模型开发

论文：https://arxiv.org/abs/2608.27287
原文：https://mp.weixin.qq.com/s/NEI-_8GtynlYMM0_QN7xjw

Astar 将 AI 系统的历史版本、代码变更、损失曲线和业务指标转化为演化训练数据，通过实验版本两两配对扩充稀疏样本，并利用调用图、AST 与 LLM 语义分析过滤无效提交。系统以“主方向—细分模块—具体动作”的三级提示约束方案搜索空间，同时训练代理奖励模型，以秒级离线评分预测候选方案改善 loss 的概率，减少昂贵的真实实验。经过中期训练、监督微调和强化学习后，Astar 8B 的单次真实执行成功率达到 67.86%，在有效优化方向生成方面超过通用大模型与人类专家。Astar 与 Code Agent、训练评估及结果回流模块组成闭环，由模型提出方向、代理实现代码并运行实验，再将验证结果沉淀为训练数据，使指导模型与目标系统共同进化。在 Lazada 广告推荐系统的 20 轮无人干预迭代中，该方案使离线 Hitrate@200 提升 23.6%、线上 GMV 提升 4.86%。

用途与启示
  • 将代码版本、实验曲线和业务指标沉淀为可训练的“系统演化经验”，降低模型优化对资深工程师隐性经验与直觉的依赖。
  • 通过分层搜索和代理奖励模型低成本预筛候选方案，将高成本训练验证集中在更有潜力的方向，提高工业实验吞吐量。
  • 为“提出方案—生成代码—训练评估—经验回流”的自动化闭环自进化提供工业级实现参考。
  • 表明在高质量垂直领域演化数据和真实反馈支持下，小模型也可能在专业优化决策上超越更大的通用模型，领域数据质量可能比单纯扩大参数规模更关键。

PARPO：个性化智能体强化学习框架

中科大与阿里提出 PARPO，通过图记忆、偏好解耦奖励和用户级锚点优化个性化智能体策略，Qwen3-8B 在多项评测及盲测中排名第一。

子主题：智能体训练 量子位  HarnessEvolve

 强化学习 智能体 偏好优化 智能体记忆 技能演化

论文：https://arxiv.org/abs/2605.23382
原文：https://mp.weixin.qq.com/s/O2GDbvazq85_Ob1603DPJQ

PARPO 将个性化偏好纳入 Agentic RL 的训练目标，解决通用奖励难以区分用户差异、行为信号混合以及记忆结构扁平等问题。框架由偏好对齐技能演化图记忆 PSGM、两阶段偏好解耦奖励模型和双 advantage 轨道优化器组成，并形成“检索—交互—评价—优化—积累”的闭环。奖励模型借助用户画像与 LightGCN 分离兴趣和从众信号，优化器则以用户级历史锚点校准个性化奖励中心与尺度。在 ETAPP、ETAPP-Hard 和 SJAgent 上，Qwen3-8B 取得领先结果，并在专家及 LLM judge 盲测中排名第一；消融实验表明技能记忆贡献尤其显著。

用途与启示
  • 为电商助手、旅行规划和日程安排等多解任务提供面向用户偏好的强化学习方案。
  • 展示如何将异构图记忆、偏好奖励建模与策略优化整合为持续积累技能的训练闭环。
  • 用户级奖励锚点可缓解异质偏好下的奖励中心和尺度失配，为个性化后训练提供参考。
  • 兴趣与从众的解耦仍非严格因果分离，后续需扩大人工评测并验证跨平台泛化能力。

DAS：1小时自动生成面向发表的学术综述

子主题：学术论文 Auto Research  ResearchEvolve

 学术写作 科研智能体 科研工作流 证据溯源 人工智能可靠性

DAS 将学术综述生成定义为 Stateful Agentic Closed-Loop Manuscript Construction，而非一次性的“检索—写作”流水线。系统基于 DAS-2M 文献元数据湖预解析近 200 万篇 arXiv 论文，并通过候选文献驱动的分类体系、论文到章节反向路由以及 Claim-Level Citation Planning 组织内容。生成后，Semantic Reviewer 与确定性验证模块会针对论述逻辑、引文支持、交叉引用、LaTeX 和编译问题执行编辑、重规划与重新评估。DAS 在 DAS-Bench 30 个主题上取得 4.34 分，高于完整参评最强基线的 4.03 分，且官网已开放 220 篇自动生成的完整综述，但最终投稿前仍需人工核验。

用途与启示
  • 为研究者快速进入陌生领域、梳理文献脉络和持续追踪研究进展提供自动化工具。
  • 展示以共享 Manuscript State 连接检索、分类、写作、审阅和修复的科研智能体闭环设计。
  • 将引文规划前置到主张层级，并结合确定性编译验证，有助于提高综述的可追溯性与成稿可靠性。
  • DAS-2M 的可复用结构化文献表示可作为学术检索、综述生成和动态知识维护的基础设施。
  • 系统结果仍需专家核验，提示自动学术写作应重点建设人机协同修改、跨评判器校准和持续更新机制。

AI 何时停止过度思考？长推理模型的早停难题

长推理模型的过度思考不仅推高 Token 成本与延迟，还可能导致正确答案发生负向翻转，亟须通过自适应计算与早停机制改善推理性价比。

子主题：推理早停 机器之心PRO会员  Groom

 推理 测试时计算 推理预算 成本优化 强化学习

原文：https://mp.weixin.qq.com/s/JDbFmYEdLWOBYBLaTG4eIA

测试期计算扩展提升了大模型在数学、编程和多步决策任务上的能力，但冗长思维链也带来了显著的成本、延迟与基础设施压力。所谓“过度思考”，是指模型已经得到正确答案后仍持续进行同质化验证、自我怀疑和无效回溯，甚至将正确结论推翻为错误答案。其成因涉及推断期搜索陷阱、强化学习中的粗粒度信用分配、内生纠偏能力脆弱，以及终止与收敛机制失配。近期研究开始探索结构感知搜索、动态语义监控和推理早退，以便根据任务难度自适应分配计算预算。

用途与启示
  • 为长推理模型设计基于置信度、语义收敛或答案稳定性的动态早停策略。
  • 评估模型时同时报告准确率、Token 消耗、延迟和负向翻转率，避免只关注最终得分。
  • 在强化学习训练中细化过程信用分配，对无效回溯、重复验证和延迟终止施加惩罚。
  • 部署模型时依据实际工作负载核算总推理成本，避免被每百万 Token 的名义低价误导。

Trace as State：轨迹前置提升长上下文推理

智谱与清华团队提出 Trace as State，无需训练或修改架构，通过将首轮推理轨迹前置为条件状态并重读原文，显著提升长上下文任务表现。

子主题：推理扩展 PaperAgent 

 推理 长上下文 测试时计算 状态表征 成本优化

论文：https://arxiv.org/abs/2609.02702
原文：https://mp.weixin.qq.com/s/9fkiLWov-s8Zk_mteM0ELA?scene=1

Trace as State 首先收集模型对原始长上下文的多条推理轨迹，再将其序列化并置于原文和问题之前，让模型带着已提炼的任务状态重新阅读与作答。理论分析指出，在因果状态更新模型中，将条件置于信息之前只需维护当前状态，而条件后置在最坏情况下需要指数级更大的状态响应档案。该方法在 DeepSeek V4 Pro Preview、Qwen 3.7 Max 和 GLM-5.2，以及 GraphWalks、MRCRv2、NUB-1M 三项基准构成的 27 个模型×任务×指标组合中赢得 26 项，其中 DeepSeek V4 Pro 的一项指标由 29.2% 提升至 81.8%。消融实验表明，同题完整轨迹的前置效果明显优于轨迹后置、单纯重读、仅提供答案、随机轨迹和仅使用轨迹，且增加轨迹数量可持续提升性能。该方法约使输入 token 翻倍，但可能减少推理输出 token，同时会降低多轮场景中的 KV 缓存复用率。

用途与启示
  • 为无需训练和架构改造的长上下文测试时扩展提供简单方案，可直接应用于复杂检索、图遍历与长文理解任务。
  • 提示系统设计者应将已发现的目标、约束和中间状态放在待处理信息之前，而非仅追加到上下文末尾。
  • 可将推理轨迹数量作为推理预算旋钮，在准确率、输入成本、输出成本与延迟之间进行权衡。
  • 为智能体记忆与状态管理提供启示：先汇总任务轨迹形成显式状态，再以该状态驱动原始证据的重读和验证。

两篇论文审视 Harness 自演化的真实增益

两篇分析论文分别从 agent/evolver 能力解耦与增益来源拆分出发，指出 Harness 自演化的效果可能受智能体利用能力、测试时搜索及评测过拟合显著影响。

子主题：评测审计 微信公众平台  HarnessEvolve EvalEvolve

 智能体脚手架演化 模型评估 智能体评估 测试时计算 人工智能可靠性

原文：https://mp.weixin.qq.com/s/2AbGy3Sd3GSkDvXWz7ir3w

文章合读《Harness Updating Is Not Harness Benefit》与《Rethinking the Evaluation of Harness Evolution》，讨论固定模型权重、仅更新提示、工具、技能、记忆或代码的 Harness 自演化是否真正有效。第一篇发现不同能力层级的 evolver 所产生的更新收益接近，而 task-solving agent 从更新中获益的程度呈非单调关系，弱模型主要受激活失败和长程遵循失败限制。第二篇在匹配反馈与推理预算后发现，Harness 演化未能稳定超过简单的测试时扩展，并且在搜索任务与评测任务分离后增益消失，暴露出记忆具体修法而非提炼通用策略的过拟合。两项研究共同提示现有标题级增益可能被高估，但前者缺少 held-out 泛化检验，后者每任务仅一次 rollout，也可能因演化证据预算不足而低估方法能力。

用途与启示
  • 评估 Harness 自演化时，应分别测量 evolver 的更新能力与 agent 对更新的利用能力，避免仅凭端到端分数归因。
  • 将 Harness 演化与并行采样、顺序修订等测试时扩展方法放在相同反馈和算力预算下比较。

TailSFT：过滤式微调提升后训练性能

TailSFT通过动态过滤模型已掌握的样本、聚焦分布尾部进行监督微调，以更高覆盖度的中间检查点显著改善后续强化学习效果。

子主题：模型微调 智源社区  Groom

 模型训练 数据策展 后训练 强化学习 样本调度

代码：https://github.com/ai2-llm/tail-sft
原文：https://hub.baai.ac.cn/paper/e90d40f9-c2e8-48ed-8f0c-0e499f46e698

TailSFT是一种轻量、无参数的SFT改进方法，动态过滤模型已能高置信度正确生成的“头部”样本，将训练集中于尚未充分建模的“尾部”样本。其目标不是单纯提高当前检查点的单次准确率，而是提升coverage与pass@K，使检查点更适合作为后续强化学习的初始化。在OLMo-3 7B的数学和编程任务上，TailSFT将pass@16绝对提升最高17%，后续使用GRPO训练时又带来最高4个百分点的pass@1提升，额外计算开销很小。论文还提出TailScore轻量诊断指标，用于预测特定训练场景采用TailSFT的潜在收益。

用途与启示
  • 为SFT数据筛选提供动态策略，减少在模型已掌握样本上的重复训练。
  • 表明中间检查点应按其支持后续训练的能力评价，而不应只关注当前阶段的单次准确率。
  • 可利用coverage、pass@K及TailScore提前判断模型是否具备较好的强化学习准备度。
  • 为课程学习、不确定性驱动采样以及面向后训练的阶段化模型开发提供参考。

标题：TailSFT: Filtered Fine-Tuning Improves Post-Training Performance 来源：智源社区热门论文（hub.baai.ac.cn） 链接：https://hub.baai.ac.cn/paper/e90d40f9-c2e8-48ed-8f0c-0e499f46e698 摘要：（今日热度 856）强化学习的后训练过程正推动现代人工智能系统在推理与智能体能力方面的进步；然而，越来越多的研究表明，只有当强化学习被用于微调一个本身已具备较强能力的基础模型时，其效果才最为显著。我们由此提出疑问：当前主流的模型训练流程所产出的模型，是否真的最适合开展后续的强化学习？基于先前研究——该研究指出“覆盖度”（coverage）与“pass@K”指标可作为预测强化学习后性能的重要依据——我们设计了一种对监督微调（SFT）的简易改进方法，称为TailSFT：它在训练过程中主动过滤掉那些模型已能较好拟合的样本序列，从而将学习重心转向数据分布中建模不足的区域，即分布的“尾部”（tail）。我们通过受控实验与理论分析相结合的方式，为TailSFT的设计选择（尤其是所采用的具体过滤标准）提供了充分的合理性论证与实证验证。在OLMo-3 7B模型上，TailSFT在数学与编程类评测任务的pass@16指标上普遍取得提升，绝对增益最高达17%，且仅带来极小的额外计算开销。更重要的是，这些具有更高覆盖度的中间检查点，在后续采用GRPO算法进行强化学习时，稳定地转化为最高达4个百分点的pass@1绝对提升，充分证明TailSFT产出的检查点更适合作为强化学习的初始化起点。此外，我们还提出了一种轻量级诊断工具，用于快速识别TailSFT最可能发挥效用的训练场景。更广泛而言，本研究的结果启示我们应采取一种原则性强、阶段意识明确的模型研发范式：即在模型开发的每个中间阶段，其产出的检查点不应仅以自身性能为评判标准，而更应以其对后续训练阶段的支持效能为根本衡量依据。
