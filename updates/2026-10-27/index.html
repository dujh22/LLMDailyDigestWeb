RRSI：正则化智能体脚手架的递归自我改进

RRSI通过约束脚手架修改范围、筛查任务泄漏并引入成本感知选择机制，缓解递归自我改进对训练任务的过拟合，提升智能体在留出集和分布外基准上的泛化表现。

RRSI关注智能体脚手架在提示词、控制流、工具接口、记忆及上下文管理等层面递归自我改进时产生的基准过拟合问题。其“如何改”机制限制每轮可修改的模块数量、记录改动及收益证据，并在性能停滞时探索尚未使用的组件。“如何选”机制加入任务信息泄漏筛查、噪声容忍下限、Token成本感知接受规则和无效组件结构化剪枝。实验覆盖编程、智能体工作空间和工程设计三个领域的8个基准，训练集成绩提升6.0分，5个OOD基准最多提升4.3分，同时Token消耗减少30%。

用途与启示
  • 为智能体脚手架的递归自我改进提供防止训练任务记忆和基准过拟合的正则化方案。
  • 说明自进化系统不仅要优化当前任务收益，还应依据分布外泛化、修改证据和推理成本筛选改动。
  • 可将模块修改约束、泄漏筛查与结构化剪枝迁移到其他持续迭代或自动优化系统中。
  • 提醒设计RSI流程时监控奖励作弊，并优先保留可跨任务复用的机制。

RSIHub：可组合的智能体演化方法框架

RSIHub以可复用算子、声明式可变资源和统一执行评估基础设施，支持智能体演化方法的构建、公平比较与扩展。

★ 3 子主题：自进化框架 Hugging Face Papers  AgentEvolve HarnessEvolve SystemEvolve Awesome-RSI

 智能体 自演化 人工智能框架 智能体脚手架演化 执行反馈

论文：https://arxiv.org/abs/2610.32253

RSIHub将提示、技能、工具及编排策略的演化表示为由可复用算子组成的 recipe，并显式声明可变资源。框架统一提供执行、评估、故障恢复和谱系追踪，同时将评估环节隔离在可变范围之外，以增强比较的公平性与可审计性。作者无需修改框架核心便复现了 AHE、Hyperagents、A-Evolve 和 GEPA，并在 Terminal Bench 2 与 τ³ Banking 上使用 MiniSWE 和 Codex 进行评测。实验中最高整体 pass@1 提升达 13.5 个百分点，但方法排名随配置变化，优化收益也未必能迁移至留出任务。

用途与启示
  • 为不同智能体演化策略提供统一、可复现的实验协议，减少重复搭建执行与评估基础设施的成本。
  • 通过候选谱系和评估条件绑定，支持演化过程审计、故障恢复及结果追溯。
  • 结果表明智能体演化策略具有明显的环境与配置依赖性，应重视留出任务评测和跨设置泛化。
  • 可利用可组合 recipe 与算子快速开发和横向比较新的提示、技能、工具及编排演化方法。

ASCENT：智能体将成功经验自蒸馏进权重，实现在线持续学习

ASCENT让智能体在每个任务仅执行一次的在线场景中，将通过验证的成功轨迹经冻结自身教师自蒸馏至LoRA快权重，在多个长程基准上显著提升成功率并减少交互轮数。

★ 3 子主题：测试时训练 量子位  AgentTrainEvolve GeneralizeEvolve

 模型训练 智能体 持续学习 自蒸馏 经验学习

论文：https://arxiv.org/abs/2610.05303
原文：https://mp.weixin.qq.com/s/vED30WX1r2evq8rQNlZErQ

ASCENT提出在线智能体测试时训练（OaTTT）方案，仅对通过任务验证的单次执行轨迹进行权重更新，无需参考答案、更强教师或逐轮奖励。冻结的初始模型读取包含完整成功轨迹的hindsight特权信息，为学生模型提供逐词元软目标，再通过KL散度将经验蒸馏到LoRA快权重中。动作有效性过滤会从教师输入中移除环境未执行的无效动作，而学生仍在相应位置接受训练，从而抑制无效行为和策略漂移。在ALFWorld与WebShop上，基于Qwen3.5-4B/9B的成功率均较基座提高22个百分点以上，并在大量任务中减少交互轮数；其能力还能迁移至未见环境。消融实验显示，成功轨迹中的推理过程比单独动作更关键，冻结教师与完整轨迹hindsight则是维持在线学习稳定性的核心。

用途与启示
  • 为部署中“边执行、边学习”的智能体提供无需重复采样的在线参数更新路径。
  • 说明经过验证的成功经验可从外部文本记忆进一步沉淀为权重，降低推理时检索依赖与交互成本。
  • 冻结教师和软目标蒸馏可缓解单轨迹训练中的噪声放大、过拟合及策略漂移。
  • 可与ACE、MemP等上下文自适应机制结合，为环境专属或用户专属快权重提供技术基础。

TTPO：无标签测试时策略优化实现自进化

TTPO利用伪标签更擅长识别错误的非对称特性，结合在策略蒸馏与分组强化学习，在无真值标签条件下稳定提升大语言模型的数学推理能力。

★ 3 子主题：测试时训练 未知  EvolveLRM GeneralizeEvolve

 模型训练 测试时计算 强化学习 自我改进 数学人工智能

论文：https://arxiv.org/abs/2608.27448
原文：https://mp.weixin.qq.com/s/DrHNsxC8J8ZLpsjAoGBbpQ

TTPO针对测试时训练缺少真值标签、错误伪标签会放大密集监督风险的问题，利用“伪标签未必正确，但与其分歧的轨迹通常错误”这一非对称信号。对于与伪标签一致的正样本，方法以伪标签作为教师的特权信息，通过前向 KL 进行在策略蒸馏；对于分歧样本，则使用 GRPO 和共识奖励压制错误推理。其正样本分支根据学生熵及师生散度调整 token 权重，负样本分支仅惩罚高置信、低熵的错误 token，以减少误伤和计算开销。在五个竞赛级数学基准上，Qwen3-1.7B 的测试时准确率由 38.0% 提升至 45.2%，并在无标签条件下达到有标签 OPSD 的水平。

用途与启示
  • 为无人工标签的测试时训练提供稳定的 token 级自监督方案。
  • 展示弱伪标签可以用于可靠识别错误，而不必被直接当作完全正确的监督目标。
  • 将在策略蒸馏与 GRPO 非对称组合，可降低错误伪标签对推理轨迹的污染。
  • 模型性能提升会同步改善伪标签质量，形成可持续的自我改进闭环。

LegoFlow：智能体自动化代码数据构建与训练评测

LegoFlow 将代码任务构建、轨迹生成、模型训练和基准评测封装为可由编码智能体自主编排的插件化流水线，并利用评测反馈实现闭环迭代改进。

★ 3 子主题：闭环自进化 机器之心  CodeEvolve AgentTrainEvolve DataEvolve

 人工智能辅助编程 数据工程 智能体 模型训练 递归自我改进

代码：https://github.com/LegoX/LegoFlow
数据集：https://huggingface.co/datasets/Lego-X/LegoFlow-SWE
原文：https://mp.weixin.qq.com/s/ywXO5qryvJhFatdk8B5u4w

LegoFlow 以 Root、Curator、Tracer、Trainer 和 Evaluator 等模块组织代码数据工程，使编码智能体能够自动完成仓库发现、任务验证、轨迹生成、微调与评测。团队从约 1,200 万个候选 PR 中筛选出 5,000 个可验证任务，并发布包含 2,780 条成功轨迹的 LegoFlow-SWE 数据集。使用约 1,000 条轨迹微调 Qwen3.5-35B-A3B-Base 后，模型在 SWE-bench Verified、Pro 和 Multilingual 上分别达到 70.2%、48.8% 和 57.0%。在端到端闭环实验中，智能体根据首次评测反馈过滤浅层推理并标准化工具调用，使模型在两轮迭代后从 7.6% 提升至 64.4%。实验还表明任务可验证性、轨迹推理深度与防止答案泄漏，比单纯扩大数据量或提高思维链触发率更重要。

用途与启示
  • 为代码模型提供可复现的自动化数据策展、轨迹生产、训练和评测基础设施。
  • 展示如何利用执行验证与评测反馈形成代码智能体的闭环自我改进流程。
  • 提示训练数据筛选应优先关注任务难度、可验证性和推理深度，而非数据规模或思维链覆盖率。
  • 为 SWE 基准训练和评测提供隔离运行、防作弊提示及网络访问限制等可靠性实践。

策略内自训练：无数据监督的语言模型自我改进

该研究将策略内自蒸馏重构为无数据自训练框架，使模型仅依据高层主题描述生成课程、问答对和特权推理轨迹，并在文本与视觉问答任务上实现持续能力提升。

研究将策略内自蒸馏扩展为自训练框架，不再依赖真实问答对、人工策划题集或更强的外部教师。模型仅根据粗粒度主题描述，自主合成查询、答案以及作为监督信号的特权推理轨迹，从而形成自己的训练课程。基于全合成特权信息的自蒸馏可在多个领域提升能力，同时较好保留未参与自训练领域的原有能力。该框架在标准语言基准和视觉问答任务上均获得一致改进，显示其具备跨文本与多模态场景的通用性。

  • 表明基础模型的潜在能力可通过策略内自训练被激活，同时减少跨领域能力遗忘。
  • 为文本与视觉任务采用统一的自蒸馏流程提供实验证据。

TWIG（Tree-structured Weights with Inherited Gates）将每个权重表示为符号、二次幂位移、零门控和共享表索引等离散决策组成的路径，相关权重可继承并共享路径上层决策。任意已训练网络均可转换为TWIG；采用二次幂决策后，权重层可主要由连线和加法器构成，适用于制造时固化权重的专用芯片。该表示把剪枝、量化、低秩分解、码本和权重共享统一为同一树结构上的编辑与优化问题，并可映射为高阶玻尔兹曼机的基态求解。在五个大语言模型权重矩阵上，TWIG在同等层误差和3/4比特精度下，相比GPTQ通常减少9%–15%的加法操作，在强离群值矩阵上减少20%–55%。

用途与启示

  • 将乘常数运算转化为移位与加法，有望降低固定权重推理芯片的面积、能耗和计算成本。
  • 将权重格式优化表述为高阶玻尔兹曼机基态问题，为退火算法和量子优化器提供新的应用场景。
  • 对包含强离群值的权重矩阵尤其有效，可作为GPTQ等量化方案的硬件友好替代路径。
