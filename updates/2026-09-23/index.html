小米开源全模态模型 MiMo-V2.6，以大规模 RL 探索 RSI

小米发布并开源原生全模态 MoE 模型 MiMo-V2.6，通过约6天、75万条轨迹的大规模多任务智能体强化学习提升长程执行、软件工程与多模态能力，并将其作为探索递归自我改进的新一步。

MiMo-V2.6 包含总参数 1.02T 的 Pro 和 310B 的 Flash，采用 hybrid-SWA 主干并支持最长 1M 上下文；团队还计划推出同等智力水平下输出速度提升20倍的 Pro-UltraSpeed。两款模型在不到6天内各完成30个 RL step，累计生成约75万条轨迹，覆盖编程、通用智能体、视觉、网络安全、Computer Use、3D、具身控制、形式化证明与科研等场景，DeepSWE v1.1 分数分别提升约17分和14分。后训练遵循“You Only RL Once”思路，结合 GRPO、全异步 partial rollout、多任务与 Multi-Harness 混合训练、mini-harness，以及 Groupwise Agentic Grading 的群组奖励合成、优势重分配、长度和行为惩罚。为稳定 MoE 强化学习并防范奖励作弊，团队冻结 Router、采用 R3 路由重放保持训练—推理一致，通过异常检测与验证器交叉校验加强防护，并开放模型权重、MiMo-V2.6-Distill-Qwen-9B、7,000余个 RL 任务环境及端到端训练框架。Pro 在 Artificial Analysis Intelligence Index 获得46.32分，并在 DeepSWE、Terminal-Bench、AutomationBench 等基准上提升，但实际测试仍暴露出思考耗时较长、反复读取目录和工具执行路径低效等问题。

用途与启示
  • 展示从原生全模态 MoE、真实多任务环境、群组评分器到异步训练基础设施同步扩展 Agentic RL 的系统化路径。
  • 群组智能评分、异常检测与验证器交叉校验可缓解二元奖励信息不足，并抑制冗长输出、错误工具调用和奖励作弊。
  • 冻结 MoE Router、R3 路由重放以及控制面与数据面解耦，为大规模稀疏模型的稳定后训练、高并发执行和训练—推理一致性提供可复用方案。
  • Multi-Harness Training、多教师在策略蒸馏及开放任务环境有助于研究跨执行框架迁移、长程软件工程泛化和递归自我改进。

OpenAI 推出基于 GPT-6 Astra 的 GPT-6 Sol 和 Luna，在保留推理、多模态及编程能力的同时，将 API 价格相较 GPT-5.6 下调约 50%。两款模型通过提升推理效率和 Prompt Caching 命中率降低长程智能体任务成本，其中缓存输入读取可享受 90% 折扣。Anthropic 发布 Claude Opus 5.5，宣称多数任务达到 Fable 5.1 水平，较 Opus 5 的典型任务成本降低约 40%、输出速度提升超过 30%。相关测试也显示，提高推理强度并不必然改善结果，合理控制测试时计算、步骤数和缓存成本可能比单纯比较 Token 单价更重要。两家公司共同将衡量指标转向“完成一次任务的总成本”，反映大模型市场正从峰值能力竞争走向高性价比的规模化部署。

  • 单位任务成本正成为模型商业化和规模部署的核心指标，可用于构建更贴近真实生产环境的评测体系。

RoboDawn：将视觉语言模型智能迁移至机器人控制

RoboDawn通过离散控制接口和上下文学习，使智能体式VLM无需任务特定机器人训练即可闭环控制仿真及真实机器人。

子主题：具身规划 Hugging Face Papers 

 具身智能 多模态 任务规划 上下文学习 工具调用

论文：https://arxiv.org/abs/2609.22966

RoboDawn将平移、旋转和夹爪操作封装为一组紧凑的离散命令，让智能体式VLM能够直接进行机器人控制。系统采用视觉观察、动作推理、命令执行和状态反馈构成的闭环，并通过少量演示在上下文中学习接口用法与任务策略。在RoboTwin 2.0 C2R上，其成功率由零样本的53.2%提升至单样本的73.6%，超过π0.5基线的46.0%；在RoboDojo上则由35.67%提升至47.17%。该框架无需针对具体任务训练机器人策略，并已迁移到Franka真实机器人上完成方块入篮与堆叠任务。

用途与启示
  • 展示通用VLM中的视觉理解与推理能力可通过简单动作接口迁移至物理机器人控制。
  • 为减少任务特定机器人数据和策略训练成本提供零样本与单样本方案。
  • 表明上下文演示不仅能教授控制接口，还能快速注入具身任务的求解策略。
  • 为利用基础模型构建闭环、可适应的通用机器人控制系统提供参考。

OmniEdu：面向 K-12 学习与教学的开放基础模型

OmniEdu 通过能力均衡的教育指令数据微调 4B、9B 和 27B 模型，全面提升 K-12 解题、课程理解、学习诊断与教学辅导能力。

子主题：模型微调 Hugging Face Papers 

 模型训练 人工智能应用 数据策展 模型评估

论文：https://arxiv.org/abs/2609.23088

OmniEdu 是面向 K-12 学习与教学的开放基础模型系列，覆盖 4B、9B 和 27B 三种规模。其指令微调语料整合逾 100 个教育及通用指令资源，围绕学科能力、课程对齐、诊断推理、教学行动与脚手架四类能力组织，共包含 69,999 个样本和 1,596 万监督回答词元。数据管线结合确定性清洗、语义审计与重写、任务级质量评分、词元预算约束下的多样性选择，以及教学指令分配。教育导向微调在不同模型规模上均改善课程理解、K-12 解题和教学辅导表现，其中 OmniEdu-27B 在 K12-Bench、MathFish、EDUMATH、MathTutorBench 和 LongTutor 上取得较强结果。

用途与启示
  • 说明教育模型的数据混合应按核心能力组织，而非仅按数据来源或任务类型划分。
