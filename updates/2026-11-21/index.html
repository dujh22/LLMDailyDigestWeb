Forward-Only Passes：角度集中度引导降秩

用前向激活的角度集中度定位并裁剪SVD分量，解决在线任务适应依赖反向传播、开销过高的问题。

★ 3 子主题：测试时优化 机器之心  ReasoningEvolve

 测试时计算 系统优化 推理加速 成本优化 推理

论文：https://arxiv.org/abs/2611.10610
原文：https://mp.weixin.qq.com/s/WgJNWHiUImUiQmKu-mYevQ
用途

在在线LLM推理服务中借鉴角度集中度搜索机制，无需反向传播即可筛选降秩权重矩阵并进行低成本任务适应。

启示

模型前向激活的几何集中程度能够充当无需梯度的权重贡献信号，使内部权重适应与常规推理共享计算过程。

📄 详细内容
  • 问题：让LLM在推理服务期间根据真实交互低成本适应特定任务，同时避免额外训练带来的内存与计算负担。
  • 旧法为何失效：PEFT、提示调优和测试时训练通常依赖反向传播；LASER式穷举搜索计算成本较高，知识增强方法又不直接调整模型内部权重。
  • 方法：将候选权重矩阵分解为多个SVD分量，通过一次前向传播测量各分量激活与隐藏状态的角度集中度，据此分层搜索并选择适合降秩的矩阵；实验发现可忽略注意力模块，重点搜索FFN输入与输出矩阵。
  • 实验：在知识推理、知识干预、多跳推理、事实验证、公平性、幻觉检测和信息检索等任务上，相比LASER-Grad具有更低峰值内存和更高加速比，相比LASER加速更快且准确率相当；结果覆盖GPT-J、RoBERTa以及最高570亿参数的LLaMA2、DeepSeekV1、Mistral、Qwen2、MoE和多模态Gemma 4。
  • 局限与后续：仅前向学习扩展至深层LLM仍面临可扩展性挑战；后续可结合用户偏好或自标记验证数据，探索推理服务中的在线实时适应。

TuringSpace：交互验证码训练空间行动

用可程序生成的交互式验证码将空间理解绑定到点击拖拽行动，微调后成功率从1.6%升至33.1%。

★ 2 子主题：评测基准 Hugging Face Papers  EvalEvolve EnvironmentEvolve PhysicalEvolve

 空间智能 交互式评估 视觉推理 图形用户界面智能体 环境合成

论文：https://arxiv.org/abs/2611.25387
用途

在多模态智能体或桌面操作系统中，可将TuringSpace作为空间行动能力的训练环境与交互式评测基准。

启示

真正可迁移的空间智能需要把视觉判断置于行动—反馈—纠错闭环中，静态推理成绩无法揭示模型固守错误空间信念的问题。

📄 详细内容
  • 问题：多模态模型能否从二维画面推断三维布局、预测操作结果，并根据反馈纠正判断，现有静态空间基准难以检验这一行动闭环。
  • 旧法为何失效：已有验证码基准大多已被攻克且很少考查空间能力，而空间基准通常不要求模型执行点击、拖拽等实际操作。
  • 方法：TuringSpace 构建125种覆盖五类空间能力的合成交互式验证码；每项任务均由程序生成新实例，并配有检查器和预言机，可同时作为可扩展评测环境与训练场。
  • 实验：人类成功率为94.1%，GPT-6 Astra仍失败25.9%，最佳开放权重模型Kimi K3失败68.0%。在该环境微调Qwen3.5-9B后，其成功率由1.6%升至33.1%，并在七个分布外基准上全部提升，其中VSI-Bench提高9.9个百分点。
  • 局限与后续：多数失败源于误读截图，模型推理往往不会纠正错误信念，反而会虚构证据为其辩护；作者计划发布TuringSpace以支持后续研究。

Mind2Act World：心智动作组合诊断

用心智、动作及闭环组合三类任务，诊断机器人操作失败源于推理、执行还是能力组合。

★ 2 子主题：评测基准 Hugging Face Papers  EvalEvolve PhysicalEvolve RobotEvolve

 具身智能评估 模型评估 具身智能 状态追踪 执行反馈

论文：https://arxiv.org/abs/2611.26444
用途

在机器人操作系统中将其作为VLA、WAM或多模态智能体的诊断基准，分别定位状态记忆、动作执行与闭环组合瓶颈。

启示

机器人即使分别具备推理和动作能力，也可能因缺乏环境反馈驱动的持续耦合而在组合任务中大幅失效。

📄 详细内容
  • 问题：现有机器人操作评测难以判断失败究竟来自历史认知推理、物理动作执行，还是两种能力未能通过环境反馈有效组合。
  • 旧法为何失效：已有基准要么在同一任务中混合评测推理与执行，要么将二者完全分开，无法单独诊断能力组合缺陷。
  • 方法：Mind2Act World设置Mind、Act和Mind2Act三种视图，覆盖5个现实应用领域的30项模拟操作任务；每项任务含3档难度及Clean、Random两种场景，共180种配置，并用诊断工具将失败归因于心智、动作或二者组合。
  • 实验：评测多模态智能体、视觉-语言-动作模型和世界动作模型；最强智能体在Mind和Act上的成功率分别为52.7%和39.0%，在Mind2Act上仅为12.0%。
  • 局限与后续：单项能力无法自然迁移至闭环组合任务，如何通过环境反馈持续耦合推理与执行仍是主要开放问题。

WeMM-Video：全模态音视频联合推理

用统一音视频感知与双模式推理解决开源模型跨模态视频理解不足，35B版刷新开源最佳。

★ 2 子主题：多模态推理 Hugging Face Papers  NewModel

 视频理解 多模态 推理 开放权重模型 模型训练

论文：https://arxiv.org/abs/2611.26409
用途

在音视频问答、视频检索与内容分析系统中直接部署其不同规模模型，或复用双模式推理和多阶段后训练流程作为开源基线。

启示

全模态能力的关键不只是扩大参数规模，而是让音频与视觉在统一训练目标下协同感知，并按任务需要切换快速响应和显式推理。

📄 详细内容
  • 问题：带音频的视频理解仍是多模态智能的核心难题，开源模型尤其缺乏统一处理文本、图像、音频和视频并进行推理的能力。
  • 旧法为何失效：现有开源全模态模型在音视频联合理解上落后于强闭源模型，较大参数规模也未必带来更好的综合视频推理表现。
  • 方法：推出2B、4B、9B和35B-A3B四种中英双语模型，以统一架构联合处理文本、图像、音频和视频，并支持快速直接回答与显式逐步推理两种模式；使用约1.2万亿词元进行渐进式预训练，再结合多教师OPD、抗重复MrDPO和专家强化学习完成多阶段后训练。
  • 实验：在超过120个基准上评测；35B-A3B在全模态视频评测中刷新开源最佳，超过Qwen3.5-Omni-Flash、Seed2.0-Mini-0428并缩小与Gemini-3.0-Flash的差距，9B版超过更大的Qwen3-Omni-30B-A3B-Instruct。

Depth Pro 2：原生分辨率时序深度

用统一网络兼顾边界清晰度与跨帧稳定性，实现图像和视频的全分辨率度量深度估计。

★ 2 子主题：三维重建 Hugging Face Papers  NewModel PhysicalEvolve

 空间智能 视频理解 时序建模 视觉表征学习 多模态

论文：https://arxiv.org/abs/2611.26603
用途

在三维重建、视频编辑或机器人感知系统中调用其公开权重，为单张图像和视频生成尺度准确且跨帧稳定的深度图。

启示

单帧锐度与多帧一致性并非必然冲突，统一训练并保持原生分辨率可以同时保留空间细节和时间稳定性。

📄 详细内容
  • 问题：单目图像与视频的稠密度量深度估计需要同时保证尺度准确、物体边界清晰和跨帧稳定，但既有方案难以三者兼得。
  • 旧法为何失效：多帧方法通常偏重时间一致性而牺牲边界锐度，单帧方法则能保留锐利边界，却容易在视频中产生深度抖动。
  • 方法：训练一个可扩展的统一网络，同时处理图像和视频，并直接在输入的原生分辨率上预测度量深度图。
  • 实验：Depth Pro 2 在度量准确性、边界锐度和时间一致性上均优于既有方法；发布的模型家族还在上述指标与运行时间之间形成新的帕累托前沿。

HiUni：共享骨干统一视觉能力

用共享视觉编码器与Transformer骨干解决视觉理解和图像生成难以真正统一的问题，同时保留细粒度空间信息。

★ 2 子主题：多模态学习 Hugging Face Papers  NewModel

 多模态 视觉生成 图像编辑 模型开发

论文：https://arxiv.org/abs/2611.26107
用途

在统一视觉理解、图像生成与编辑系统中，可借鉴共享骨干加输出端专用头的架构，减少重复的任务专用计算。

启示

视觉理解与生成的差异未必需要通过分离骨干解决，只要在输出端恢复空间细节并适配优化目标，共享语义表征即可兼顾两类能力。

📄 详细内容
  • 问题：统一多模态系统通常无法用同一套视觉表征与骨干同时做好视觉理解、图像生成和编辑。
  • 旧法为何失效：现有方案常为理解与生成分设视觉表征或骨干计算；预训练ViT的语义抽象还会丢失生成所需的精细空间细节。
  • 方法：HiUni让两类任务共享语言对齐ViT与稠密Transformer骨干，仅在输出端保留任务专用计算；Pixel Diffusion Head直接优化像素空间，轻量HiGate通路在输出端补充细粒度空间信息。
  • 实验：HiUni的平均视觉理解成绩与原预训练视觉语言模型相近，并在图像生成和编辑任务上取得有竞争力的表现；受控对比表明单一稠密骨干无需任务专用计算即可支撑两类能力。

  • 实验：受控训练显示可靠的选择性访问晚于概念可读性形成；跨不同视觉语言模型家族和规模，均观察到概念可访问、查询依赖选择及跨任务干预效应。

启示

高质量第一人称字幕的关键不是单纯增加描述长度，而是先建立稳定的事件结构，再用独立的事实与时序信号约束细节扩写。

  • 问题：第一人称视频字幕需要同时覆盖细微动作并准确标注发生时间，但现有模型容易漏掉短暂动作、混淆动作顺序或误判佩戴者自身运动。

  • 方法：EgoCaptioner先生成场景、参与者及整体活动概述，再输出带时间戳的自适应细粒度步骤。其粗到细标注流程从8个第一人称视频源构建5万条训练样本，并通过GRPO联合优化事实准确性、内容覆盖、步骤级时序对齐及叙述连贯性；有传感器数据时还加入姿态推导的运动事实。
  • 实验：在5个第一人称视频基准上，该方法在字幕质量、字幕条件问答和时序对齐方面领先受测开源模型；在PhysCapBench上超过Gemini 3.1 Pro，并在Minerva-Ego字幕转问答设置中超过全部受测闭源基线。消融实验表明，事实奖励与时序奖励具有互补作用，粗到细标注优于单遍标注。
