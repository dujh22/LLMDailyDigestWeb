R²Orch：通过技能内化与自博弈实现智能体编排的递归自我改进

R²Orch以双层自博弈和技能内化循环训练智能体编排器，使其自动选择可学习任务、将失败内化为参数并逐步实现零技能部署。

 递归自我改进 智能体编排 自博弈 技能演化 模型训练

论文：https://arxiv.org/abs/2610.22740
代码：https://github.com/beita6969/R2Orch

R²Orch提出递归自博弈编排范式：内循环在自主选择的任务上改进编排器，外循环则优化内循环的改进过程。其“递归可学习性”目标鼓励任务提议器选择在逐步撤除技能时仍能产生差异化结果的任务，以缓解固定课程和优势坍缩问题。Skill Withdrawal机制在受控自博弈评估确认编排器无需某项技能也能保持表现后，将该技能撤除，并把失败蒸馏为技能、再内化到参数中。实验覆盖12个数据集，在问答、数学、代码和交互任务上均持续优于基线，并推动编排器趋向零外部技能部署。

用途与启示
  • 为无需人工设计课程的智能体训练提供双层递归优化框架。
  • 通过递归可学习性维持任务结果差异，缓解同质化回报导致的优势坍缩。
  • 将显式技能逐步内化到模型参数，可降低部署阶段的技能库依赖与编排开销。
  • Skill Withdrawal可作为检验技能是否已被模型真正掌握的受控评估机制。

Astra 直接编程神经网络权重，显著提升 Qwen 数学能力

MIT CSAIL 展示 Weight-Space Programming，让 GPT-6 Astra 无需梯度下降即可读取、修复乃至从零编写神经网络权重。

原文：https://mp.weixin.qq.com/s/JhpDYH4I18BPu8cnyF9G3A

MIT CSAIL 团队提出 Weight-Space Programming，使通用语言模型能够依据自然语言目标直接分析和修改神经网络权重，而无需优化器或梯度下降。Astra 仅修改 Qwen3.5-0.8B 约 0.016% 的参数，便将其 MATH-500 成绩从 7.9% 提升至 48.1%，并显著改善指令遵循能力。实验还显示，Astra 可以从权重识别网络所学任务、修复陷入局部最优的控制策略，并从零构造游戏与围棋策略网络。部分零训练生成的策略网络超过了经过大规模 PPO 训练的基线，显示模型推理可能成为传统数值优化之外的新型权重编辑途径。

用途与启示
  • 为无需梯度和再训练的模型修复、能力注入与快速迭代提供新路径。
  • 表明前沿语言模型可能具备直接解释参数结构和定位行为缺陷的初步能力。
  • 可用于探索由模型自主诊断并修改其他模型的递归自我改进闭环。
  • 仍需验证其在更大参数规模、不同架构及安全约束下的稳定性与可复现性。

REA 通过路由记忆、边界触发判断门和共享预算升级机制，统一协调基础模型与快速具身策略，实现无需等待高层推理的异步控制。

 具身智能 智能体运行时 系统优化 任务规划 执行恢复

REA 将负责审慎推理的 System 2、承担具身路由的 System 1 和执行快速反应的 System 0 策略整合进统一运行时，并规定正在运行的策略不得等待高层“脑”模块。系统利用路由记忆预存各策略的实测成功率，通过边界触发的判断门选择性咨询基础模型，并以共享预算的升级阶梯约束故障恢复。在 60 个 LIBERO-Pro 任务的 3,000 个测试回合中，REA 达到 95.9% 成功率，同时将控制步数和控制时间分别降低 25% 和 17%。在 RoboTwin 2.0 上，VLA 与 VLA+代码配置分别达到 84% 和 86% 成功率，并进一步迁移到 BEHAVIOR-1K 和真实 Unitree G1 人形机器人。

用途与启示

  • 路由记忆与边界触发机制可减少重复回退和静默故障漏检，适用于长程具身任务的受限恢复。
  • 统一容纳学习策略与程序化策略，为跨策略栈评估、策略路由和真实机器人部署提供参考。

Meta提出路由式持续学习架构Routed CL

Meta FAIR提出Routed CL，通过按任务聚类、路由记忆系统并隔离经验，将智能体归一化奖励提高15%至30%，同时降低65%至72%的API成本。

★ 3 子主题：持续学习 未知  MemoryEvolve AgentEvolve GeneralizeEvolve

 持续学习 智能体记忆 智能体 经验复用 成本优化

论文：https://arxiv.org/abs/2610.38796
原文：https://mp.weixin.qq.com/s/YfICz_rESlgDod8bJwAczQ?scene=1

Meta FAIR提出路由式持续学习（Routed CL），将历史执行轨迹划分为多个簇，并为每个簇维护独立记忆，以减少异构任务之间的经验干扰。基于LLM的路由器会结合当前问题、记忆系统说明和簇摘要，决定复用已有簇或创建新簇，同时为任务选择原始轨迹、推理策略或结构化状态等不同记忆表示。上下文记忆适配器负责在任务执行前注入相关记忆，并在完成后使用新轨迹更新对应簇。混合任务流实验显示，该架构在四种语言模型上的平均归一化奖励均超过无状态ICL、全局ICL和路由ICL，API成本估算降低65%至72%。当前工作尚未验证并发更新、旧状态读取、跨模型共享记忆簇以及多簇联合读写等场景。

用途与启示
  • 为持续运行的智能体提供可插拔的经验复用架构，无需改变原有智能体执行方式。
  • 通过任务聚类和记忆隔离缓解不同任务经验混合导致的负迁移与上下文干扰。
  • 根据任务特征动态选择记忆表示，在保留有效经验的同时压缩上下文和API成本。
  • 后续可探索多簇联合检索、一次轨迹更新多个簇，以及并发和跨模型条件下的状态一致性。

Trajectory2Gym：面向工具智能体的决策接地交互合成

Trajectory2Gym 通过合成跨步依赖交互、逐决策接地认证和结构化数据分配，仅用全参数 SFT 就显著提升工具智能体在有状态多轮任务上的表现。

★ 2 子主题：数据合成 未知  DataEvolve AgentTrainEvolve EnvironmentEvolve

 智能体数据合成 工具调用 模型训练 智能体 执行轨迹

原文：https://mp.weixin.qq.com/s/V2ZVlGaifV7T5TCXGjeTZg

Trajectory2Gym 将工具智能体训练数据的筛选标准从整条轨迹是否成功，细化为每个动作在决策时是否具有可见依据、执行有效且符合工作流顺序。它围绕信息依赖、状态变化、错误恢复等能力路径定向合成交互，并保留失败调用作为上下文，但通过损失掩码取消对无效动作的模仿监督。系统还按能力路径分配样本深度，并采用父级交互归一化，避免一条交互因渲染成多行样本而获得过高训练权重。在五个 Qwen3 尺度上，仅使用全参数 SFT 即将 Tau1 与 Tau2 等权均值从 20.04 提升至 40.92，其中 4B 模型在 Tau2 上达到 69.17，超过 Qwen3-30B-A3B 的公开起点。

用途与启示
  • 为工具智能体构造包含跨步依赖、状态变化和错误恢复的数据，而非单纯扩充成功轨迹数量。
  • 将监督信号落实到单个决策，减少无依据动作、错误调用和顺序错误对模仿学习的污染。
  • 在固定 token 预算下优先覆盖更多能力路径，并控制每条路径的支持深度，避免重复样本挤占训练预算。
  • 对多轮轨迹拆分、思维链子问题等数据管线采用父级归一化，防止渲染次数造成隐性权重漂移。
  • 提示后续可探索在策略采样与在线认证，但需进一步评估逐决策认证的成本和判据稳定性。

BHI：为158个LLM评测基准评估健康度

阿里数据团队提出基准健康指数 BHI，从能力区分度、抗饱和度和影响力三个维度评估158个主流评测基准的持续有效性。

★ 2 子主题：评测审计 机器之心  EvalEvolve

 模型评估 动态基准测试 测量效度 评估透明度

原文：https://mp.weixin.qq.com/s/UdJ6nxf_nf_UJ3MHvZUQ7Q
  • 研究基于117个模型的技术报告整理出158个评测基准，并提出基准健康指数（BHI），用于诊断基准是否仍能提供有价值的模型比较结果。
  • BHI 综合考察能力区分度、抗饱和度和能力加权的实际采用影响力，并通过留一基准法（LOBO）避免使用被评基准自身估计模型能力造成循环评价。
  • CRITIC 方法为三个维度分配数据驱动权重，最终排名中 Humanity’s Last Exam、Agents’ Last Exam 和 AutomationBench 位列前三。
  • 消融实验、外部健康状态对照及随机移除30%模型后的稳定性分析表明，BHI 能较稳健地识别饱和或仍处于前沿的基准，但仍受提示词、工具配置和测试条件差异影响。
用途与启示
  • 为模型开发者选择仍具区分力和挑战空间的评测基准提供量化依据。
  • 支持定期识别分数压缩、天花板效应及采用热度与实际价值脱钩的问题。
  • 可作为动态维护评测套件、淘汰饱和基准和引入新基准的审计工具。
  • 提醒评测实践不能只依赖引用量或单一跑分，应结合多维指标与持续更新的数据。

OSWAM：单步动作生成的世界动作模型

OSWAM通过想象令牌与未来条件特权信息蒸馏，将世界动作模型的动作生成压缩至单次扩散步骤，在自动驾驶和具身控制中实现约3倍加速及最低40毫秒实时推理。

  • 直接策略世界动作模型虽然省去了显式未来视觉预测，但通常仍需数十次去噪才能生成高质量动作，难以满足实时控制需求。
  • OSWAM使用“想象令牌”初始化扩散过程，为动作生成注入物理先验与动作条件表征，避免从随机噪声中反复恢复连贯动作序列。
  • 该模型进一步采用带未来条件的特权信息蒸馏，增强单步生成动作对未来状态的感知能力。
  • 实验显示，OSWAM仅用一次扩散步骤即可达到或超过多步WAM基线，推理速度提升约3倍，并在NVIDIA RTX 5090上实现最低40毫秒的编译推理延迟。
用途与启示
  • 为自动驾驶与机器人控制提供低延迟的世界动作模型方案，适合实时闭环决策。
  • 表明结构化动作先验可替代部分迭代去噪计算，为扩散策略的单步化提供设计思路。
  • 可将未来信息作为训练期特权信号进行蒸馏，在不增加部署期开销的情况下提升动作质量。
  • 为评估动作生成模型时同时考察任务性能、去噪步数和端到端延迟提供参考。

HiFOR：动作引导世界锚定与分层前瞻的视觉-语言-动作模型

 具身智能 世界模型 具身基础模型 任务规划 时序建模

论文：https://arxiv.org/abs/2610.40373
