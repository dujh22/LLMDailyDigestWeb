JEPA-Anything：跨异构世界的通用预测模型

JEPA-Anything通过正交预测因子分解，在视觉、生物、临床、控制、分子动力学、物理场和天气等异构领域中统一学习表征、干预效果与长期动态。

 世界模型 跨域泛化 科学发现 时序建模

论文：https://arxiv.org/abs/2609.20800

JEPA-Anything提出正交预测因子分解（OPF），将潜在预测目标拆分为互补因子，经专用路径学习后在统一架构中重新组合。该方法覆盖视觉、生物、临床轨迹、控制、分子动力学、物理场和天气七类领域，并评估表征学习、干预预测、分布外泛化与长时程动力学能力。相较匹配的JEPA基线，它在10项动力学任务上均提升指标，并将Interventional Pong的单次干预预测误差降低34.8%。在四种分子系统中，该方法取得最低的单步和100步滚动误差，其生物干预发现还获得细胞共培养、类器官、肿瘤组织及小鼠实验支持。

用途与启示

  • 可用于干预效果预测、长期动力学模拟和分布外泛化研究。
  • 展示潜在因子不仅能提升预测性能，还可支持具有实验验证的科学发现。
  • 为构建连接视觉、生命科学、物理系统与控制任务的通用预测基础模型提供参考。

RiskChainBench：混淆消息还原与证据驱动网络调查基准

RiskChainBench 将混淆平台消息还原、目标网站路由和基于多模态证据的风险调查串联评测，揭示稳定网页探索与风险判断是当前模型的主要瓶颈。

子主题：安全评测 Hugging Face Papers 

 模型评估 网络安全 智能体评估 证据推理 安全沙箱

论文：https://arxiv.org/abs/2609.16900

RiskChainBench 包含来自 600 个源会话的 3,600 条合成混淆文本，以及 600 个经人工标注、可重置的本地网页环境。评测首先要求模型还原消息、操作意图和目标入口，再由同一底层模型作为 VLM 网页智能体调查对应网站并生成带证据引用的风险报告。基准分别衡量入口恢复与正确路由后的网页调查，并以冻结的首选入口预测作为门控离线组合两项结果。十个模型的入口 Top-1 准确率为 35.2%～95.2%，网页风险决策准确率为 26.3%～62.8%；31.9% 的网页运行出现执行失败，说明稳定探索和风险判断远比决策后的细粒度分类更具挑战。

用途与启示
  • 用于端到端评估模型从混淆信息解码、目标定位到网页风险取证的完整能力。
  • 将路由错误与网页调查错误分开计量，有助于定位安全智能体在感知、执行和判断环节的失效原因。
  • 可重置本地沙箱适合开展可复现的网络安全评测，并避免直接访问真实高风险网站。
  • 结果提示后续研究应重点提升网页智能体的执行稳定性、证据获取完整性与风险判断可靠性。

 社会智能 模型评估 多智能体系统 行为建模 交互式评估

论文：https://arxiv.org/abs/2609.17496

Fuse 是一个面向用户中介社会推理的多智能体模拟框架，其中具有隐藏动机的目标智能体与用户等角色交互，再由用户向待评估助手咨询目标动机。该设计通过模拟设定直接提供可验证的动机真值，并以包含 2.4 万条标注的人类研究验证模拟的忠实性。研究评估了 12 个 LLM，发现用户转述会进一步增加社会推理难度，模型也会系统性地受到用户偏见性表述影响。实验还表明，模型可能需要比人类更多的信息才能正确判断，而更长的对话即使允许澄清提问，也不一定提升表现。作者开源了 Fuse 及包含 2.1 万个样例的数据集。

用途与启示
  • 为难以获得客观真值的社会推理任务提供可控、可验证的评测方法。
  • 可用于分析用户叙事偏差、信息量和对话长度对助手判断的因果影响。

SELF-INDEX：自我进化的搜索索引

SELF-INDEX 通过自主诊断检索缺陷、修订并验证索引键及模拟潜在查询，使搜索索引能够适应检索环境并持续自我进化。

子主题：数据自演化 Hugging Face Papers  DataEvolve

 自演化 检索增强生成 数据工程 智能体 智能体记忆

论文：https://arxiv.org/abs/2609.19656

论文提出 SELF-INDEX 框架，以减少搜索索引优化过程中对人工诊断和策略调整的依赖。其 Optimizer 会定位导致检索失败的索引键，选择性修订相关表示，并在更新索引前验证修订效果。Query Simulator 还能主动生成额外的信息需求，使索引不局限于已有优化查询，而是持续探索潜在检索场景。实验表明，该方法在多种语料库和检索器上优于现有索引优化方法，并能提升搜索智能体及智能体记忆系统的效果与效率。

用途与启示

  • 可将“诊断—修订—验证”闭环用于索引键、文档摘要及其他检索表示的持续优化。
  • Query Simulator 展示了通过合成潜在查询主动发现索引盲区的思路，可用于提升长尾需求覆盖率。
  • 对智能体长期记忆具有启示：记忆索引可根据实际访问失败和模拟需求持续重组，从而提高历史交互的召回质量。

研究发现学生与教师模型对功能等价 EOS 标记的偏好不一致，会抑制正常终止并引发在策略蒸馏中的响应长度膨胀。

子主题：在策略蒸馏 Hugging Face Papers 

 在策略蒸馏 模型蒸馏 模型训练 停止策略 词元选择

论文：https://arxiv.org/abs/2609.20511

论文研究在策略蒸馏（OPD）中学生响应持续变长、甚至耗尽生成预算的问题，并将终止标记不匹配识别为重要成因。实验显示，在 Qwen3、Llama 和 Gemma 系列中，基础学生模型与后训练教师模型可能将停止概率分配给不同的 EOS 标记，即使双方声明的停止集合相同。仅对齐解码阶段的停止集合并不足以解决问题，而将功能等价的 EOS 标记视为共享的语义停止动作，可在三个模型家族中显著缓解长度膨胀。对 K2-Horizon 不同训练阶段的分析还发现，终止偏好会随训练明显变化，且 OPD 后期仍存在无法完全由 EOS 对齐解释的另一类长度膨胀。

用途与启示
  • 在实施在策略蒸馏时，应检查教师与学生在各类 EOS 标记上的概率分布，而不能只比较配置中的停止集合。
  • 可将功能等价的终止标记合并为统一语义动作，以降低错误的继续生成倾向和推理成本。
  • 训练监控应分阶段跟踪输出长度与终止偏好，及时识别后期出现的独立长度膨胀机制。
  • 该研究提示蒸馏目标需显式处理词表及终止语义差异，以改善训练与推理行为的一致性。

AgentLoop 将历史运行轨迹自动沉淀为可追溯经验，通过 Skill 按需召回，并以消融实验优化注入策略，实现智能体耗时、成本与工具调用量的显著下降。

 智能体 经验学习 智能体记忆 检索增强生成 系统优化

原文：https://mp.weixin.qq.com/s/wYgU7rQEt-31j7sd-QRoJA?scene=1

AgentLoop 经验库从智能体运行轨迹中自动挖掘成功与失败模式，将其转化为可复用且可追溯至原始 Trace 的经验资产。智能体通过 alibabacloud-agentloop-experience Skill 检索相关经验并注入上下文，无匹配经验时则不召回，以降低噪声和错误经验的干扰。消融实验分别考察召回阈值、注入条数、上下文位置、经验瘦身和防护护栏，演示场景最终采用 0.6 阈值与 top1 经验。相较无经验基线，优化后的注入策略使耗时降低 30%～40%、成本降低 20%～47%，同时大幅减少 Token 消耗和工具调用。

用途与启示
  • 为智能体构建从执行轨迹到经验沉淀、检索召回和运行反馈的自动化经验学习闭环。
  • 表明经验注入并非越多越好，应通过业务场景下的消融实验确定阈值、数量、位置及压缩策略。
  • 经验需保留来源追溯与历史参考护栏，避免过时或不相关经验被模型机械执行。
  • 可将耗时、成本、Token 和工具调用次数作为经验库上线前的量化验收指标。
