CoEvo-RSI：模型与测试框架协同演化

CoEvo-RSI通过双向历史继承、检查点选择或合并及轨迹微调，缓解递归自我改进中模型能力与演化执行框架之间的“脑—身体”错配。

★ 3 子主题：协同演化 Hugging Face Papers  HarnessEvolve AgentEvolve EvolveLLM Awesome-RSI SystemEvolve

 模型与框架协同优化 智能体脚手架演化 递归自我改进 执行反馈 模型训练

论文：https://arxiv.org/abs/2610.25078

CoEvo-RSI关注模型与执行框架协同演化时长期被忽视的“脑—身体”错配：框架可能要求模型尚未学会的行为，也可能限制模型已有能力。框架由元智能体利用共享演化档案和执行反馈，协调历史框架设计继承、模型检查点选择或合并，以及面向当前框架的后续适配。训练仅使用模型自身经拒绝采样得到的轨迹进行监督微调，使Qwen3.5-9B在多智能体故障归因、角色感知Text-to-SQL和智能家居指令遵循等任务上具备竞争力。该系统在TraceElephant上较DeepSeek-V4-Pro提升14.16点智能体准确率，并在HomeBench VM上较GLM-5.3提升4.90点成功率。

用途与启示
  • 表明智能体自我改进不能只演化执行框架，还需同步选择、合并或适配模型检查点。
  • 可利用历史演化档案复用有效的模型能力与脚手架设计，降低每轮协同演化的训练成本。
  • 为小参数模型在垂直任务中追赶更大模型提供了基于执行反馈和自生成轨迹的训练路径。
  • 提示评测智能体系统时应单独检查模型能力、框架约束及二者接口错配造成的性能损失。

RSIGame：自主试玩、修复与迭代的游戏开发智能体

RSIGame通过局部开发闭环与全局质量控制，使智能体持续试玩、诊断、修改和验证游戏，并将开发经验用于训练底层模型，实现作品与开发能力的双重自我改进。

★ 3 子主题：递归自我改进 未知  TaskEvolve CodeEvolve AgentTrainEvolve

 智能体 递归自我改进 长程任务 执行验证 经验学习

论文：https://arxiv.org/abs/2609.39045
代码：https://github.com/WenyiWU0111/RSIGame
原文：https://mp.weixin.qq.com/s/kPASsLuAtoiAR_iBDV05PA

RSIGame将游戏开发构造成递归自我改进过程：Local Loop由Controller、Explorer、Editor和Verifier协作完成问题发现、代码修改与交互验证，Global Loop则保留最佳检查点、监测质量退化和判断迭代饱和。系统在GameCraft-Bench的140个任务、15类游戏及Godot、Phaser两种引擎上进行评测，能比普通迭代开发更稳定地将开发预算转化为质量提升，并将GPT-5.5初始游戏的评分从50.26提高到64.53。团队收集了2,213条游戏生成轨迹、2,108条规划轨迹和4,003轮改进记录，其中2,013轮通过独立验证，并用这些经验监督微调Qwen3.8-27B。经验训练后的27B模型配合RSIGame取得61.38分，超过GPT-5.5一次生成的50.26分，同时显著降低一次生成的Token消耗。

用途与启示
  • 为缺少明确通过条件的开放式开发任务提供“探索—修改—验证—全局监控”闭环范式。
  • 表明长期自主开发不能仅靠增加迭代轮数，还需要最佳检查点保留、退化防护和饱和停止策略。
  • 展示如何把经过独立验证的智能体执行轨迹转化为训练数据，提升较小模型的规划、诊断和开发能力。
  • 可迁移到软件开发、交互内容生成等需要持续发现目标并验证改进效果的长程任务。

ScholarEvolve：从科研文献中持续演化 Agent Harness

UCSB 与微软提出 ScholarEvolve，通过自动检索论文、实现候选算法并进行组合评估，在不更新底层模型参数的情况下持续演化 Agent Harness。

ScholarEvolve 将 Agent Harness 拆分为工具、上下文、技能、记忆和工作流五类模块，并根据执行轨迹识别能力缺口。Research Agent 从 arXiv、论文附录和 GitHub 实现中检索解决方案，利用 Topic Modeling 覆盖不同技术机制，再由 Coding Agent 将候选方法实现为代码。系统通过验证任务筛选模块改进并搜索有效组合，避免单个最优组件组合后出现性能退化。在不修改底层模型参数的情况下，Qwen3.5-27B 在 AppWorld Challenge 上的任务完成率由 49.6% 提升至 63.6%，并能随新论文加入持续迭代。

用途与启示
  • 展示了以科研文献作为外部创新源、持续改进智能体脚手架的可行路径。
  • 说明智能体性能提升不必完全依赖参数训练，工具、记忆、上下文和工作流等系统组件同样具有较大优化空间。
  • 模块改进需要经过端到端组合评估，不能仅依据单模块成绩进行集成。
  • 可用于构建自动完成文献检索、算法复现、代码修改和实验验收的闭环科研工作流。

阶跃星辰开放 Step 5 Preview 权重，面向长程 Agent

阶跃星辰开放面向长程 Agent 的 Step 5 Preview 权重，以稀疏 MoE、百万 token 上下文、可验证环境和端到端上下文压缩训练提升复杂任务执行能力。

Step 5 Preview 提供 BF16 与 FP8 权重，采用总参数 600B、每 token 激活 27B 的稀疏 MoE 架构，并原生支持文本、视觉输入和 100 万 token 上下文。模型使用 92 层窄深架构、Sparse GQA，以及滑动窗口注意力与稀疏全局注意力交替配置，以控制长上下文计算开销。训练体系覆盖百万级可验证环境和长程任务强化学习，并显式关注合成任务的难度、多样性、验证质量及奖励作弊问题。上下文压缩被纳入端到端策略训练，使 Agent 在预算耗尽前整理可恢复状态，但其长程可靠性仍需通过真实工作负载、人工接管率和多轮压缩后的任务完成率验证。

用途与启示
  • 为跨文件代码修改、工具反复调用和专业知识工作等长程 Agent 场景提供开放权重基础模型。

  • 提醒部署方区分激活参数量与实际资源门槛，并以端到端任务耗时、资源消耗和人工接管次数评估价值。
  • 可在企业代码仓库、业务文档和金融工作流中测试任务完成率、信息追溯及工具调用失败后的恢复能力。

PAR：进度对齐循环机制提升状态跟踪长度泛化

PAR通过对齐循环迭代进度并锚定隐状态范数，使语言模型在状态跟踪任务上泛化至训练长度16倍的序列。

★ 2 子主题：状态追踪 Hugging Face Papers  GeneralizeEvolve EvolveLRM NewModel

 状态追踪 长度泛化 循环计算 推理 模型训练

论文：https://arxiv.org/abs/2610.27628

PAR要求第 $k$ 次迭代的预测对应前 $k$ 个操作后的状态，从而将循环深度与任务进度显式对齐。该方法还将循环状态缩放至首次迭代的范数，以抑制重复更新造成的状态尺度漂移。在 swap-$S_5$ 上，仅使用最长32步数据训练的 Qwen2.5-0.5B，在512步任务上取得95.5%的平均完整状态准确率。消融实验表明，移除范数锚定会使外推倍数从16倍降至不足2.2倍；缺少中间标签时，可通过前缀自蒸馏从最终答案中学习进度对应关系。

用途与启示
  • 为循环语言模型的测试时深度扩展提供明确的训练目标，使额外迭代真正对应任务进度。
  • 表明长度泛化不仅依赖中间状态监督，还需要控制循环隐状态的尺度稳定性。
  • 前缀自蒸馏可在缺少中间标签时构造进度监督，适用于更广泛的序列状态跟踪任务。
  • 学习式完成度读出能够自主决定停止时机，减少对预设循环深度的依赖。

VLA-Rolling：自适应复用动作尾部以加速具身控制

VLA-Rolling通过继承动作尾部并按置信度自适应分配去噪预算，在冻结VLA模型的情况下以更少去噪步骤提升控制成功率和推理速度。

★ 2 子主题：推理效率 Hugging Face Papers  RobotEvolve SystemEvolve

 具身智能 推理加速 缓存优化 任务规划 成本优化

论文：https://arxiv.org/abs/2610.25043

流匹配视觉-语言-动作模型通常只执行动作块的短前缀，并在重新规划时丢弃其余动作尾部。VLA-Rolling将动作尾部视为可复用的中间状态，通过动作尾部继承、逐动作置信度估计，以及置信度引导的重新加噪和去噪预算分配进行优化。该框架不修改底层VLA参数，可适配 π₀.₅、SmolVLA、X-VLA 和 MolmoAct2。在LIBERO、MetaWorld、LIBERO-Plus和RoboTwin 2.0的16组模型与基准组合中，其最高实现1.48倍加速，并在14组实验中提升成功率，最大增幅为15.08个百分点。

用途与启示
  • 将上一轮未执行的动作预测作为可复用推理状态，避免每次规划都从高斯噪声重新生成。
  • 利用逐动作置信度动态调整重新加噪程度和去噪计算预算，在效率与控制质量之间自适应权衡。
  • 为冻结式VLA部署提供轻量级推理优化方案，无需重新训练即可降低动作块生成成本。
  • 表明具身控制中的历史动作尾部可以充当跨规划周期的隐式缓存和暖启动状态。

Ropedia W0：利用人类经验扩展跨具身运动操作世界模型
