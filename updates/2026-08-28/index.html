  • 三种核心范式依次为人类专家手工优化、Meta-Harness 使用外部 coding agent 搜索完整 Harness 源码，以及 Self-Harness 让同一固定模型兼任执行者与 proposer，通过失败模式挖掘、有界编辑和 held-in/held-out 非回归门实现可审计的自我改进。

  • EnvHarness、Prime Agent 与 MetaCaster 将 Harness 自进化进一步扩展到环境、权重通道和非编码领域，各方案均强调依据真实执行结果而非文本合理性验收改动。
  • 现有方法仍受验证器质量、基准特化、评估成本和可编辑范围限制，需要结合安全性、稳定性及跨任务泛化能力判断更新是否有效。

  • 采用“失败聚类—有界提议—执行评估—非回归验收”的闭环，并结合结构化补丁与双分区回归测试，降低轨迹过拟合和能力回退风险。
  • 针对不同基础模型自动搜索适配的提示、工具、上下文与恢复策略，避免直接复用单一 Harness 造成性能失配并降低人工维护成本。

  • 在高风险或开放式自进化场景中，除任务通过率外，还应纳入安全、成本、稳定性和跨任务泛化等验收指标。

用途与启示

  • 适合作为比较不同智能体数据生成方法、评测协议、训练方案和扩展策略的综述框架。
