WorkRover：递归环境演化扩展长程协同智能体训练

WorkRover 利用执行反馈递归修复训练环境，并通过确定性验证器将终端奖励分配到具体回合，显著提升长程协同智能体的训练效果与环境可靠性。

★ 3 子主题：环境合成 未知  EnvironmentEvolve AgentTrainEvolve HarnessEvolve

 环境合成 长程智能体 强化学习 信用分配 执行反馈

论文：https://arxiv.org/abs/2610.18067
原文：https://mp.weixin.qq.com/s/L8qvtmlLsReDbMcyGqaigg

WorkRover 将 Harness 驱动的环境合成、递归环境演化 FCR 与验证器引导的信用分配 VTCA 结合，用于训练操作文件、工具和应用的长程协同智能体。FCR 在工作上下文、任务、执行框架和验证器的依赖闭包内组合重放修复方案，以最小组件改动解决缺陷，同时保持任务意图、信息边界和评估契约不变。VTCA 使用冻结的确定性检查计算逐回合状态进度，并根据实际依赖关系把部分正向信用分配给有效的前置回合，负向信用则保留在本地回合。基于 Qwen3.5-35B-A3B 的实验显示，WorkRover 在五个外部协同智能体基准的同规模开源模型中均排名第一；FCR 还将环境安全解决率从 60.7% 提升至 70.3%，并将初始合成通过率从 49.8% 提升至 74.8%。

用途与启示
  • 展示如何让智能体执行反馈同时服务于训练环境维护和策略学习，形成环境与智能体相互促进的闭环。
  • FCR 可用于修复上下文、任务和验证器之间的联动缺陷，避免整体重生成带来的意图漂移与额外成本。
  • VTCA 为长程任务中的延迟贡献提供可复现、依赖感知的信用分配方案，减少稀疏奖励和主观 Judge 带来的噪声。
  • 冻结评估契约、验证器及随机条件的设计可提升环境修复对比的公平性，并抑制奖励作弊。

CMU开源Hermit：统一Harness层RSI与持续学习框架

卡内基梅隆大学开源Hermit，通过外置可插拔Harness Adapter统一训练、评估和部署流程，使Codex、Claude Code等智能体无需修改底层模型即可基于任务反馈持续进化。

★ 3 子主题：脚手架演化 智猩猩AI  HarnessEvolve AgentEvolve SystemEvolve

 智能体脚手架演化 递归自我改进 持续学习 人工智能框架 智能体评估

原文：https://mp.weixin.qq.com/s/fOHC43ehv6LZgOOMsRsMNw

Hermit是面向Harness进化、持续学习与递归自我改进的统一训练框架，将学习机制置于原有Harness之外，避免破坏其内部组件与运行流程。框架通过可插拔Adapter形成“任务执行—结果评估—反馈驱动修改—合法性验证—版本保存”的闭环，并允许适配器在兼容的模型与Harness之间迁移。Hermit已支持GEPA、SkillOpt、MetaWorld Model、Harness²和Continual Harness等方法，可在统一模型、工具、评估器和Benchmark条件下进行相对公平的比较。训练所得规则还能部署至Codex工作区等宿主，让智能体在后续任务中复用积累的执行经验。

用途与启示
  • 为不同Harness进化与RSI算法提供统一实验接口，减少因Benchmark、工具和评估配置不一致导致的比较偏差。
  • 通过外置Adapter支持黑盒模型和既有Harness的持续学习，降低系统改造成本及内部逻辑受损风险。
  • 可将任务反馈沉淀为可版本化、可迁移和可部署的规则或配置，为Codex、Claude Code等编程智能体构建经验积累闭环。
  • 适合作为Harness层递归自我改进、算法消融和跨智能体迁移实验的基础设施。

LongZero：零外部数据增强长上下文推理

LongZero 让语言模型自主合成长上下文多跳推理与多轮检索任务，并通过 GRPO 训练，在无需外部语料或教师模型的情况下提升长上下文推理能力。

★ 3 子主题：数据合成 Hugging Face Papers  DataEvolve EvolveLRM

 长上下文 数据合成 强化学习 推理 自我改进

论文：https://arxiv.org/abs/2610.30132

LongZero 面向强化学习所需的长、多样、困难且可验证的数据稀缺问题，提出完全不依赖外部数据的任务合成方案。模型先以紧凑结构生成问题、答案及支撑证据，再将证据独立扩展成长篇多文档上下文，从而降低直接生成长任务的难度。训练数据同时包含自主生成的多跳推理任务和多轮检索任务，并使用 GRPO 进行强化学习。两个语言模型在五项长上下文推理基准上的实验表明，该方法能够泛化到真实任务，并优于基于外部语料合成数据的基线。

用途与启示
  • 为缺少高质量长上下文训练数据的场景提供零外部数据增强路径。
  • 将结构化证据生成与长文档扩展解耦，可提高合成任务的可验证性与长度可控性。
  • 表明自生成任务结合强化学习能够提升真实长上下文、多跳推理及检索能力。
  • 可用于构建随模型能力持续演化的数据生成与自我改进闭环。

CausGround：基于因果交互定位的自适应具身规划

CausGround 将交互经验提炼为可复用的动作前置条件与效果知识，无需参数更新即可提升跨环境的长程具身规划、动作恢复与验证能力。

★ 3 子主题：具身规划 Hugging Face Papers  RobotEvolve AgentEvolve

 具身智能 任务规划 长程任务 世界模型 状态表征

论文：https://arxiv.org/abs/2610.29702

CausGround 是一种非参数因果交互定位框架，将交互经验组织为以动作为中心的因果知识，显式刻画动作的前置条件和执行效果。框架采用因子化世界状态表示描述物体属性及物体间关系，并在规划时结合当前观测定位与任务相关的因果依赖，通过前置条件的反向推理和动作效果的前向推理选择动作。在 VirtualHome 上，该框架将视觉高层规划的平均任务成功率从 24.9% 提升至 53.3%；在 RoboCasa 上将闭环规划成功率从 43.0% 提升至 57.0%。SWITCH 评测与真实机器人实验进一步表明，该方法能够改善交互推理、失败恢复和动作验证，并生成可执行的连续操作序列。

用途与启示
  • 为具身智能体提供可跨环境复用的显式动作因果知识，减少针对特定环境重新训练的成本。
  • 将动作前置条件与效果纳入规划，可同时支持目标驱动的反向规划和结果预测式的前向验证。
  • 因子化世界状态有助于积累结构化交互经验，并提升长程任务中的动作选择、错误恢复与执行可靠性。
  • 该非参数方案可作为不同 MLLM 主干之上的规划增强模块，适用于仿真环境和真实机器人操作。

RealCLI：统一评估 CLI 智能体的人机协作

RealCLI 通过配对执行模式和多维协作指标评估真实 CLI 任务，揭示前沿智能体在可操控性、信任校准及安全边界管理方面的明显短板。

★ 2 子主题：交互式评测 Hugging Face Papers  EvalEvolve HumanEvolve HarnessEvolve

 智能体评估 交互式评估 人在回路 长程任务 工具调用

论文：https://arxiv.org/abs/2610.22507

RealCLI 是面向 CLI 智能体的配对评测基准，同时衡量任务执行效果与运行时人机协作质量。其评估框架包含 5 个维度、22 个子维度和 51 类交互场景模板，并提供一次性给出完整需求的 RealCLI-Exec 与渐进提供信息、修正、约束和授权的 RealCLI-Collab 两种模式。实验中最佳配置的平均得分仅为 49.2%，联合协作分数最高仅为 37.6%。结果表明，任务完成效果并不等同于良好协作，当前智能体尤其欠缺可操控性、信任校准和安全边界管理能力。

用途与启示
  • 为 CLI 智能体建立兼顾任务结果与交互过程的统一评估框架。
  • 可用于诊断智能体处理需求变更、用户纠正、权限授权和渐进信息时的失效模式。
  • 提示开发者不能仅以任务成功率衡量长程智能体，还应纳入可操控性、信任校准与安全边界指标。
  • 配对评测模式有助于量化静态完整指令与动态人机协作场景之间的性能差距。
