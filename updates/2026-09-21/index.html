独立研究者Michael Hla使用约220亿token的1900年前语料，从零训练了33亿参数模型GPT-1900，并补充约2.9亿token的历史物理文献。模型在经过精心组织的光电效应问题上，一度提出光可能由彼此分离的部分组成，与爱因斯坦的光量子解释相似，但在多数物理任务中表现不佳。实验的指令数据生成和强化学习评分使用了Claude等现代模型，加之历史语料难以彻底去除后世知识，使“重新发现”与知识泄漏或召回难以区分。研究者认为，真正的科学智能不仅要生成新解释，还要自主发现重要问题、完成溯因推理、判断理论价值，并通过实验持续验证和修正。

用途与启示
  • 为评测AI科学创造力提供“历史知识截止”思路，以已知科学史作为可对照的发现轨迹。
  • 提醒科研智能体评测必须严格审计训练数据、合成指令、奖励模型和提示中的答案泄漏。
  • 评测重点不应停留在是否复现正确理论，还应覆盖问题发现、理论筛选、实验设计与自我修正能力。

英伟达 SoL-Pi：智能体 Harness 的递归自我进化

SoL-Pi 通过自动研究循环持续优化智能体 Harness，在基本保持任务性能的同时，将代码智能体的 Token 流量降低约一半。

子主题：脚手架演化 模智空间  HarnessEvolve Awesome-RSI

 智能体脚手架演化 递归自我改进 成本优化 人工智能辅助编程 上下文压缩

原文：https://mp.weixin.qq.com/s/HGMw_y35WDgt0GqdQXBwAw

SoL-Pi 不修改底层大模型，而是让研究智能体分析执行轨迹、提出 Harness 改进方案，并通过能力与效率双重闸门筛选有效机制。最终方案包含 Action Fusion、Online Context Compact、ObservationPack 和 Evidence-Preserving Reducer，分别减少动作交互、按收益压缩上下文、避免重复传输大输出，并在保留关键证据的前提下精简日志。EdgeBench 实验中，效率优先配置在 GPT-5.6 Sol 上减少 49.0% Token 流量、降低约三分之一 API 成本，同时保留 93.7% 的任务得分；迁移至 Opus 5 后仍取得相近效率收益。该方法还可用于多智能体集群，但跨模型触发率差异、自动搜索成本及训练评测隔离仍是后续重点。

用途与启示
  • 展示模型层优化之外的降本路径：通过演化智能体 Harness 减少无效交互、上下文和日志开销。
  • 为代码智能体设计可组合的运行时优化组件，并用能力与效率双指标控制性能退化。
  • 提示自动进化研究必须严格隔离开发任务与最终评测集，避免基准过拟合和结果虚高。
  • 可进一步探索多模型联合优化、Harness 预训练，以及利用更高效的 Harness 反哺下一轮递归改进。

Environment Evolution：让终端智能体的训练环境持续进化

混元提出面向终端智能体的环境演化框架，通过离策略提升难度并分代调度演化环境，为长程强化学习持续提供有效信号，在 Terminal-Bench 2.1 上显著提升模型表现。

子主题：环境合成 arXiv 

 环境演化 智能体 强化学习 长程任务 多智能体系统

论文：https://arxiv.org/abs/2609.04128

论文针对静态或从零合成的环境很快落后于前沿智能体能力、难以持续提供学习信号的问题，提出 Environment Evolution 框架。该方法从多轮学习目标中推导出三个影响环境难度的演化方向，并通过循环工程化的多智能体脚手架，以离策略方式逐步提高难度、分代调度环境。演化过程持续生成接近或超出智能体当前能力边界的任务，同时控制任务分布偏移，以稳定暴露模型弱点。使用简单的长程强化学习训练后，Qwen3.6-27B 与 Qwen3.6-35B-A3B 在 Terminal-Bench 2.1 上分别提升 14.4 和 18.0 个百分点。

用途与启示
  • 为终端智能体构建可随模型能力增长而持续升级的交互式训练环境，缓解静态环境学习信号枯竭问题。
  • 将环境难度演化与分代调度结合，可用于提高长序列规划、鲁棒性及未知终端场景下的自适应决策能力。
  • 离策略环境演化降低了对当前策略在线轨迹的依赖，为环境生成与智能体训练解耦提供了参考。

用途与启示
  • 为辨析自我反思、自训练、有界 RSI、递归自我加速与开放式 RSI 提供分层框架。
  • 提醒研究者不能仅凭任务分数提升判断 RSI 已经“点火”，还需直接测量新版本产生后续改进的能力。
  • 可用于设计 RSI 评测，重点考察跨轮增益、隐藏任务泛化、资源约束下的持续性和评估独立性。
