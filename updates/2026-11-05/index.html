SwarmRSI：共享失败经验驱动科研智能体群递归自我改进

华为团队提出 SwarmRSI，通过共享研究图谱保存并重组假设、程序、证据与失败经验，使科研智能体群在跨代继承中持续提升效果并降低搜索成本。

★ 3 子主题：递归自我改进 小扬  SwarmEvolve ResearchEvolve AgentEvolve Awesome-RSI

 递归自我改进 多智能体系统 自动化科学研究 经验学习 智能体记忆

论文：https://arxiv.org/abs/2610.20431
原文：https://mp.weixin.qq.com/s/pnVW6eZfSydjemE50iFwjQ

SwarmRSI 将假设、程序、实验证据和未解决需求写入共享研究图谱，使失败实现与半成品也能成为后续智能体的可继承资产。系统通过反馈引导的群体变异区分假设问题与实现问题，并利用 Rebase 和 Crossover 将好想法迁移到更可靠的程序底座或重组互补组件。实验显示，其在 OpenProblems、NatureBench 和 MLE-Bench Lite 上优于多种科研智能体基线；继承三代经验后，NatureBench 新任务的 Match-SOTA 率由 41.7% 提升至 86.1%，同时 token 消耗下降。约 35% 的失败实现经后续改造成为新最优程序，部分生物信息学结果还由领域专家完成复现。

用途与启示
  • 将失败实验、未兑现假设和局部有效组件纳入长期记忆，而非只保留高分轨迹。
  • 以结构化研究状态作为多智能体协作和跨代演化的基本单位，支持经验复用与证据溯源。
  • 根据反馈分别修复程序实现或调整研究假设，可减少无效重启并提高搜索效率。
  • Rebase 与 Crossover 为科研智能体的经验组合、程序演化和闭环自我改进提供了可复用架构。

VERSE：面向智能体 Harness 的可验证自进化优化器

MIT 与 Amazon 提出 VERSE，通过失败归因、执行重放、因果扰动和训练审计验证 Harness 改动，使冻结权重的智能体实现更稳定的自进化。

★ 3 子主题：脚手架演化 Tau Lab  HarnessEvolve AgentEvolve SystemEvolve

 智能体脚手架演化 自演化 执行验证 轨迹审计 人工智能辅助编程

原文：https://mp.weixin.qq.com/s/42HIenjCaJM6s7hoW3pFMw?scene=1

VERSE 将智能体系统分为任务执行器与 Harness 优化器，两者均可更新提示词、技能、工具、钩子和工作流，但底层模型权重保持冻结。优化器先定位并最小化失败轨迹，再通过草稿执行、失败重放和可疑步骤扰动检查修复效果与因果归因，最后以训练审计记录任务级修复和回归。实验显示，无执行验证的自进化使验证集结果降至 31.79%，加入验证后达到 41.05%；在 SWE-rebench 上，最佳配置取得 42.3% 的同分布成功率和 37.7% 的跨语言 OOD 成功率。结果表明执行验证是 Harness 自进化稳定生效的重要前提，但当前证据仍受单次进化运行、验证预算差异和有限任务分布约束。

用途与启示
  • 为智能体 Harness 优化建立“提出修改—执行验证—审计回归—接受或回滚”的闭环，避免仅凭文本判断保留改动。
  • 可将失败轨迹最小化、执行回放和步骤扰动用于工具调用与工作流故障的因果诊断。
  • 说明智能体自进化不应只追求验证集增益，还需持续监测跨任务、跨语言回归及最后一轮稳定性。
  • 为冻结模型权重条件下改进软件工程智能体提供了低成本路径，重点优化提示词、工具、技能与脚手架。

HarnessPro：兼顾性能与成本的智能体脚手架自进化框架

清华大学与智谱提出HarnessPro，通过轨迹诊断、测试合成和帕累托多目标优化递归演化智能体Harness，在提高任务通过率的同时显著降低执行成本。

★ 3 子主题：脚手架演化 未知  HarnessEvolve SystemEvolve

 智能体脚手架演化 成本优化 递归自我改进 系统优化 数据合成

论文：https://arxiv.org/abs/2610.26770
原文：https://mp.weixin.qq.com/s/07V3GbOZ_bTnQfDcpzJing?scene=1

HarnessPro不修改基座模型权重，而是递归优化系统提示词、工具调用逻辑、内存管理、执行Hook与校验策略等Harness组件。框架通过“轨迹诊断—方案规划与编辑—候选评估筛选”形成闭环，并分别生成成本优先、均衡和性能优先的Lite、Medium、Heavy版本。其利用固定的合成测试用例评估候选，再以基线通过率约束和帕累托支配规则筛选方案，降低LLM自评判带来的过度乐观问题。实验显示，HarnessPro可在Terminal-Bench2、SWE-Bench Pro和ProgramBench上推动性能—成本帕累托前沿，其中Medium版本在接近高性能基线的同时最多降低约53%的单任务成本。

用途与启示
  • 为预算不同的生产业务提供Lite、Medium、Heavy三档可部署Harness，而非追求单一最优配置。
  • 说明智能体成本瓶颈可能来自无效探索、冗余工具输出和缺少停止约束，可优先优化脚手架而非更换基座模型。
  • 可将固定测试合成、轨迹证据诊断和帕累托筛选结合，提升无标签脚手架演化的可靠性。
  • 任务自适应推理预算、工具调用上限和输出压缩可作为智能体系统降本的通用机制。

RSIGym：面向递归自我改进的真实训练环境

RSIGym 通过 Everything as a Service 架构将科研智能体与底层训练、推理和评测设施解耦，为递归自我改进提供受预算约束且可复现的统一实验环境。

RSIGym 将科研智能体置于轻量级纯 CPU 容器中，仅保留代码、数据与实验记录，避免其直接处理 GPU 驱动、依赖冲突等底层工程问题。训练、推理、数据生成、打分和基准评测均被封装为远程微服务，其中训练可通过 Tinker 执行 LoRA 微调，评测则由 Harbor 在隔离云沙盒中并发运行。环境为每次实验设置固定资金预算和权限，使资源调度、数据合成与评测轮次之间的权衡成为自我改进决策的一部分。实验观察显示，盲目增加训练量可能造成性能退化，而分析日志、重构 Harness 并配合轻量微调可能获得更稳定的改进。

用途与启示
  • 为递归自我改进实验提供统一、隔离且可复现的基础设施，减少环境配置对结果的干扰。
  • 将算力、资金和权限纳入智能体决策空间，用于评估其资源调度与科研决策能力。
  • 通过标准服务接口公平比较不同模型，避免底层工程实现差异影响评测结论。
  • 提示 RSI 系统应重视日志分析、脚手架重构和受控微调，而非单纯扩大训练规模。

ToolSpace：面向长程智能体的工具中心环境合成

ToolSpace从真实MCP服务执行轨迹中构建工具组合环境与可验证长程任务，借助规模化合成和强化学习显著提升智能体的跨工具执行能力。

★ 3 子主题：环境合成 Hugging Face Papers  EnvironmentEvolve AgentTrainEvolve

 环境合成 长程智能体 工具调用 数据合成

论文：https://arxiv.org/abs/2611.05036

ToolSpace颠倒传统的数据中心式合成流程，先从真实MCP服务和开放智能体语料的相邻调用中挖掘数据、状态及重试依赖，再聚类工具组合图形成环境。框架仅为改变状态的环境合成数据库，无状态工具和查询工具则重放已记录返回，以提高接口及执行行为的真实性。系统通过带状态感知、回滚机制的随机游走生成调用链，将其反编译为自然语言任务，并使用断言检查与成功重放筛选样本。其生成的Pro版基准令7个前沿模型最多下降38.2分，同时将Qwen3.6-35B-A3B在七项长程工具使用基准上的平均分从23.0提升至41.0，结合强化学习后达到43.2。

用途与启示
  • 为长程工具调用智能体提供可规模扩展、贴近真实接口且具备执行依据的训练环境。
  • 以确定性规则挖掘执行依赖，减少依靠大模型判断工具关系带来的噪声与错误组合。
  • 通过状态回滚、断言检查和初始状态重放，提升合成任务的可执行性与可验证性。
  • 结果表明，扩大工具数据和环境规模可持续改善智能体能力，并可与强化学习进一步叠加增益。

用途与启示

MoviEdit面向长篇多镜头视频，解决场景、视角和主体外观突变时的编辑一致性问题。团队从同步多视角素材、真实多镜头视频和生成内容中自动构建了87K组配对编辑视频，无需人工标注。其级联双向—自回归架构先在时空压缩表征上生成全局一致的编辑草稿，再对完整视频进行自回归传播和细化。配套的MoviEdit-Bench用于系统评估长篇多镜头编辑，实验显示其优于现有开源模型，并在文本及图像引导编辑上达到业界前沿模型水平。

用途与启示
  • 为长视频编辑提供兼顾全局跨镜头一致性与局部细节质量的架构思路。
  • 展示利用多源自动化流水线规模化生成跨镜头编辑监督数据的可行路径。
  • MoviEdit-Bench可用于比较文本引导和图像引导的长篇视频编辑系统。
