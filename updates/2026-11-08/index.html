WildAWM：用合成“个人电脑”训练计算机使用智能体

WildAWM 合成可执行的个人电脑环境、跨 GUI/MCP/CLI 的长程任务及可靠验证器，仅在合成环境中训练便显著提升智能体在八个分布外基准上的表现。

★ 3 子主题：环境合成 未知  EnvironmentEvolve AgentTrainEvolve GeneralizeEvolve

 环境合成 智能体 强化学习 长程任务 跨域泛化

论文：https://arxiv.org/abs/2610.26828
代码：https://github.com/MSR-Orchard/WildAWM
数据集：https://huggingface.co/collections/ChilleD/agent-world-model-in-the-wild
原文：https://mp.weixin.qq.com/s/gamAVH5qDdXx-Y0sXXvodA

WildAWM 使用代码与数据库合成包含文件系统、浏览器、Shell、应用及 MCP 服务的完整个人电脑，共构建36个虚构人物和640个连续世界状态。系统生成必须横跨 GUI、MCP、CLI 的长程任务，并通过评判一致性、初始未完成、可解性、难度和反事实探针五道关卡，从2,551个草稿中筛出341个任务。研究以验证脚本、LLM Judge 和高权限 Agent Judge 共同审计执行轨迹，最终验证器与 Agent Judge 多数投票的一致率达到95%，Cohen’s κ 为0.90。使用 SFT 与 GRPO 训练两个 Qwen 模型后，其在八个未见过的 Web、Claw 和 GUI 智能体基准上均获提升，其中 Qwen3.6-35B-A3B 平均分由42.84升至53.42。

用途与启示
  • 以可复制、可重置且离线隔离的合成电脑替代真实系统，降低计算机使用智能体训练的成本与安全风险。
  • 将环境、任务和验证器联合合成，为长程跨界面任务提供可规模化的强化学习数据与可靠奖励信号。
  • 多智能体试做与分层评判可用于过滤不可解、过于简单或验证器存在漏洞的合成任务。
  • 分布外评测结果表明，复杂合成环境能够促进接口切换、长程执行和跨场景泛化能力。

Firefly：先探索后出题的可验证工具调用数据合成

Firefly 通过先探索真实 API、再反向生成任务，并结合可离线复现的工具调用模拟器，规模化构造真实且可验证的智能体训练数据。

★ 3 子主题：数据合成 DataEvolve  DataEvolve EnvironmentEvolve AgentTrainEvolve

 智能体数据合成 工具调用 强化学习 环境合成 执行验证

论文：https://arxiv.org/abs/2605.17558
代码：https://github.com/leoleoasd/firefly-neurips-2026
数据集：https://github.com/leoleoasd/firefly-neurips-2026
原文：https://mp.weixin.qq.com/s/buhBJF85rFQtmuIT3_GeeA

Firefly 将传统“先出题、后求解”的前向合成流程反转为 Back-Chaining：先让强模型在真实 MCP Server 上探索，再依据实际工具输出生成任务和结构化答案。系统从约 3,000 个 MCP Server 中筛选出 240 个服务器和 993 个工具，构建 Tool Graph，并通过 DAG Exploration 采集真实、可达的多工具调用轨迹。任务经过可验证性、明确性、可解释性、真实性和难度校准等维度的自动验证，最终得到 5,144 个可验证任务。针对真实 API 的环境漂移、服务下线和限流问题，Firefly 使用 Retrieval-Augmented Tool-Call Simulator 缓存并检索真实调用结果，使强化学习训练能够离线复现。

用途与启示
  • 为 Tool-Calling Agent 提供兼顾规模、真实性与可验证性的强化学习训练数据生成方案。
  • 将 ground truth 正确性转化为数据生成过程的构造性质，减少对事后过滤和人工核查的依赖。
  • 通过离线工具模拟器缓解 API 环境漂移、服务不可用和调用限流，提高训练与评估的可复现性。
  • Tool Graph 与 DAG 探索机制可用于扩展跨服务器、多工具组合任务的数据覆盖范围。

Anthropic公开Claude离线“做梦”长期记忆架构

Anthropic展示Claude智能体的分层长期记忆架构，通过任务间歇回放原始记录、纠正错误并构建知识维基，实现跨会话经验沉淀与高效检索。

★ 3 子主题：长期记忆 心兰  MemoryEvolve AgentEvolve

 智能体记忆 长程任务 自我反思 上下文压缩 多智能体协作

原文：https://mp.weixin.qq.com/s/w-GWahEmeSUDwvD1apgc_w
  • 该架构将记忆划分为原始记录、记忆笔记、记忆表征和注入上下文，并利用空闲算力进行离线“做梦”，反复回放和重组历史经验。
  • Claude可根据任务反馈验证规则、记录勘误并清理过时信息；宝可梦实验表明，少量高价值记忆优于无差别记录，离线复盘还能纠正持续误导决策的错误笔记。
  • 面对约35万个文件、4.2亿Token的企业资料库，Claude在128次会话中构建超链接知识维基，结合搜索后将答题得分由53%提升至61%，并降低检索Token消耗。
  • 系统采用分层注入策略，顶层仅保留索引和跳转链接、细节按需检索；“做梦”还可修复多智能体覆盖写入、事实丢失及失效链接等协作问题。
  • 主要工程挑战包括实时记忆与离线整理的取舍、知识漂移、维基过度膨胀，以及如何按记忆调用频率动态分配维护算力。
用途与启示
  • 为跨会话智能体设计“在线记录、离线巩固、按需检索”的长期记忆闭环。
  • 提示记忆系统应优先保存不可直接观察的规律、长期计划和验证证据，而非完整复制即时状态。
  • 可通过原始轨迹回放和矛盾检测定期修正错误记忆，降低错误信息对后续决策的持续污染。
  • 多智能体知识库应采用独立页面、原文证据保留和离线统一编审，避免并发覆盖与事实丢失。
  • 顶层上下文宜保持为轻量索引，以兼顾检索效率、Token成本和指令遵循能力。

Drex：迈向基础决策模型

Drex 发布四款开放权重基础决策模型，通过直接输出候选选项的概率分布，在保持竞争性准确率和顺序鲁棒性的同时显著降低推理延迟。

★ 3 子主题：模型发布 Hugging Face Papers  NewModel JevEvolve

 模型开发 推理加速 强化学习 成本优化 多模态

论文：https://arxiv.org/abs/2611.07854
代码：https://github.com/nace-ai/drex-decision-models

Drex 是一组参数规模覆盖 8B、9B、35B（3B 激活）和 27B 的开放决策模型，可针对文档、记录或智能体上下文直接输出选项概率、二元判断或有序评分。与长思维链等自回归方案不同，它无需生成和解析自然语言答案，能够降低生产环境中的成本、延迟与输出波动。训练流程结合监督微调、基于调整反馈的强化学习（RLAF），其中 Max 版本还加入视觉调优；消融实验显示 RLAF 可提高准确率，一致性损失可增强选项重排鲁棒性。Drex Max 在多个决策基准上达到领先或接近闭源前沿系统的水平，典型请求延迟为 183 毫秒，且四款模型均已开源。

用途与启示
  • 为分类、排序、审核、路由和智能体动作选择提供低延迟的概率化决策接口。
  • 说明非自回归决策架构可在生产环境中替代部分长思维链推理，减少输出解析和部署成本。
  • RLAF 与选项顺序一致性损失可用于提升决策准确率、概率稳定性及候选重排鲁棒性。
  • 开放权重及多种参数规模便于研究基础决策模型的规模扩展、端侧部署与多模态应用。

Naive-N0.5-Flash可根据任务书自主完成数据清洗、模型微调、强化学习、评测修复和早停，并在发现奖励漏洞、过拟合或训练退化时调整方案。文章展示了角色模型、银行客诉分类器、游戏智能体及机器人控制等个人端案例，其中本地BERT分类模型在BANKING77上达到93.34%准确率和6.77毫秒中位响应时间。该模型采用5:1混合稀疏注意力与MoE架构，支持100万token上下文，并结合NaiveRT推理引擎提升长程实验管理和生成效率。文章将AI辅助研发划分为脚本协助、独立训练外部模型、优化自身运行系统和参与研发下一代模型四级路径，认为当前个人用户已开始进入第二级“Vibe Training”。

  • 现阶段更适合采用“人定目标与验收标准、AI执行和试错”的人在回路模式，而非完全无人监督训练。

  • 为研究无需参数更新的具身上下文学习及视觉目标条件控制提供开放基础设施。

ICRPM以前瞻风险预测优化Rollout任务采样

国防科技大学与清华大学提出ICRPM，利用近期任务风险记录预测策略更新后的风险，在无需额外rollout的情况下改善RLVR、Meta-RL和鲁棒控制中的任务选择。

★ 2 子主题：采样控制 量子位  DataEvolve AgentTrainEvolve EvolveLRM

 强化学习 样本调度 风险控制 模型训练 成本优化

论文：https://arxiv.org/pdf/2610.14913
原文：https://mp.weixin.qq.com/s/T4tj9m5pdWWb8K1zTEqwsA
  • ICRPM将近期“任务—风险”记录作为上下文，预测策略下一次更新后的任务风险，而非仅拟合当前风险，从而缓解任务难度排序随训练过程漂移的问题。
  • 方法采用3步滑动窗口与0.9时间衰减系数，在复用稀疏监督信号的同时降低过时策略数据的干扰；消融实验表明，收益主要来自前瞻预测，而非Transformer结构或单纯增加历史数据。
  • 在Meta-RL、Domain Randomization和少样本回归实验中，ICRPM整体改善了风险排序相关性与CVaR尾部表现，例如Walker2dVel的CVaR₀.₉由MPTS的-27.9提升至-1.5。
