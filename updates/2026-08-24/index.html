WorldSimProbe：首个动作条件世界模型评测系统

北京大学与 EvoPhys AI 发布 WorldSimProbe，以动作实现和交互响应为统一标准，沿模拟因果链系统评测动作条件世界模型的物理与因果保真度。

子主题：模拟评测 具身智能之心 

 世界模型 世界评测 具身评测 动作表征 接触评测 物理智能 因果保真 接触幻觉 动作保真

论文：https://arxiv.org/abs/2608.09298
代码：https://github.com/pxxq25/WorldSimProbe
数据集：https://huggingface.co/datasets/petersonco/worldsimprobe_robotwin
原文：https://mp.weixin.qq.com/s/E-cSt-adF3ss2BmNnJtW3Q

WorldSimProbe 提出 Observable Simulator Contract，要求动作条件世界模型既能把输入动作准确转化为机器人运动，也能基于真实接触产生正确的环境响应。评测沿“输入动作 → 机器人运动 → 接触与交互 → 环境变化”因果链设置五项测试，覆盖局部动作校准、全局轨迹覆盖、动作来源特征保持、交互接触验证和交互动力学。基准包含来自 RoboTwin、ManiSkill 和 LIBERO 的 18,608 个受控实例，并评估 IRASim、Ctrl-World、BWM、DreamDojo、LingBot-VA 和 Cosmos-3-Nano 六个开源模型。实验发现，现有模型普遍存在动作响应衰减、轨迹细节丢失、接触幻觉及交互动力学错误，其中复杂的晃动等交互原语尤其薄弱。研究表明，视觉自然或任务成功并不代表模拟正确，单一总体得分也容易掩盖因果链不同环节的能力缺陷。

用途与启示
  • 为动作条件世界模型提供区别于视频逼真度和任务成功率的模拟器评测标准。
  • 可逐段定位动作校准、轨迹保持、接触接地和交互动力学中的具体失效模式。
  • 提醒规划、反事实预测及合成数据应用关注模型的因果保真度，而不只关注视觉合理性。
  • 受控干预与推理前冻结参照的设计，可为具身世界模型基准建设和回归测试提供方法参考。

PlayWorld：Agent 试玩世界模型的长程目标评测基准

PlayWorld 通过可观察、调整和停止的 Agent Player，以场景相关长程目标公平评测世界模型的几何一致性、交互保真度及持续演化能力。

子主题：长程评测 机器之心 

 世界评测 世界模型 智能体 长程任务 交互评测 试玩评测

论文：https://arxiv.org/abs/2608.13552
代码：https://github.com/kxding/PlayWorld
数据集：https://huggingface.co/datasets/jocelynd/playworld-bench
原文：https://mp.weixin.qq.com/s/QP8X8Ph7w3NsdK4A5m4MeQ

PlayWorld 将世界模型的评测单位从固定动作序列升级为场景相关的长程目标，允许 Agent Player 根据生成画面实时修正操作。Agent Player 基于多模态模型作出 Keep、Stop、Extend、Correct 和 End 五类决策，并通过接口转换器适配不同世界模型的控制方式。基准包含人工筛选的 171 个样本和 820 余个 VQA 问题，覆盖几何一致性、交互保真度、视野外演化和视野内演化四个维度。实验显示，当前模型在跨时间和跨遮挡的状态演化、长时重访中的全局空间一致性方面仍存在明显不足，而且到达目标并不代表真正理解和维持了世界状态。

用途与启示
  • 为控制粒度和交互接口不同的世界模型提供更公平、贴近真实用户体验的统一评测方式。
  • 用闭环 Agent 替代僵化的固定轨迹，使评测聚焦于目标是否完成以及完成后的世界状态是否可信。
  • 揭示世界模型需要从短时画面连续性进一步发展到长期空间记忆、物体身份保持、物理反馈和因果演化。
  • 可作为交互式视频生成与具身智能系统开展长程目标评测和失败模式分析的参考基准。

MoE 大模型的计算高效超参数迁移

论文提出两步式超参数迁移框架，利用小规模代理模型跨宽度迁移并沿训练 token 规模外推，以低成本预测超大规模 MoE 模型的最优学习率。

子主题：超参迁移 Hugging Face Papers 

 混合专家 规模定律 参数效率 训练 成本优化 超参迁移 学习率迁移

论文：https://arxiv.org/abs/2608.20061

论文针对大型 MoE 模型难以通过全面搜索确定最优学习率的问题，提出跨模型宽度与 token 预算的两步迁移方法。首先，作者为结合 MLA 和 Muon 优化器的 MoE 架构适配 μP，验证最优学习率可在不同宽度模型间稳定迁移。随后，通过拟合小型代理模型在有限训练预算下的最优值建立缩放定律，可高精度外推至 10 万亿 token 的训练范围，回归拟合达到 $R^2=0.95$。该方法被用于从零预训练总参数 155B、激活参数 17B 的基础模型，稳定的训练与评测结果验证了预测配置的有效性。

用途与启示

  • 可先在小模型和有限 token 预算上实验，再将最优配置迁移到完整训练规模。
  • 展示了 μP、MLA 与 Muon 在 MoE 缩放训练中的联合适配思路。
  • 为训练预算规划和大模型超参数预测提供可量化的缩放定律。

OmniAssistBench 面向实时视频助手场景，要求模型结合视觉状态、用户目标和先验知识，持续引导用户完成任务。为控制同一目标可能产生的交互路径分歧，基准向模型提供从源视频提取的预定义先验，并要求其沿指定路线提供指导。数据集通过逆向分析互联网视频、推导用户目标并切分为多轮片段构建，耗费超过 1000 个专家工时。实验中 Gemini-3-Pro 得分 66.4/100，Qwen3-Omni-Instruct 得分 51.2，现有模型主要受限于视觉提示理解、历史上下文保持、回答完整性及响应时机判断。

ParaTempo：基于时间置信度的高效并行推理

ParaTempo利用分支局部的时间置信度异步剪枝、提前终止并重新分配计算，在保持推理准确率的同时显著降低延迟和令牌消耗。

子主题：并行推理 Hugging Face Papers 

 并行搜索 时间置信 异步推理 停止策略 推理加速 成本优化 分支剪枝 置信调度

论文：https://arxiv.org/abs/2608.16425

ParaTempo是一种无需训练的异步并行推理框架，以答案空间随时间的收敛程度作为统一控制信号。框架周期性探测每条推理分支的候选答案分布，并根据近期探测是否集中于主导答案计算时间置信度。低置信分支会被剪枝，持续收敛的分支可提前退出，释放的计算资源则用于派生新分支；当置信加权投票足够集中时，全局生成停止。数学与科学推理实验显示，该方法在保持有竞争力准确率的同时，将平均延迟降低21.8%至32.2%，总令牌用量降低18.1%至30.3%。

用途与启示
  • 为并行推理提供不依赖最终答案共识的在线分支调度机制。
  • 可将时间置信度用于分支剪枝、提前退出、计算重分配和全局停止，统一简化控制策略。
  • 适合对延迟和令牌成本敏感的数学、科学推理服务，无需额外训练即可接入。
  • 启示推理系统应关注中间答案分布的时间稳定性，而非仅依赖瞬时 token 置信度。

OPD 泛化的双重效应：师生来源决定能力迁移

受控实验表明，同策略蒸馏主要迁移教师的推理行为而非特定答案，其跨语言、跨推理长度和跨领域泛化高度取决于师生模型的来源关系，并在多教师场景中产生能力跷跷板效应。

子主题：泛化机制 Hugging Face Papers 

 同策略蒸馏 多师蒸馏 同源迁移 跨域泛化 能力迁移 蒸馏泛化

论文：https://arxiv.org/abs/2608.16647
  • 研究逐一控制泛化因素，系统考察 OPD 在域内分布偏移、跨领域迁移及多教师设置下的表现。
  • 结果显示，OPD 迁移的是教师的推理行为，而非具体问题答案；训练样本难度影响很小，即使教师未能解出的题目也可提供有效监督。
  • 师生来源关系是关键变量：同源模型组合可在语言、推理跨度乃至其他领域广泛迁移能力，异源组合则主要拟合训练分布。
  • 这种广泛迁移具有双刃剑效应，领域路由提示无法完全限制各教师的影响，多教师蒸馏会形成随混合比例变化的能力跷跷板。
用途与启示
  • 为选择 OPD 的教师—学生组合提供依据：若追求广泛能力迁移，应优先考虑同源模型。
  • 提醒多教师蒸馏不能仅靠领域提示隔离教师影响，需要显式评估不同混合比例下的能力增益与退化。
  • 启示蒸馏数据筛选不必过度强调题目难度或教师答对率，教师轨迹中的推理行为本身可能更重要。
  • 可用于构建覆盖域内偏移、跨语言、跨推理跨度和跨领域迁移的蒸馏泛化评测体系。

PatternEval：混合思考多模态模型的响应行为对齐

论文提出 PatternEval、PatternRM 与 PatternRL，用于评测并缓解混合思考多模态模型在思考和非思考模式之间的响应行为失配。

子主题：响应对齐 Hugging Face Papers 

 多模态 思考模式 评估 推理泄露 奖励建模 强化学习 响应模式 模式对齐 表演推理

论文：https://arxiv.org/abs/2608.12781
