WildAWM：面向计算机使用智能体的可控环境与任务合成

WildAWM利用开源模型合成同时支持GUI、MCP和命令行交互的可执行环境及长程任务，并通过执行质量门控保障可解性、难度与验证可靠性。

 环境合成 世界模型 智能体 数据合成 长程任务

论文：https://arxiv.org/abs/2610.26828
代码：https://github.com/MSR-Orchard/WildAWM

WildAWM是一套面向通用计算机使用智能体的可扩展环境与任务合成流水线，可生成同时支持图形用户界面、MCP服务和命令行接口的可执行环境。系统通过异构智能体轨迹、跨评判器一致性检查和反事实探测构成执行式质量门控，以提高任务的可解性、难度及验证器可靠性。该流水线共合成341组长程环境—任务对，部分任务需要超过100步操作，GPT-6-Astra的完成率仅为60%。仅在这些合成世界中训练的两种不同规模Qwen模型，在覆盖Web、Claw和计算机使用智能体的8个分布外基准上均取得显著提升。

用途与启示
  • 为计算机使用智能体提供比真实系统更安全、可控且易扩展的交互训练环境。
  • 展示GUI操作、工具调用与代码执行可以在统一环境中联合训练，增强智能体的跨接口协作能力。
  • 执行式质量门控可用于过滤不可解、过于简单或验证器不可靠的合成任务。
  • 分布外评测结果表明，高质量合成世界能够向未见过的真实计算机任务迁移。

Socratic Skill Learning 通过专家教学与学生智能体实践交替进行，使智能体自主测试、修订并沉淀可跨任务复用的技能，同时显著降低指导成本。

★ 3 子主题：技能演化 Hugging Face Papers  AgentTrainEvolve AgentEvolve MemoryEvolve

 智能体 智能体技能库 能力迁移 经验学习 多轮反馈

论文：https://arxiv.org/abs/2610.17860

Socratic Skill Learning（SSL）让 Educator 提供调查指导，但由 Student 独立操作环境、编写技能，并通过提问和测试调整建议。作者构建 SkillTransferBench，包含 35 个任务族和 408 个可执行案例，以新求解会话中的留出任务检验技能迁移。在主要的 22 个任务族、155 个案例上，Fixed-Window SSL 的效用达到 0.801，高于无技能、Trace2Skill 轨迹蒸馏和 SKILL-KD 对比蒸馏。Issue-Guided SSL 持续追踪技能修订中的未解决问题，取得 0.805 效用，并较 Fixed-Window SSL 减少 61.7% 的 Educator token 和 16.9% 的总技能获取 token。

用途与启示
  • 为智能体技能学习提供“专家引导—自主实践—技能修订”的闭环范式，避免仅从成功轨迹中提炼未经验证的操作规则。
  • SkillTransferBench 可用于评估技能能否跨会话、跨任务变体复用，而非只衡量原任务上的即时成功率。
  • 通过追踪未解决问题来按需安排指导，可在保持迁移效果的同时减少专家调用与 token 成本。
  • 结果表明，交替式过程指导比专家直接编写技能或任务完成后的事后教学更有效。

PrismaForge是一套分层数据流水线，通过合成评分标准将程序正确性、代码构建质量和渲染视觉效果分解为可检查的评价维度。该评分标准同时充当数据过滤器和强化学习奖励信号，用于筛选监督训练语料并优化视觉编码任务。团队据此构建了覆盖广泛的开放数据集PrismaCoder-2M，并训练、发布PrismaCoder-9B与PrismaCoder-35B。实验显示，两款模型大幅刷新开放多模态代码智能水平，并可与领先闭源系统竞争，评分标准驱动的流程也能跨模型骨干带来增益。

用途与启示

  • PrismaCoder-2M及开放权重模型可作为多模态代码生成、视觉编程评测和奖励建模的研究基础。
  • 该流程具备跨模型骨干迁移潜力，可用于扩展开放多模态代码模型的数据规模与质量。

FCP：面向未来演化建模的自回归视频生成

论文提出未来片段预测（FCP）辅助目标，通过预测间隔较远的视频片段，促使自回归视频扩散模型学习场景演化规律，并以更低训练计算量提升生成结果的物理合理性。

★ 2 子主题：视频生成 Hugging Face Papers  NewModel

 视频生成 模型训练 世界模型 时序建模 多模态

论文：https://arxiv.org/abs/2610.29989

自回归视频扩散模型通常逐片段生成视频，但教师强制训练中的高度时间冗余可能使模型依赖局部视觉连续性这一捷径，而未能充分学习场景的长期演化。作者提出未来片段预测（Future Chunk Prediction，FCP）辅助目标，要求模型在无法访问中间视觉上下文的情况下预测时间上相隔较远的片段。FCP直接使用训练视频提供监督，无需额外的预训练视觉编码器，也不改变原有的自回归推理流程。实验表明，该方法以更低的整体训练计算预算获得了优于标准教师强制训练的物理合理性，并形成更具结构性的表征空间。

用途与启示
  • 为自回归视频生成提供针对场景动态演化的显式训练信号，减少模型对局部时间冗余的依赖。
  • 在不增加预训练编码器或修改推理流程的前提下，提高生成视频的物理合理性与训练效率。
  • FCP形成的结构化表征空间可为构建具备长期预测能力的自回归世界模型提供基础。

DONIC：基于人类演示的通用灵巧双手追踪控制

DONIC通过融合PPO、行为克隆与成功轨迹回收，在单一策略中实现跨物体、跨动作来源的通用灵巧双手协同操控。

★ 2 子主题：具身基础模型 Hugging Face Papers  RobotEvolve

 具身智能 模仿学习 强化学习 动作表征 数据增强

论文：https://arxiv.org/abs/2610.29997

DONIC是一个面向接触密集型交互的通用双手追踪控制器，可联合学习不同操作类别和人类动作来源。作者同时构建BiHOI多视角数据集，包含1,575段双手交互序列和229个物体，并将重建的人类交互重定向为机器人参考动作。训练方法将近端策略优化（PPO）与行为克隆结合，通过反馈循环把验证成功的执行轨迹重新纳入演示数据，并采用以物体为中心的单手奖励和Clip-Centered Advantages改善协同学习。无需微调时，单一检查点在训练物体的未见轨迹上达到86.79%成功率，在留出物体上达到57.32%，分别领先双手追踪基线77.36和45.73个百分点。

用途与启示
  • 为从人类多视角演示学习通用双手灵巧操控提供可扩展的数据与训练范式。
  • 成功执行轨迹的验证和回收机制可用于构建强化学习与模仿学习相结合的闭环数据增强流程。
  • 以物体运动为中心、按双手接触角色分配监督，有助于解决接触密集任务中的协同控制与信用分配问题。
  • 单一策略对未见轨迹和留出物体的泛化结果表明，异构人类动作参考可支持更通用的机器人控制策略。

StreamEval 是面向交互式流式视频生成的统一评测基准，覆盖虚拟人对话、虚拟人表演、世界生成、指令编辑和参考编辑五类任务。基准包含300个持续15至300秒的脚本化案例，每个案例均设定初始素材、逐步到达的多模态请求，以及状态变化和内容保留要求。评测从任务执行、状态一致性、视觉保真度和视听协调四个维度展开，并采用10项任务特定指标进行百分制评分。对37种模型的实验表明，高视觉质量和身份保持能力并不等同于可靠的请求执行或持续状态一致性，其中参考编辑的最高编辑成功分仅为15.00。

用途与启示
  • 为交互式流式视频模型提供覆盖生成、控制与编辑任务的统一评测框架。
  • 将请求执行、状态保持和视听协调纳入长时连续交互评估，避免只依赖单帧画质或身份一致性指标。
  • 结果提示后续系统应重点提升时序约束下的指令遵循、内容保留与状态持续能力。
  • 可用于比较实时全模态视频系统，并定位视觉质量与交互可靠性之间的能力错配。

SpatialScout 是面向视觉语言模型智能体的主动式物体级三维建图基准，包含80个多样化室内场景和3140个目标物体。智能体根据物体清单、RGB观测、相机标定及位姿控制相机探索场景，并在统一坐标系中估计物体中心。任务综合考察视点选择、跨视图关联、几何估计和地图修订，并以兼顾定位精度与目标覆盖率的物体尺度重叠分数进行评价。实验中表现最强的 Claude Opus 5.5 平均重叠分数仅为41.71%，说明当前前沿VLM距离构建完整、精确的度量地图仍有显著差距。

用途与启示
  • 为主动感知、具身探索和物体级三维建图提供可量化的统一评测环境。
  • 可用于诊断VLM智能体在视点规划、跨视图关联、几何定位及地图动态修订方面的能力短板。
  • 结果表明粗略恢复物体布局不等同于构建可靠的度量地图，后续系统需强化覆盖率、定位精度与交互预算之间的联合优化。
