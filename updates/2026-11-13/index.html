TreeOPSD：树式信用分配提升深度研究智能体准确率

清华大学与腾讯提出TreeOPSD，通过树式轮次信用估计、后验蒸馏和动态残差更新改善长程智能体强化学习，使30B-A3B模型的深度研究平均准确率较GRPO提升4.97个百分点。

★ 3 子主题：信用分配 量子位  ResearchEvolve AgentTrainEvolve

 信用分配 强化学习 长程智能体 深度研究 策略优化

论文：https://arxiv.org/abs/2610.23181
原文：https://mp.weixin.qq.com/s/7HsvsEcqXHKrUr5OIafdvg
  • TreeOPSD采用“初始化后扩展”的树式采样，从共享前缀生成不同后续路径，并依据终局奖励估计每轮操作的细粒度信用。
  • 方法将轮次信用映射为有界Bernoulli教师目标，再以Forward KL执行后验蒸馏，无需额外训练Critic、奖励模型或依赖人工过程奖励。
  • 动态残差机制会根据当前策略与目标的距离调节更新力度，达到目标后停止推动，发生过冲时反转更新方向，从而缓解连续mini-batch更新中的策略陈旧问题。
  • 在Qwen3-30B-A3B-Thinking-2507上，四项Deep Research评测的平均Exact Match达到21.20%，较GRPO的16.23%提升4.97个百分点，较TreePO提升3.61个百分点。
  • 消融实验表明，pointwise credit、odds map以及4条初始轨迹各扩展2个分支的采样配置表现更优。
用途与启示
  • 为长程智能体训练提供比整轨迹统一奖励更精细的轮次级信用分配方案。
  • 通过随策略状态变化的目标匹配机制，降低离策略数据被连续复用时的过度更新风险。
  • 可用于深度研究、多跳问答和长程工具调用等仅有终局可验证奖励的任务。
  • 提示训练预算不仅取决于Rollout总量，完整轨迹与分叉数量的分配同样会显著影响效果。

RSI 持续进步评测：从 RSIBench-Data 到 S³Gym

文章对比 RSIBench-Data 与 S³Gym，指出判断智能体是否持续改进必须联合审查版本轨迹、计算预算、基线收益、历史峰值及独立未见任务表现。

★ 3 子主题：演化能力评测 未知  EvalEvolve AgentEvolve Awesome-RSI GeneralizeEvolve

 智能体评估 递归自我改进 模型评估 经验学习 评估透明度

原文：https://mp.weixin.qq.com/s/VSiiBiEPQ08vnSj198Hb6A?scene=1

RSIBench-Data 固定基础模型、训练后端、任务环境和评分规则，让研究 Agent 迭代数据策略，并区分首次有效候选、历史最佳、最终提交和未训练基线。其跨轮继承的是研究历史与反馈，而非连续更新研究 Agent 自身权重，因此主要衡量数据研究能力，不能直接作为同一模型递归升级的证据。 S³Gym 将探索与严格评估隔离，比较 History ICL、Summary Memory 和参数训练三种经验复用路径，并用独立随机种子检查经验能否迁移。实验表明，自评分准确度与后续能力提升几乎不相关，生成合理摘要也不保证策略真正改善。 评估持续进步不能只看最高分或迭代轮数，还应同时检查独立测试、最终成绩、回退幅度、AUC+、预算以及是否适应了反复使用的评价条件。

用途与启示
  • 为递归自我改进与智能体自进化系统设计可审计的持续进步评测协议。
  • 提醒研究者区分参数自我更新、数据策略搜索、上下文经验复用和摘要记忆等不同改进机制。
  • 建议同时报告未训练基线、首次有效候选、历史峰值、最终提交及独立重测结果，避免把恢复受损能力误判为能力突破。
  • 强调将搜索反馈与未见任务评估隔离，并记录版本、轨迹和预算，以识别基准适应、偶然命中及后期回退。

TestPrism揭示Coding Agent测试生成合格率被高估

南京大学团队提出TestPrism，以多样化正确与错误实现联合评估生成测试，发现单一参考答案会将最强Coding Agent的测试成功率从28.00%高估至59.67%。

★ 2 子主题：代码评测 新智元  CodeEvolve EvalEvolve HarnessEvolve

 人工智能辅助编程 模型评估 软件缺陷修复评估 动态基准测试 自我改进

论文：https://arxiv.org/abs/2610.12289
代码：https://github.com/TestPrism/TestPrism
数据集：https://github.com/TestPrism/TestPrism
原文：https://mp.weixin.qq.com/s/2c10EW-WopHPgsM1wr_Clw

TestPrism包含来自17个来源的300个测试任务和3000个带标签候选实现，每项任务配置参考实现、正确替代实现及错误实现。其核心指标联合成功函数（JSF）要求生成测试在原始代码上失败、接受全部正确实现并拒绝全部错误实现，从而同时识别测试过严和过松的问题。14种Coding Agent配置中，最佳配置的单一参考接受率为59.67%，但JSF仅为28.00%，表明传统Fail-to-Pass评测显著高估测试可靠性。对286条失败轨迹的分析归纳出覆盖缺口、错误检查等3大类7种错误机制，其中错误判断标准、遗漏输入和参考实现过拟合尤为突出。团队进一步提出TestHelix，通过异构合成、同伴交叉验证和递归自我改进，在相同推理预算下将JSF提高11.67至12.00个百分点。

用途与启示
  • 用多正确实现与多错误实现面板替代单一Gold Solution，可更严格地评估Coding Agent生成测试的泛化性与判别能力。
  • 软件修复、代码评审和强化学习不应直接把单一参考测试结果作为可靠奖励，否则可能放大过拟合及错误奖励。
  • 测试生成系统需要同时优化输入覆盖、断言强度和对合法替代实现的兼容性，而不能只追求代码覆盖率。
  • TestHelix表明异构候选生成、交叉验证与递归改进可作为提升自动测试可靠性的有效闭环。

该研究通过BookNavigator与细粒度强化学习奖励，训练模型自主检索、研读并应用长篇教材知识，显著提升数学证明及跨领域长上下文任务表现。

研究将自我学习定义为模型面对陌生领域时，自主检索、研读并即时应用长篇参考材料，而非仅聚合检索事实或依赖预先组装的上下文。作者设计了基于教材的数学问题求解任务，并提供BookNavigator接口，使模型能够浏览教材、学习相关原理并在隐藏参考答案的情况下构造证明。通过细粒度奖励开展强化学习后，Intern-S2-Preview-35B的整体证明准确率由51.5%提升至79.5%，超过无教材和固定检索的强化学习基线。该策略还能迁移至不同教材、学科和任务类型，在BrowseComp-Plus与CL-bench上分别较基础模型提升1.7和2.3个百分点。

  • 可用于数学证明、专业教材问答及陌生领域的长上下文问题求解系统。

TOME-Math：从结构化教科书扩展数学证明监督

TOME-Math 从2,118本大学数学教科书构建约38万条保留课程顺序、证明依赖和来源信息的结构化监督记录，微调后使模型综合评测均分提升16.7个百分点。

★ 2 子主题：数据策展 Hugging Face Papers  DataEvolve LogicEvolve

 数据工程 数学人工智能 模型训练 课程学习 证据溯源

论文：https://arxiv.org/abs/2610.40394

TOME-Math（Textbook-Oriented Mathematical Evidence）覆盖大学数学核心学科，从2,118本教科书中提取约38万条结构化证明监督记录。不同于扁平化的问题—解答数据，它保留章节顺序、命题与证明链接、依赖引用以及来源溯源信息。研究利用这些结构信号开展跨数学学科的课程学习，并分析监督数据规模与来源广度带来的扩展规律。全量数据微调使模型在留出评测和公开基准上的非加权平均分相较基础模型提升16.7个百分点，综合表现超过三种公开指令数据基线。

用途与启示
  • 展示结构化教科书可作为可扩展、高质量的数学证明监督来源。
  • 说明课程顺序、证明依赖和来源证据等数据组织信息不应在预处理时被扁平化丢弃。
  • 为研究监督规模、来源多样性与数学推理能力之间的关系提供实证框架。
  • 可用于构建具备依赖感知和证据溯源能力的数学推理训练集。
