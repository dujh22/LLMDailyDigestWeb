RSIAgent通过自主探索实现递归自我提升

RSIAgent 通过课程生成、环境执行、结果验证与记忆演化组成的递归闭环，使开源模型无需更新参数即可自主探索和适应新环境，并持续提升任务表现。

代码：https://github.com/AetherLabsAI/RSIAgent
原文：https://mp.weixin.qq.com/s/bg0tkvHsKTZ88uBNKUdVTQ

RSIAgent 是一个免训练的多智能体框架，由 curriculum agent、actor agent 和 verifier agent 协作，将探索任务生成、环境交互、结果验证及 Memory 更新组织成递归闭环，适用于界面、工具规则和失效模式未知的环境。框架采用 Broad-to-Deep 两阶段策略：先并行探索不同工具、操作流程和输入条件以扩大知识覆盖，再连续生成更困难的任务，深入挖掘失败模式、隐藏约束、异常状态、边界条件及未知因果依赖。系统不微调或强化学习底层模型，而是将验证后的动作—条件—结果关系写入可演化记忆，构建完成后冻结并直接复用于下游任务。在 OSWorld 2.0 和 Agents’ Last Exam 上，RSIAgent 分别取得 78.98% Partial Score 和 84.82%，并在 GameCraft-Bench 等交互场景中展现跨场景迁移及自主游戏开发能力；实验还显示其可持续增强 Kimi-K3、GLM-5.3 等开源模型，部分指标超过文中对比的闭源模型。

用途与启示
  • 展示从 Scaling Model 转向 Scaling Experience 的路径，使智能体能在部署后通过自主探索持续提升，而不必针对每个新环境重新采集数据或训练模型。
  • 可用于新软件、桌面应用、企业系统及隐私工具环境，通过主动试错与验证低成本积累可复用的操作知识。
  • 将课程生成、并行探索、任务执行、结果验证和长期记忆解耦并组成闭环，可降低错误经验写入与持续累积的风险。
  • Broad-to-Deep 策略兼顾环境结构与工具规则的覆盖，以及困难任务、失效模式和边界条件的发现，可用于自动课程学习与极限测试。
  • 结构化保存经验证的动作—条件—结果因果经验，有助于经验复用、故障诊断、长程决策执行及跨任务和跨环境迁移。

论文：https://arxiv.org/abs/2608.03223

ADRS使用同一策略快照，在普通上下文和带任务技能的上下文下对无技能轨迹进行重评分，将训练期特权技能转化为Token级奖励信号，推理时无需读取技能。方法先在每个交互步骤内对教师分数进行中心化和尺度归一化，再利用TVA门控衡量教师置信度与实际回报的关联，仅放行可靠的任务信用。门控后的信号被直接注入环境奖励到优势估计再到策略更新的原生路径，而非增加独立的蒸馏损失。在150步预算下，Qwen2.5-3B在ALFWorld取得94.5%成功率，较最强基线提升10.1个百分点，并在WebShop、搜索式问答、未见任务及更长交互链路上展现优势。

用途与启示
  • 为只有终点奖励的多轮智能体提供细粒度时间信用分配方案，使训练更新聚焦于查询、动作和对象选择等关键Token。
  • 展示如何将训练期特权技能蒸馏进策略，同时保持采样和部署阶段完全无技能依赖。
  • TVA说明教师置信度不能直接等同于任务价值，奖励塑造应根据其与实际回报的关联进行可靠性门控。
  • 该方法可作为GRPO、GiGPO等强化学习算法之上的信用构造层，但需权衡额外重评分计算，并注意批内相关性不代表因果归因。

Dream-RSI：通过演化世界实现递归自我改进

谷歌、Google DeepMind等机构提出Dream-RSI，利用历史发现树构建低成本回放世界，在不修改基础模型权重或底层编码智能体的情况下，离线演化并递归改写探索策略，以更低搜索预算持续提升智能体能力。

子主题：递归自我改进 Hugging Face Papers  Awesome-RSI HarnessEvolve

 递归自我改进 智能体 探索与利用 经验复用 策略优化 智能体脚手架演化 进化搜索 执行回放 并行搜索

论文：https://arxiv.org/abs/2609.14858
原文：https://aiera.com.cn/asi-preview/asi-item.html?id=tga1b9c1

Dream-RSI面向自主编码智能体，将底层发现智能体与顶层探索策略解耦，仅通过轻量级可编程编排层改写节点选择、并行规模和停止规则。系统保存真实探索中的工作区快照、产物、诊断与得分，形成“发现树”，并将已探索的搜索空间转化为无需再次调用模型或执行代码的离线回放模拟器。策略开发智能体在历史树上生成和评估候选策略，综合探索质量、成本与并行效率进行筛选，仅部署回放得分优于当前策略的版本，从而形成“在线发现—离线梦境优化—策略再部署”的递归闭环。实验覆盖Lasso求解器、数学优化和GPU内核工程等任务，其中算法任务仅用317次模型调用便追平固定策略约550次调用及SimpleTES约51200次生成的水平；实验还表明，将历史经验概括为高层提示可能压缩搜索多样性并降低性能。

用途与启示
  • 展示一种无需修改基础模型权重、通过递归改写外围探索脚手架实现能力持续提升的自我改进路径。
  • 将昂贵且反馈延迟较高的在线策略评估转化为低成本历史回放，适用于代码搜索、算法发现、数学优化和GPU内核工程等自动化研发任务。
  • 使发现树同时充当经验库、策略模拟器与离线评测环境，为分支选择、并行调度和早停规则的自动优化提供反馈。
  • 构建可扩展的“在线发现—离线梦境优化—策略再部署”闭环，使新发现能够持续扩充回放世界并支持后续策略演化。
  • 提示经验复用应保留原始轨迹、分支多样性和可执行反馈，避免过度抽象的高层总结引入搜索偏置或局部最优。

分组价值注意力：按需重建键以压缩 KV 缓存

分组价值注意力（GVA）通过缓存分组值并按需重建内容键，在保持接近 GQA 准确率的同时将持久化 KV 缓存量减少约 45%～47%。

子主题：模型架构创新 Hugging Face Papers 

 缓存优化 系统优化 推理加速 模型开发 长上下文

论文：https://arxiv.org/abs/2609.13285

论文提出分组价值注意力（GVA），不再为每个解码步骤同时缓存内容键和值，而是缓存分组值，并使用学习到的线性映射重建内容键。推理时，该线性映射可吸收到查询向量中，从而避免在目标解码路径上显式生成内容键；位置信息则由一个小型共享、解耦的 RoPE 通道及单独缓存的位置键保留。实验配置下，GVA 相比匹配的 GQA 将持久化缓存标量减少约 45%～47%。在使用 30B FineWeb-Edu 词元训练的 3.5 亿参数模型上，16 维位置通道版本五项任务平均准确率为 44.18，接近 GQA 的 44.36，并高于 MLA 的 43.88；作者正在评估定制解码内核的端到端性能，并计划开源。

用途与启示
  • 为长上下文和高并发推理提供一种显著降低 KV 缓存容量与读取流量的新型注意力结构。
  • 展示了将可学习的键重建映射吸收到查询侧的思路，可用于联合优化模型架构与推理内核。
  • 当前结果主要验证缓存压缩与任务准确率，实际吞吐、延迟及硬件利用率仍需等待定制内核的端到端评测。
  • 适合进一步研究位置通道维度、缓存压缩率和模型质量之间的权衡。

  • BVB（Blender-VideoBench）不再仅以问答评测视频理解，而是要求智能体将真实视频重建为可渲染的 Blender 动画场景。

  • 将过程信号内化到策略后可移除推理阶段的奖励模型，从而兼顾跨数据集迁移能力与部署成本。
