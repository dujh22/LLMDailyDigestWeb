SO-Arena 面向无需冗长词元生成、强调快速决策的 System One 模型，覆盖 11 个领域和五类能力家族。基准通过可靠来源、人工核验参考标签和领域特定难度标准，提供有证据支撑的细粒度能力评估，并要求模型在沙箱中迭代执行动作。除准确率外，它还通过受控改变选项集合后的决策稳定性，以及不存在有效选项时的缺失答案识别能力来衡量可靠性。对 21 个模型的实验表明，规模扩展与额外推理的收益高度依赖领域，综合性能最强的 System One 模型在可靠性上仅排名第七。

用途与启示

  • 结果提示模型能力与可靠性并不等价，部署和选型时应将稳定性、缺失答案识别与任务性能分别评估。
  • 沙箱交互任务及 System One/Two 对比可用于分析额外推理在不同领域的实际收益。

CoACT：面向 Coding Agent 的动作保持式上下文压缩

清华大学提出 CoACT，以保持 Coding Agent 下一步动作为压缩准则，在 SWE-bench Verified 上平均降低 33.0% Token 消耗，同时维持相近的任务成功率。

★ 2 子主题：上下文压缩 机器之心  Groom HarnessEvolve

 人工智能辅助编程 上下文压缩 成本优化 智能体 缓存优化

论文：https://arxiv.org/abs/2607.02911
代码：https://github.com/THU-Agent/CoACT
原文：https://mp.weixin.qq.com/s/ryId58B7OK5j1Ja6HA80eQ

CoACT 在新 observation 写入上下文前进行压缩，避免改写历史，从而保留 KV Cache 的复用能力。其核心指标是下一步动作保持（NAP）：比较智能体读取原始与压缩 observation 后的动作是否一致，以低成本评估压缩是否保留任务所需信息。团队基于教师模型生成候选压缩，并通过动作类型、目标文件和读取范围等结构化信息筛选训练示范，再采用离线监督微调与在线对齐两阶段训练轻量压缩器。在 SWE-bench Verified 的 200 个实例和三个 Agent 模型上，CoACT 平均减少 33.0% 总 Token 消耗，平均 PASS@1 从 69.0% 提升至 71.0%，且可与 AgentDiet 等历史压缩方法组合。

用途与启示
  • 为长程 Coding Agent 提供兼顾任务成功率、Token 成本与 KV Cache 复用的上下文压缩方案。
  • 将“动作是否保持”而非文本相似度作为压缩质量标准，可用于构造更贴近智能体执行目标的训练数据。
  • 离线轨迹与在线部署轨迹联合训练，有助于缓解压缩历史导致的训练—推理分布偏移。
  • 结果表明，单步输出变短不等于全任务成本下降，压缩策略还需考虑重复读取、交互步数和缓存失效。

行动者、评判者还是教师？长时程智能体中的决策模型

研究发现，长时程任务中表现不佳的行动模型仍可能成为有效教师，因为完整轨迹上的事后评判能更准确地识别有益动作并提供强化学习信号。

★ 2 子主题：信用分配 Hugging Face Papers  JevEvolve AgentTrainEvolve

 智能体 长程任务 信用分配 强化学习 模型评估

论文：https://arxiv.org/abs/2611.17167
代码：https://github.com/ZJU-REAL/decision-agents

研究在 ALFWorld 上比较了三种决策模型和三种通用 LLM 作为行动者与评判者的表现，并使用 JEV 在 ALFWorld 和 WebShop 上训练策略。作为行动者，六个模型都会受到更容易完成的目标干扰，偏离必须优先完成的子目标。看到完整轨迹后，模型能够正确认可推进关键子目标的步骤；逐动作判断“是否有帮助”也比预测任务最终能否成功更能区分有效与无效动作。以 JEV 作为教师进行 GRPO 训练后，Qwen2.5-1.5B 在 ALFWorld 上的成功率由 72.8% 提升至 82.9%，在 WebShop 上由 56.8% 提升至 71.4%。

用途与启示
  • 说明行动能力并非衡量决策模型训练价值的唯一标准，较弱行动者也可能提供高质量监督。
  • 支持采用完整轨迹事后评判实施动作级信用分配，缓解长时程任务中的短视决策问题。
  • 为强化学习教师模型的选型提供依据：应单独评估其评判与教学能力，而非仅依据直接任务成功率。
  • 提示奖励设计优先询问单步动作是否推进任务，而非直接预测整条轨迹能否成功。

PhysLoop 是一个面向视频生成模型的统一自我改进框架，重点解决物理动态错误与因果不一致问题。它在视频生成、样本筛选和错误纠正环节引导并约束 LLM，将其物理知识转化为具有物理一致性的训练样本。该框架同时支持可控训练数据构建与推理时局部视频修复，并通过识别和修正失败案例形成改进闭环。作者发布了覆盖室内外真实场景的 10 万段视频，以及 PhysLoop-Gen、PhysLoop-Repair 两个评测数据集，并在 Physics-IQ Verified 上评估物理行为。

用途与启示
