Self-Developing Agents 三项基准揭示智能体自进化瓶颈

字节跳动 Seed、TokenWave 等提出 ASPIRE、S³Gym 与 HarnessDev，分别评测智能体从模糊目标确定学习方向、吸收自身经验以及持久演化执行系统的能力。

子主题：递归自我改进 机器之心  HarnessEvolve

 递归自我改进 智能体评估 自我改进 经验学习 智能体脚手架演化

论文：https://arxiv.org/abs/2609.01437
原文：https://mp.weixin.qq.com/s/IXykZ19IPZF28aytiIZSHg

Self-Developing Agents 将递归自我改进拆分为目标形成、经验吸收和系统演化三个环节，并通过 ASPIRE、S³Gym 与 HarnessDev 分别开展评测。ASPIRE 显示，智能体面对模糊能力目标时会投入大量预算解释目标和选择代理指标，但真正保留下来的训练增益极少。S³Gym 发现，自我判断的准确性与后续学习收益关联较弱，原始轨迹、摘要记忆和参数更新也不存在跨环境通用的经验保存方式。HarnessDev 表明，智能体能够持续修改 Harness，但这些改动容易过拟合可见反馈、损害原有功能，并在隐藏任务上出现性能下降。三项基准共同指出，自进化的核心瓶颈不是能否修改系统，而是能否验证改动、筛选可泛化经验并安全地保留长期收益。

用途与启示
  • 为递归自我改进研究提供覆盖目标形成、经验学习与 Harness 演化的分层评测框架。
  • 提醒研究者区分“完成自我修改”与“获得可泛化能力提升”，避免以代理指标或合理的复盘文本代替真实效果验证。
  • Harness 的持久改动应经过隐藏任务评测、机制调用审计和回滚测试，防止反馈过拟合及功能退化。
  • 长期自进化系统需要建立可靠的目标选择、经验保留、跨任务验证和版本恢复机制。

Harness Evolution 公平评测：复杂进化不如多次采样

研究在统一推理预算与反馈条件下发现，现有 Harness Evolution 未能稳定超越简单的多次采样或顺序修正，且其在未见任务上的迁移增益仅约 0.6 个百分点。

 模型评估 智能体脚手架演化 测试时计算 跨域泛化 评估透明度

论文：https://arxiv.org/abs/2607.12227
代码：https://github.com/rethinking-harness-evolution
原文：https://mp.weixin.qq.com/s/qovt_73lfy1zoH_TelYhjg

论文《Rethinking the Evaluation of Harness Evolution for Agents》在 Terminal-Bench 2.1 上，以相近的推理预算和反馈条件比较 Parallel Sampling、Sequential Refinement、Harness Evolution 与 Harness Scaling。没有 Unit Test 时，简单的并行采样从 68.2 提升至 72.3，而传统 Harness Evolution 降至 67.4；加入可靠正确性信号后，多次采样和顺序修正仍整体占优。研究强调应关注新 Harness 的首次尝试表现，因为依靠多条轨迹获得的提升可能主要来自测试时计算，而非脚手架本身的能力改进。在完全隔离的测试任务上，进化 Harness 的平均增益仅为 0.6 个百分点，表明部分收益可能是针对基准任务的适应，而非可迁移的通用 Agent 设计原则。

用途与启示
  • 评估 Harness Evolution 时，应为基线提供相同的推理次数、计算预算和外部反馈，避免把重试收益误判为架构进化。
  • 应同时报告 pass@1、总调用次数、轨迹数量和反馈类型，以区分脚手架能力提升与测试时扩展收益。
  • 需要采用严格隔离的训练、验证和测试任务，检验进化 Harness 是否具备跨任务迁移能力。
  • 后续基准应突出长期记忆、多工具协同、复杂工作流、验证与故障恢复等真正依赖 Harness 质量的能力。

持续学习机制组合提升长时程记忆

研究通过组合数据、函数和权重锚点及 merged LoRA，将连续微调模型在 100 个任务后的平均最终记忆保持率从 1.2%提升至 34.9%。

子主题：长期记忆 Hugging Face Papers  MemoryEvolve

 持续学习 模型训练 长程任务 参数高效微调 灾难性遗忘

论文：https://arxiv.org/abs/2609.06986

论文提出长时程记忆设定：模型连续学习 100 个问答任务，不能保留早期训练样本，推理时也无法获得任务标识。实验表明，朴素顺序监督微调会引发严重灾难性遗忘，且单一持续学习机制无法在这一时间跨度上维持较强记忆。作者从“保留什么”和“将更新存在哪里”两个维度组合数据、函数、权重锚点以及低秩分配规则，并通过任务级 successive halving 和因子实验分析各机制及其交互作用。最佳方案组合三类锚点与 merged LoRA，在三个数据集上均位列前三，将平均最终保持率由 1.2%提高到 34.9%，其中数据锚点与 merged LoRA 呈现超加性交互。

用途与启示
  • 为需要持续吸收信息的模型设计长期知识保持机制提供组合式方案。
  • 表明缓解灾难性遗忘不能只依赖单一正则化或参数隔离方法，应同时约束数据、函数与权重变化。
  • 数据锚点与 merged LoRA 的超加性效果可指导持续微调和参数高效更新系统的工程设计。
  • 任务级 successive halving 可用于低成本搜索复杂持续学习机制的组合空间。

FLAT：灵活长度对齐的跨模态表征统一检索与生成

FLAT 将图像与文本映射为可变长度的一维连续对齐标记，通过联合对比学习和双向生成目标，使统一表征同时支持跨模态检索与图文生成。

子主题：多模态学习 Hugging Face Papers 

 多模态 视觉表征学习 视觉生成 模型训练 检索增强生成

论文：https://arxiv.org/abs/2609.16591

FLAT 采用共享多模态编码器，并联合训练文生图和图生文解码器，避免生成模型受限于冻结视觉嵌入。它将图像与文本重采样至统一的一维连续序列空间，并通过针对前缀 K 个标记的 nested dropout 支持动态表征长度。模型在单阶段预训练后即可使用不同长度前缀完成跨模态检索和生成，微调后在 GenEval、MS-COCO 与 Flickr30K 等基准上达到有竞争力的结果。所得表征还原生支持线性插值、潜空间算术和零样本组合检索。

用途与启示
  • 为统一跨模态检索与生成提供共享表征方案，减少独立编码器与生成器之间的能力瓶颈。
  • 可根据任务复杂度动态调整标记长度，在表征质量、计算成本和存储开销之间进行权衡。
  • 连续且可插值的跨模态空间可用于组合检索、语义编辑及潜空间可控生成。
  • 联合判别与生成目标的设计可为通用多模态基础模型预训练提供参考。

ModAR：模态自回归世界-动作模型

ModAR 通过依次去噪并生成点轨迹、DINO 特征和深度等未来模态来预测动作，以更低训练成本提升真实世界双臂操作成功率。

子主题：世界模型 Hugging Face Papers 

 世界模型 具身智能 多模态 模型训练 任务规划

论文：https://arxiv.org/abs/2609.17524

ModAR 是首个在动作预测前自回归去噪多种未来模态的世界-动作模型，使每种模态的预测能够以此前生成的模态为条件。研究从零训练模型，系统比较训练数据混合、预测模态和 WAM 建模方式对性能的影响。实验表明，预测点轨迹、DINO 视觉特征和深度图能够带来收益，而额外预测未来 RGB 图像并无稳定增益。ModAR 在所有评估数据规模上取得最高平均成功率，并以约少 20 倍的训练 FLOPs 超越经视频模型初始化的 Flex-π（75% 对 72%）。在三项真实世界双臂任务中，ModAR 优于基线，且引入人类视频后性能进一步提升。

用途与启示

  • 表明人类视频可用于增强真实世界机器人操作，为低成本扩展具身训练数据提供依据。
