Synthetic Persona Pretraining：从首个 Token 开始对齐

Synthetic Persona Pretraining（SPP）通过在预训练语料中加入符合价值规范的第一人称反思，从预训练起点植入目标助手人格，提升价值遵循与越狱鲁棒性且基本保持模型能力。

子主题：预训练对齐 arXiv

论文提出 Synthetic Persona Pretraining（SPP），在预训练阶段就将目标助手人格和价值观注入模型，而非仅依赖后训练对齐。其方法依据规范性价值宪法，为预训练文档生成价值对齐的第一人称反思，并使用标准交叉熵损失共同训练原始文档与反思文本；随后通过用户—助手对话进行“人格绑定”。在最高 3B 参数、500B Token 的实验中，SPP 提升了宪法遵循和越狱鲁棒性，并降低分布外道德困境中的失准率，同时保持原有能力。相比仅在预训练末期引入 SPP，从首个 Token 开始干预能更有效地改变价值优先级，其优势还会随预训练预算增加而扩大。

用途与启示
  • 将价值对齐前移至预训练阶段，使目标价值成为模型行为先验的一部分，而非脆弱的后训练覆盖层。
  • 可利用合成的第一人称价值反思扩充预训练数据，为低成本、规模化的人格与价值注入提供路径。
  • “人格绑定”结果说明，仅预训练目标人格并不足够，还需在后训练阶段将其稳定映射到助手身份。
  • 为评估早期对齐干预提供实验依据，可重点考察价值遵循、越狱防御、分布外道德决策及能力保持。
