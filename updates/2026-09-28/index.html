Raven V0.2.0 将 Raven-Research、Raven-Code、Raven-Design、Raven-Oncall 及 Claude Code、Codex 等专业 Agent 纳入统一编排，通过 DAG 完成成员选择、任务拆解、依赖调度和产物交接。其 Harness 将可进化部分划分为 Modules、Code、Prompt 和 Policy，并以 Memory、Planning、Capability、Action 四类公共策略接口承接具体调整。实验性 Curator 可读取任务轨迹与用户反馈，生成策略代码或配置，经声明检查、真实装配和预检后安装，失败时自动恢复上一版本，从而形成可追溯的 Harness 自进化闭环。EverOS 负责保存跨会话上下文与经验，并将任务结果沉淀为可复用的 Playbook 和执行策略；模拟案例已跑通多轮改进，但尚缺少跨场景、可重复的统计验证。现有评测显示 Raven 在任务图生成、深度研究等多智能体编排与专业任务上优于部分同底座 Harness，但这些结果并不能直接证明 Harness 自进化的实际收益。

用途与启示
  • 展示递归自我改进可从模型参数层扩展到提示、记忆、策略代码、工具权限、工作流和团队编排等 Harness 层。
  • 为跨模型、跨框架的异构专业 Agent 协作提供可复用架构：以 DAG 表达依赖并管理结果交接，以 Playbook 和持久记忆支持跨会话经验复用。
  • Curator 的声明检查、真实装配、预检安装、版本追溯与自动回滚机制，为安全部署可自修改智能体提供了工程参考。
  • 后续研究应通过跨任务、跨场景的重复实验，单独评估 Harness 演化的泛化收益、长期稳定性、回滚可靠性与回归风险，并探索其与模型参数慢更新机制的协同。
