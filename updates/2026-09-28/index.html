Anthropic 将 Workbench 升级为 Claude API Playground

Anthropic 将 Workbench 更名并升级为 Playground，通过可视化配置、API 报文查看和一键代码导出，降低 Claude API 的应用开发门槛。

子主题：编程工具 新智元 

 模型开发 人工智能框架 人工智能辅助编程 工具调用 人工智能应用

原文：https://mp.weixin.qq.com/s/2TKEA5rW3NPScPQnyVpQxA

Anthropic 将使用近两年的开发者工具 Workbench 更名为 Playground，并将其打造为建立在 Messages API 之上的可视化开发环境。用户无需编写代码，即可切换 Claude 模型、调整生成参数，并测试工具调用、结构化输出、代码执行和 Web Search 等能力。平台允许查看原始 HTTP 请求与响应、Token 消耗及上下文调用逻辑，还可将调试结果一键导出为 Python、TypeScript 或 cURL 代码。其产品思路是先在浏览器中低成本完成原型验证，再导出可直接集成至代码仓库和 CI/CD 流程的脚本。

用途与启示
  • 降低 Claude API 的试用和原型开发门槛，使非专业开发者也能验证人工智能应用构想。
  • 将参数调试、工具配置、成本观察和代码生成整合到统一界面，缩短从实验到工程集成的路径。
  • 体现大模型厂商竞争正从聊天入口扩展至开发控制台、API 易用性和应用生态建设。
  • 可用于快速比较模型、提示词与高级 API 功能，并生成后续工程开发的初始代码。

对话 OpenAI Codex 负责人：从内部工具到通用智能体

OpenAI Codex 负责人 Tibo Sottiaux 回顾 Codex 从内部研究工具和自主软件工程师项目演变为开放式 Coding Agent 的历程，并阐述其超越代码生成、重塑软件开发全生命周期的目标。

子主题：人工智能辅助编程 The Pragmatic Engineer  HarnessEvolve

 人工智能辅助编程 智能体 SWE 软件工程 智能体脚手架 开放权重模型

原文：https://mp.weixin.qq.com/s/aBFDItu7Qcz0gJANM1A6RQ

Codex 最初源于 OpenAI 内部帮助研究人员编写 Python、搭建基础设施的小型智能体，随后与自主软件工程师（ASWE）项目合并，逐步扩展到理解代码库、调用工具、执行测试和提交修改。团队选择使用 Rust 重写核心智能体，并开源 CLI 与 SDK、允许接入其他模型，以提升正确性、效率和生态开放性。Codex 正从本地 Coding Agent 走向云端并与 ChatGPT 统一，其长期目标不局限于编程，而是成为可承担更广泛知识工作与长程任务的通用智能体。随着正确性检查、安全审查、依赖升级和重构逐渐自动化，人类工程师的重心将转向产品意图、架构边界、用户理解以及问题选择。

用途与启示
  • 为 HarnessEvolve 研究提供真实产品案例，展示智能体脚手架如何从内部工具经由用户反馈、工程重写和云端化持续演进。
  • 说明 Coding Agent 的竞争力不仅取决于基础模型，还取决于代码库理解、工具调用、测试执行、运行时环境及反馈闭环等系统能力。
  • 开源 CLI、SDK 和模型兼容接口有助于形成可扩展生态，并降低智能体与单一模型供应商的绑定。
  • 软件开发自动化将重新划分人机职责：智能体负责执行与验证，人类更多关注需求、架构、安全边界和高价值问题。

Raven V0.2.0：统一编排专业 Agent 并推动 Harness 持续进化

EverMind 开源 Raven V0.2.0，通过 Harness of Harnesses 统一编排 Claude Code、Codex 等专业 Agent，并利用 Curator 根据执行反馈持续改写和验证 Harness。

子主题：脚手架演化 机器之心  SwarmEvolve HarnessEvolve Awesome-RSI

 智能体脚手架演化 智能体编排 多智能体系统 递归自我改进 智能体记忆

原文：https://mp.weixin.qq.com/s/u9Pnht2mHluZH_FS5tnbAg

Raven V0.2.0 将 Raven-Research、Raven-Code、Raven-Design、Raven-Oncall 及 Claude Code、Codex 等专业 Agent 纳入统一编排，通过 DAG 完成成员选择、任务拆解、依赖调度和产物交接。其 Harness 将可进化部分拆分为 Modules、Code、Prompt 和 Policy，并以 Memory、Planning、Capability、Action 四类公共策略接口承接具体调整。实验性 Curator 可读取任务轨迹与用户反馈，生成策略代码或配置，经声明检查、真实装配和预检后安装，失败时自动回滚，从而形成 Harness 层递归自我改进闭环。EverOS 负责保存跨会话上下文与经验，评测则显示 Raven 在多智能体编排和深度研究等任务上优于部分同底座 Harness，但 Harness 自进化效果尚缺少跨场景、重复性统计验证。

用途与启示
  • 展示递归自我改进可从模型参数层扩展到提示、记忆、工具权限、控制代码和团队编排等 Harness 层。
  • 为异构专业 Agent 协作提供可复用架构：以 DAG 表达依赖，以 Playbook 固化流程，以持久记忆支持跨会话经验复用。
  • Curator 的检查、预检、安装、追溯与回滚机制，为安全部署可自修改智能体提供了工程参考。
  • 后续研究应重点评估 Harness 改写的跨任务泛化、长期稳定性、回滚可靠性，以及与模型参数慢更新机制的协同。

基础模型冲击下，AI 博士生与学术研究何去何从

文章讨论基础模型对传统 AI 研究范式的冲击，并提出 AI 博士生可转向基础模型工程或研究智能机制等基础科学问题。

文章指出，部分 AI 论文仍沿用更换基础模型、叠加归纳偏置和刷新基准成绩的套路，其研究价值正受到质疑。随着通用基础模型进入三维视觉、空间推理和机器人操作等专业领域，许多可符号化且具有明确强化学习评价标准的任务可能被统一模型吸收。作者认为 AI 博士生可选择参与高质量数据、训练基础设施和基础模型研发，也可回归科学问题，研究模型为何有效、能力如何产生。讨论者同时强调，代码智能体、开源模型与开放权重生态也在降低前沿研究门槛，学术研究并未终结，而是在发生问题迁移。

用途与启示
  • 帮助 AI 博士生评估以刷榜和局部结构创新为主的研究路线是否仍具长期价值。
  • 启发研究者从性能增量转向机制解释、能力边界、表征分析与基础科学问题。
  • 提示个人研究者利用代码智能体和开放权重模型提升实验效率并参与前沿探索。
  • 为院系和实验室调整人才培养、科研评价及基础设施投入方向提供参考。
