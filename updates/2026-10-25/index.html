RoboSkill：具身智能体的技能积累与复用框架

复旦大学团队提出RoboSkill，通过融合触觉反馈与文字、代码结合的技能积累机制，使具身智能体能够跨任务、跨模型复用并持续更新操作经验，显著降低新任务的探索与执行成本。

RoboSkill针对通用多模态智能体操控机器人时反复“观察—推理—执行—检查”带来的高时间开销，围绕“探索—执行—演化”构建技能获取与复用闭环，无需预先采集目标任务示范数据或开展针对性训练。框架引入压力、力和力矩等触觉反馈，帮助智能体快速确认接触状态，减少重复视觉检查和动作调整。任务结束后，系统会将有效策略整理为包含文字说明与真实执行代码的Skill，并根据后续执行结果持续更新，供不同任务和模型复用。仿真与真机实验显示，技能积累和代码复用能够缩短任务耗时、提高一次执行成功率；其中GPT-5.6-Sol使用文字与代码技能后，一次成功率由15%提升至67.5%。

用途与启示
  • 将机器人现场探索产生的策略与经真实执行验证的代码沉淀为可持续更新的技能库，把单次交互经验转化为可复用资产。
  • 降低新任务对示范数据、重复推理、程序生成和现场试错的依赖，从而减少执行成本。
  • 说明触觉反馈可作为视觉观测的重要补充，高效确认物理接触状态并加快执行闭环。
  • 为跨任务、跨模型复用经验的具身递归自我改进与持续进化系统提供实践路径。

 强化学习 智能体记忆 元学习 长上下文 测试时计算

论文：https://arxiv.org/abs/2610.31656

METTA将元强化学习的快速适应拆分为两个时间尺度：因果神经记忆负责回合内的细粒度适应，紧凑的回合级摘要负责跨回合的长期任务推断。该设计无需关注完整交互历史，将序列处理复杂度由Transformer式二次开销降至线性级别。神经记忆还支持测试时训练，使智能体能够适应元测试阶段未见的任务及任务族。在Meta-World ML10/45未见测试环境中，METTA以较低训练预算取得超过50%的成功率，并在长上下文、稀疏奖励PointMaze任务上展现出比Transformer基线更有结构的探索行为。

用途与启示
  • 为需要跨长交互历史推断任务的元强化学习智能体提供低成本记忆架构。
  • 展示回合内神经记忆与跨回合摘要结合的分层状态表征思路。
  • 说明测试时训练可提升智能体对未见任务及任务族的快速适应能力。
  • 可用于长上下文、稀疏奖励和探索密集型连续控制任务。

WholeBodyMem针对人形机器人移动操作中的非马尔可夫问题，保存机器人执行目标前与任务对象相关的视觉历史。系统利用SAM3追踪对象，并根据对象事件在自适应预算内因果选择关键帧，而非均匀保留全部历史。动作专家通过交叉注意力读取关键帧及包含外观、几何和时间信息的对象词元。作者还提出HuMeGo基准，涵盖6项仿真与6项真实Unitree G1任务；该方法将基础策略成功率从仿真的29.1%提升至72.6%，并将真机成功率从36.7%提升至88.3%。

用途与启示

  • 为动态遮挡、转身离开视野及对象状态变化等部分可观测场景提供事件驱动的记忆设计。
  • HuMeGo可用于评估人形机器人策略对历史视觉信息的利用能力及其仿真到现实表现。
  • 对长程具身任务的启示是将对象追踪、关键帧筛选与动作策略联合建模。

Reflexion 将 Actor、Evaluator 与 Self-Reflection 组成闭环，把环境奖励、规则或测试结果转化为可执行的语言反馈，并将其称为“语义梯度”。系统以当前轨迹作为短期记忆、以失败反思作为长期记忆，使后续尝试能够跨越循环复用经验，而模型权重始终保持不变。在 ALFWorld、HotPotQA、HumanEval、MBPP 和 LeetcodeHardGym 等任务中，该机制改善了长程决策、检索推理和代码修复表现，例如在 HumanEval Python 上由 80.1% 提升至 91.0%。实验也表明收益并不稳定，MBPP Python 出现性能下降，反思质量、信用分配、评估器可靠性与有限记忆容量仍是关键约束。

用途与启示
  • 展示无需参数更新的测试时经验学习路径，可用于构建低成本、自我改进的智能体。
  • 将环境反馈转写为具体反思，有助于定位长轨迹中的关键错误并调整后续计划。
  • Actor、Evaluator 与 Self-Reflection 的模块化设计可迁移到工具调用、知识检索和代码修复工作流。
  • 实际应用需要审计评估器与反思内容，防止错误反馈被写入记忆并在后续循环中持续放大。

 模型评估 同行评审分析 模型评判偏差 科学研究基准 人工智能可靠性

论文：https://arxiv.org/abs/2610.31414

研究收集了 2026 年发表于 Nature、Science、Cell 等 20 种期刊的 200 篇 CC BY 4.0 论文，并让四种闭源或开放权重 LLM 在盲审条件下分别生成评审报告。800 份评审中有 605 份（75.6%）建议大修或拒稿，但不同模型给出此类决定的比例从 17.5% 到 100% 不等。研究者进一步向论文植入特定领域的方法学或统计缺陷，各模型的检出率仅为 17.0% 至 60.5%。结果表明，LLM 评审既可能对已通过真实同行评审的论文过度否定，也可能漏掉明确缺陷，其输出强烈依赖模型及任务框架。

用途与启示
  • 为 LLM 同行评审系统提供同时考察特异性、敏感性和模型间一致性的评测设计。
  • 提醒期刊和科研平台不要将单一 LLM 的评审结论直接用作稿件录用或拒绝依据。
  • 实际部署时应引入多模型交叉验证、专家复核与缺陷检测校准，并披露所用模型及提示设置。
  • 顶刊已发表论文并非绝对真值，但可作为检验自动评审系统判断稳定性与责任边界的重要参照。

VAST 引入以当前状态、未来状态和时间跨度为输入的 G-function，用于估计任意轨迹片段的折扣累计回报，并通过组合一致性约束增强跨时间尺度泛化。框架学习拼接策略，联合选择未来子目标与自举跨度，再将局部回报和后续价值拼接起来；其 stitching Bellman operator 被证明具有收缩性质。执行策略采用目标条件行为克隆，并在测试时通过拒绝采样生成多个动作，再由 Q 函数选择价值最高的候选。VAST 在 OGBench 的 10 个领域、50 个状态输入任务上优于多类单步、多步、动作分块和生成式价值基线，尤其适合多阶段操作任务。

用途与启示
  • 为长程离线强化学习提供可自适应选择时间尺度的价值更新机制，减少固定步长造成的自举偏差与阶段错配。
  • 将子目标选择、跨时间信用分配和动作生成连接起来，可用于复杂规划及多阶段机器人操作。
  • 启示价值学习应根据任务阶段动态决定观察跨度，而非仅依赖固定 n-step TD 或固定动作分块。
  • 当前结果主要来自状态输入的离线基准，后续仍需验证其在视觉输入、真实机器人和开放环境中的泛化能力。
