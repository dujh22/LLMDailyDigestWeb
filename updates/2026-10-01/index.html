子主题：环境合成 量子位  EnvironmentEvolve

 智能体执行框架 环境合成 系统优化 强化学习 安全沙箱

DSec通过统一Python SDK接入FnCall、Container、MicroVM和Full VM四类执行后端，以适配不同隔离强度、系统功能与性能要求的智能体任务。系统将基础镜像、工作区和工具包拆分为可组合的EROFS层，并结合OverlayFS、3FS与按需加载机制，显著减少镜像重建、磁盘写入和沙盒启动时间。针对智能体交互期间CPU低利用率但内存需持续驻留的特点，DSec采用高密度资源超卖、共享页缓存、内存回收和优先级调度，生产环境超卖率超过50倍。DSec还将轨迹执行与GPU训练解耦，利用增量快照支持状态恢复和轨迹分叉，并通过AppArmor与eBPF限制文件、套接字及网络访问；单分片每天可服务约300万个沙盒，峰值并发超过38万个。

用途与启示
  • 为大规模智能体强化学习提供可持续保留文件、进程和交互进度的状态化执行环境。
  • 可组合环境层与按需镜像加载适合用于批量生成、更新和复用高度多样化的训练及评测环境。
  • 将轨迹执行从可抢占GPU训练任务中解耦，可降低中断恢复复杂度并提升长程训练任务的可靠性。
  • 增量快照与轨迹分叉机制可支持从同一中间状态并行探索，为搜索、数据合成和策略优化提供基础设施。
  • 智能体主动寻找奖励捷径的生产案例表明，环境演化必须同步加强访问控制、执行隔离和持续攻防评估。

同系列在策略蒸馏的缩放特性

研究揭示同系列模型在策略蒸馏的能力迁移规律，并发现小型 RL 专家可使更大模型学生超越教师表现。

子主题：在策略蒸馏 Hugging Face Papers 

 在策略蒸馏 模型蒸馏 缩放定律 弱到强泛化 强化学习

论文：https://arxiv.org/abs/2609.32722

论文系统研究弱到强、同基座及强到弱三类教师—学生组合中的在策略蒸馏（OPD）缩放特性。训练早期普遍存在“有效迁移”区间，留出集准确率与学生相对初始化模型的词元级反向 KL 散度平方根近似呈线性关系。所有观测到的弱到强组合中，学生的峰值成绩均超过教师，表明紧凑型 RL 专家能够向更大的学生模型有效迁移推理能力。作者进一步拟合参数规模、教师成绩与峰值表现及迁移斜率之间的幂律，发现教师规模增益在接近学生规模时趋于饱和，且成绩相同时较小教师反而迁移得更好。

用途与启示
  • 为不同规模教师与学生的 OPD 配对提供可预测的缩放规律。
  • 说明教师的基准成绩不能单独衡量监督价值，模型规模同样影响迁移效率。
  • 支持使用计算成本较低的小型 RL 专家训练更强的大模型学生。
  • 可依据有效迁移区间和 KL 距离监控训练进程，并辅助确定合理的蒸馏停止点。

Omni-IO Skills：让智能体原生支持全模态任务

Omni-IO Skills 通过分层技能、统一多模态执行接口、依赖感知编排和持久化资产注册表，在不修改推理核心的情况下将现有智能体扩展为全模态系统。

子主题：智能体框架 Hugging Face Papers  HarnessEvolve

 人工智能框架 多模态 智能体 插件架构 智能体编排

论文：https://arxiv.org/abs/2609.31847

Omni-IO Skills 是一个即插即用的 Agent Harness，用于协调文本、图像、音频、视频、文档、3D 资产和代码等多类产物。框架以分层 Skills 和标准化执行接口封装能力，并通过声明式执行图管理任务依赖、并发调度和可替换的执行后端。持久化 Asset Registry 会登记成功产物，支持后续步骤及跨轮对话中的复用和修改。系统提供 27 项技能，覆盖 38 个代表性任务；在 UniM-90 上将 GPT-5.6 Sol 与 Claude Sonnet 5 的输入支持率提升至 100%，并显著提高语义—质量耦合得分与严格结构得分。

用途与启示

  • 声明式执行图可用于编排复杂多资产工作流，并借助依赖分析并行执行互不依赖的操作。
  • 持久化资产注册机制为跨轮修改、中间产物复用和长程任务状态管理提供了通用设计。
  • 分层技能与可替换后端有助于降低智能体和专用模型、工具之间的耦合，便于持续扩展与演化。

VoxMem：大型音频语言模型多模态记忆评测基准

VoxMem通过跨会话音频历史评测大型音频语言模型对语义、说话人、辅助语言线索和环境声音的记忆能力，结果显示15个模型在32K上下文下均未超过40%准确率。

子主题：记忆能力评测 Hugging Face Papers  MemoryEvolve

 模型评估 智能体记忆 多模态 长上下文 语音识别

论文：https://arxiv.org/abs/2609.32607

VoxMem包含3,196个评测实例，覆盖34,743段口语会话、共177小时音频，并按8K至64K词元的上下文预算分层。基准同时考察语音语义、说话人身份、辅助语言线索和环境声音四类声学证据，以及信息提取、多会话推理、时序追踪和拒答四类记忆操作。对15个大型音频语言模型的评测显示，没有模型在32K上下文设置下超过40%准确率。模型对“说了什么”的记忆明显优于“谁说的”“如何说的”和“听到了什么”，且该差距会随操作复杂度和历史长度增加而扩大。

用途与启示
  • 为大型音频语言模型提供覆盖声学证据、记忆操作和跨会话历史的系统化评测框架。
  • 揭示仅依赖转录文本会遗漏说话人身份、辅助语言信息和环境声音等关键记忆信号。
  • 可用于诊断长上下文音频模型在多会话推理、状态追踪及不充分证据拒答方面的失效模式。
  • 为后续设计原生音频记忆模块、多模态长期记忆机制和针对性训练数据提供依据。

Simple-WAM：测试时未来建模提升世界动作模型泛化

研究发现世界动作模型的泛化收益主要来自首个去噪步骤对未来表征的预备，而非完整生成未来视频，并据此提出兼顾泛化与效率的 Simple-WAM。

子主题：世界模型 Hugging Face Papers 

 世界模型 具身智能 测试时计算 跨域泛化 视频理解

论文：https://arxiv.org/abs/2609.34981

世界动作模型在训练时同时预测动作与未来视频，但测试时是否需要完整生成未来帧一直存在效率争议。受控实验表明，完全丢弃未来表征的 Latent WAM 虽能保持分布内性能，却在环境扰动、数据效率和任务泛化三个维度上持续弱于 Explicit WAM。进一步分析发现，几乎全部泛化增益都来自第一次去噪，即关键在于为动作专家准备未来表征，而不是生成清晰视频。Simple-WAM 仅对完全加噪的视频 token 执行一次前向计算，并调整训练噪声调度，在仿真与真实任务中以接近 Latent WAM 的效率取得优于 Explicit WAM 的泛化性能。

用途与启示
  • 说明测试时未来表征是世界动作模型实现跨环境、跨任务泛化的关键条件。
