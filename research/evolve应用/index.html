Evolve应用

研究方向：Evolve 应用——跟踪自进化 / 递归自我改进（RSI）方法走出论文、进入真实场景后的成果与形态：AI 做科学与数学、实验室内部的 RSI 闭环、产业与产品中的自进化系统、具身机器人的自主进化，以及国家级科研计划。

研究范畴

Evolve 应用（evolve application watch）是本站的横向跟踪方向，与各 *Evolve 方向及 Awesome-RSI 关心"方法如何自我改进"不同，本方向关心"自我改进在哪里真正产生了结果"；与 NewApply 跟踪一般性的能力落地相比，本方向只收录以自进化、自主迭代为核心机制的应用；与 RSI创业 关注公司与融资相比，本方向关注成果本身。本方向涵盖：AI 在数学与科学硬问题上的突破（猜想证明、矩阵乘法指数、蛋白质设计、自动化科研基准）；头部实验室披露的 RSI 内部实践（大规模智能体自我迭代、模型参与训练下一代模型）；产业侧的自进化系统（搜索引擎递归自我进化、企业级 RSI 落地、可生长的 Agent OS）；具身智能的自进化模型与系统；以及国家层面的 AI 科研计划。社区关注的核心问题包括：成果是否可独立核验、自进化在真实工作场景中的成功率究竟如何，以及人类在闭环中正在从执行者变为瓶颈还是把关者。

研究挑战

  • 成果核验：媒体标题常有夸大（“40 年难题 56 分钟破局"“年底实现 AGI”），需回到论文、证明或官方报告核对原始结论与人类参与程度。
  • 实验室与真实场景的落差：基准与 demo 上的自进化效果，在真实工作场景中成功率依然偏低，长程任务的错误累积尚未解决。
  • 归因困难：改进来自模型自身、搜索与验证脚手架，还是人类专家的筛选与修正，难以拆分。
  • 可持续性：一次性的突破（单个猜想、单个纪录）与能持续迭代、持续产出的自进化系统之间仍有距离。
  • 安全与治理：大规模智能体自我迭代、模型训练下一代模型，带来监督、审计与对齐上的新问题。

自研项目

  • Awesome-RSI — 面向 RSI 的持续研究项目，本方向的应用条目是其方法清单的落地侧补充。
  • EvolveLLM — 博士课题《Toward True ASI》承载仓库，Evolve 应用跟踪为其"自进化能否在真实场景成立"的观察窗口。
  • LLM-DailyDigest — 本站自身：采集 → LLM 判定 → 标注 → 建站部署，Evolve 应用条目由日报流水线持续汇入。

研究经验

  1. 科研协作闭环：开放式自主科研应把智能体、专家判断、实验资源和可接续记录纳入同一闭环，而非只增强单体能力。
    • HFM：开放式自主科研协作 · 2026-11-25
  2. 工具检查闭环：工具密集场景应先统一工具描述与接口，再让智能体依据可执行检查迭代程序，比单独增强推理更可靠。
    • Fin-RSI：统一金融技能与自改进 · 2026-11-25
  3. 稀疏权重搜索：成熟模型可优先搜索少量关键权重实现低成本自改进，不必默认采用端到端反向传播。
    • Weight Coding：智能体直接编辑模型权重 · 2026-11-25
  4. 数学证明可信链：AI生成重大数学结论时，应把形式化覆盖、独立验算和同行评审设为发布门槛，不能以草稿产量代替可信度。
    • OpenAI Math：AI批量生成数学证明 · 2026-11-26
    • Cogentic：自主证明分解复杂度 · 2026-11-26
  5. 混合式科学发现：开放式科学发现宜由LLM编排数据生成，以可解释窄模型和符号工具提出假设，再用反例与分区检验筛选。
    • PatternMiner：小模型解释驱动数学发现 · 2026-11-26
    • AI Buckingham：跨区间量纲标度发现 · 2026-11-26
  6. 证据约束演化：经验复用或系统演化应绑定适用条件、证据溯源和执行验证，并用受限编辑、回放审计与性能容差阻断错误累积。
    • Sports Agent：反馈驱动闭环自进化 · 2026-11-26
    • PowerFix：物理引导迭代修复 · 2026-11-26
    • EGSE：证据溯源式技能演化 · 2026-11-26
  7. 常驻智能体治理：常驻智能体接入多应用前，应建立最小授权、全程审计和人工兜底；单项任务能力不足以支撑长期自主运行。
    • dots：常驻智能体自建系统 · 2026-11-26
  8. 技能调用诊断：评测技能型智能体时应同时测自主与引导执行；两者差距可定位技能欠用，避免把脚手架缺陷误判为模型能力。
    • MedSkill-E²：医疗技能评测与演化 · 2026-11-26
  9. 主观反馈分解：演化交互产品时，不能以可执行性替代体验质量；应把趣味等主观目标拆成可诊断维度，驱动试玩、诊断与改写闭环。
    • Play2Evolve：趣味反馈驱动游戏演化 · 2026-11-27
