# 大模型日报 LLM-DailyDigest

> **您的 AI 前沿资讯中心** — 每日精选大型语言模型（LLM）领域的研究论文、开源工具与行业动态。

## 🎯 项目简介

**LLM-DailyDigest** 是一个专注于 LLM 领域的综合性资讯聚合站，自动追踪 ArXiv 等来源的最新进展，提供中文摘要与主题分类，帮助研究者、开发者和爱好者在快速演变的领域中保持领先。

## 📚 内容体系

网站由四个板块组成：

| 板块 | 内容 |
| --- | --- |
| **📰 [日报](/updates/)** | 每日更新的论文与资讯汇总，含中文摘要与原文链接 |
| **🏷️ [主题](/topic/)** | 按研究方向分类（智能体、推理、强化学习、多模态、训练…共 18 类） |
| **📖 [资源](/resources/)** | 必读论文、公开数据集、开源框架等学习资料 |
| **🔬 ArXiv 日报** | 自动抓取并智能分类的学术论文，附中文翻译 |

## 🚀 如何使用

1. 在 **[日报](/updates/)** 查看最新资讯
2. 在 **[主题](/topic/)** 按研究方向浏览
3. 在 **[资源](/resources/)** 获取学习材料
4. 用顶部 **搜索** 快速定位特定内容

获取更新：订阅 **RSS**、关注 **GitHub** 仓库，移动端同样适用。
